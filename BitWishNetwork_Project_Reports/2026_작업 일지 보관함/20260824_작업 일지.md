### 📷 이미지별 현상 및 원인 분석

#### 1. [1번 이미지] 스마트폰 접속 후 "나의 지갑" 열었을 때
* **현상**: 지갑 화면이 스마트폰 화면 중앙 전체나 모바일 전용 팝업/바텀시트(Bottom Sheet) 형태로 깔끔하게 뜨지 않고, PC용 지갑 모달 레이어 일부가 **화면 좌측 하단 구석으로 삐져나가 잘려 보임**.
* **기술적 원인**:
  * 데스크톱 환경이나 크롬 확장프로그램(Chrome Extension)용으로 맞춰진 고정 픽셀 너비(`width: 800px` 또는 `fixed position`) 스타일 규칙이 모바일 뷰포트(폭 360~412px)에 닿았을 때 모바일 전용 100% 반응형으로 전환되는 미디어 쿼리가 적용되지 않고 뷰포트 좌측 하단에 고정 배치되었기 때문입니다.

#### 2. [2번 이미지] 마이닝 페이지 / 추천 보너스 내역 접속 시
* **현상**: 지갑 모달, 추천 보너스 내역 팝업, 마이페이지 레이어 등 **여러 개의 팝업 모달이 어둡게 처리되는 배경(Backdrop) 없이 이중/삼중으로 겹쳐서 뒤엉킴**.
* **기술적 원인**:
  * 모바일과 같이 좁은 화면에서는 모달 팝업이 뜰 때 배경을 완전히 덮어 이전 화면을 블러/암전 처리(`z-index` 및 `backdrop-filter`)하거나 활성화된 팝업 1개만 스크린 전체에 집중 노출(Focus)되도록 해야 합니다.
  * 그러나 각 팝업 컴포넌트의 오버레이 z-index와 모바일 폭 감지 모달 제어가 표준화되어 있지 않아 레이어들이 유령처럼 화면 좌측에 겹쳐서 나타나는 현상입니다.

#### 3. [3번 이미지] BW 블록 익스플로러 접속 시
* **현상**:

  * **"개인채굴자할당량(65%)"** 및 금액 숫자들이 세로로 비정상 분해됨.
  * 오른쪽 영역의 "네트워크 상...", "거래...", "블록..." 카드들이 화면 오른쪽 밖으로 넘쳐 잘림.
* **기술적 원인**:
  * `ExplorerPage.css` 파일 내의 `economic-hybrid-grid` 등 주요 대시보드 레이아웃이 데스크톱용 **2~3열 가로 배치(`flex-direction: row`)로 고정**되어 있으며, **모바일 미디어 쿼리(`@media (max-width: 768px) { flex-direction: column; }`)가 완전히 누락**되어 있습니다.
  * PC의 넓은 화면용 카드를 360px짜리 스마트폰 폭에 강제로 구겨 넣다 보니, 왼쪽 카드의 너비가 40px 이하로 억지로 압축되면서 글자가 세로 1글자 단위로 쏟아져 내렸고, 오른쪽 카드는 화면 밖으로 밀려나 잘린 것입니다.

### ❓ 왜 이런 일이 발생했는가? (근본 원인)

1. **데스크톱(1920x1080) 모니터 위주의 개발 방식**:
   * 대시보드 및 지갑 UI 개발 시 PC 웹 브라우저 화면을 기준으로 레이아웃과 픽셀(px)을 구성하면서, **스마트폰 디바이스 브레이크포인트(Mobile Breakpoint - 768px / 480px 이하)에서의 반응형 검증 및 CSS 처리가 부분적으로 빠졌습니다.**
2. **모달/팝업 UI의 모바일 반응형 래퍼(Responsive Wrapper) 미비**:
   * PC용 모달 팝업을 모바일 기기 접속 시 스마트폰 화면에 딱 맞는 **"전체화면 모달"** 또는 **"하단 슬라이드 시트(Bottom Sheet)"** 형태로 전환해주는 모바일 전용 UX 설계가 되어있지 않습니다.

1. **블록 익스플로러 & 메인 페이지 레이아웃 모바일 수직 전환**:

   * `word-break: keep-all;` 옵션 적용으로 한글 단어가 1글자씩 세로로 깨지는 현상 완벽 방지.
2. **모달 팝업 시스템 모바일 최적화**:

   * `z-index` 및 배경 어둡게 처리(Backdrop)를 정립하여 팝업들이 겹치지 않고 1개씩 깔끔하게 노출되도록 제어.

스마트폰 접속 최적화 작업(반응형 CSS 수정 및 모달 최적화)을 진행하고자 하시면, 곧바로 전체 모바일 최적화 작업 계획 수립 및 코드 개선을 착수하겠습니다.

### 2. 🛠️ 1단계 핵심 기술 적용 내용

1. **스마트폰 가로 스크롤 및 화면 짤림 방지 (Viewport Overflow Lock)**
   ```css
   html, body {
     width: 100%;
     max-width: 100vw;
     overflow-x: hidden;
     scroll-behavior: smooth;
   }
   ```
   * 스마트폰 접속 시 화면이 좌우로 흔들리거나 우측 밖으로 삐져나가는 가로 오버플로우 현상을 근본적으로 차단했습니다.

2. **한글 단어 단위 보존 및 세로 1글자 깨짐 차단 (`word-break: keep-all`)**
   ```css
   p, h1, h2, h3, h4, h5, h6, span, a, label, button, div, td, th {
     word-break: keep-all;
     word-wrap: break-word;
     overflow-wrap: break-word;
   }
   ```
   * 3번 이미지(익스플로러)에서 관찰되었던 **"빗 / 위 / 시 / 통 / 합 / 경 / 제 / 센 / 터"** 형태의 한 글자 단위 세로 분해 깨짐 현상을 전역 텍스트 요소 수준에서 사전 예방 조치했습니다.

3. **스마트폰 터치 최적화 (Touch Standard & Area)**
   ```css
   /* 480px 이하 스마트폰 초소형 화면 터치 가이드라인 적용 */
   button, input, select {
     min-height: 44px; /* Apple / Google 모바일 터치 최소 표준 높이 */
     touch-action: manipulation;
   }
   ```
   * 모바일 디바이스에서 버튼이나 입력 필드를 터치할 때 더블 터치 확대 현상을 방지하고, 44px 이상의 터치 타겟을 확보하였습니다.

4. **모바일 반응형 전역 유틸리티 클래스 신설**
   * `.keep-all-text`: 단어 잘림 보존 전용 클래스
   * `.mobile-only` / `.desktop-only`: 화면 해상도(768px 이하)에 따른 요소 노출 Control 클래스
   * `.responsive-container`: 모바일 스마트폰 화면 폭(`padding: 0 0.75rem`) 유연성 제공

### 2. 🛠️ 2단계 핵심 기술 적용 내용

1. **우측 슬라이드 방식의 모바일 전용 수직 드로어(Drawer Side Menu) 구축**
   * 기존 단순 팝업 레이어 방식에서 우측에서 부드럽게 나오는 **모바일 전용 수직 드로어 메뉴(`right: 0`, `width: 320px`, `z-index: 1999`)**로 완전 전환했습니다.
   * 메뉴가 열릴 때 모바일 화면 전체에 **검은색 반투명 블러 오버레이(`mobile-menu-backdrop`, `backdrop-filter: blur(4px)`)**를 적용하여 뒤쪽 페이지 내용과의 시각적 겹침을 완전 차단했습니다.

2. **모바일 퀵 지갑 서비스(Quick Wallet Actions) 통합**
   * 모바일 드로어 메뉴 상단에 **`➕ 지갑 생성`** 및 **`👛 나의 지갑`** 퀵 실행 전용 대형 터치 버튼을 추가하여, 좁은 이모지 팝업을 누르지 않고도 손쉽게 지갑 기능을 사용할 수 있도록 하였습니다.

3. **모바일 햄버거 토글 및 터치 타겟 규격화 (44px Touch Target)**
   ```css
   .mobile-menu-toggle, .nav-icon {
     width: 44px;
     height: 44px;
     min-width: 44px;
     min-height: 44px; /* Apple / Google 터치 최소 권장 높이 */
   }
   ```
   * 스마트폰 터치 시 조작 오류를 방지하도록 모바일 햄버거 토글 버튼과 상단 컨트롤 이모지 버튼의 터치 패딩 및 영역을 44px로 확대했습니다.

4. **다국어(KO / EN / JA / ZH) 및 다크모드 수직 칩(Chip) 인터페이스 통합**
   * 드로어 메뉴 하단에 언어 변경 칩(`lang-chip`)과 다크 모드 토글 버튼을 모바일 가로/세로 손가락 동선에 맞춰 직관적으로 구성했습니다.
