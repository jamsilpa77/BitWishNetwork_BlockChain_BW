## 3. 🚨 현재 핵심 잠재 위험 — 3가지 분자 단위 분석

### 🔴 위험 #1 【가장 심각】 — `onMiningBlock()`에 Global Cap Guard가 없다

현재 [BlockMiningService.ts L23](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/server/services/BlockMiningService.ts#L23-L113)의 `onMiningBlock()` 함수 내부를 보면:

```typescript
public static async onMiningBlock(walletAddress: string, session?: any): Promise<BlockMiningResult> {
    // ← 여기에 "현재 블록 수 >= 발행량 정수" 검사가 전혀 없다!
    const newBlock = await bwChainCore.createBlock(walletAddress); // 무조건 블록 생성
    ...
}
```

이 함수는 **누가 부르든, 블록 수가 BW를 초과해도 무조건 블록을 하나 더 만든다.** `syncGlobalBlocks()` → `auditAndSyncGlobalBlocks()` 가 상한선을 검사하지만, `onMiningBlock()` 자체에는 아무 검사가 없다.

**현재 `onMiningBlock()`을 호출하는 경로:**
1. `autoRestoreMiningStates()` L81 → `syncGlobalBlocks()` → `auditAndSyncGlobalBlocks()` → `onMiningBlock()` (서버 기동 시)
2. `syncMiningData()` L280 → `syncGlobalBlocks()` → `auditAndSyncGlobalBlocks()` → `onMiningBlock()` (30초마다 클라이언트 요청 시)

`auditAndSyncGlobalBlocks()` 내부는 L201에서:
```typescript
if (targetBlockCount > currentBlockCount) {
    // 부족한 만큼 for 루프로 생성
    for (let i = 0; i < blocksToCreate; i++) {
        await this.onMiningBlock(systemValidator); // 대량 생성
    }
}
```

이 검사 자체는 올바르다. `auditAndSyncGlobalBlocks()`가 상한선을 체크하고 부족할 때만 생성하니까. **문제는 이 체크가 `onMiningBlock()` 밖에 있다는 것이다.** 누군가 다른 경로에서 `onMiningBlock()`을 직접 호출하면 상한선 없이 무조건 생성된다.

**현재 직접 호출 경로:**
- `sync-blocks-1to1.ts` L131, L155, L174 — 스크립트에서 직접 호출
- 테스트 파일 등

> **핵심 결론**: 현재 정상 운영 경로(syncMiningData → syncGlobalBlocks → auditAndSyncGlobalBlocks → onMiningBlock)에서는 상한선 검사가 있어서 **이론적으로 안전하다.** 그러나 `onMiningBlock()` 자체에 가드가 없어 다른 경로로 호출되면 위험하다.

이것은 `autoRestoreMiningStates()` 완료 후 비동기로 1회 실행된다. 내부적으로 `auditAndSyncGlobalBlocks()`를 호출하며, 총발행량 대비 부족 블록이 있으면 for 루프로 대량 생성한다.

**현재 상황(BW 7,444, 블록 7,482):**
- 블록(7,482) > BW 발행량 정수(7,444) → `targetBlockCount(7,444) <= currentBlockCount(7,482)` → **부족 블록 없음 → for 루프 실행 안 됨**
- 즉 지금 당장은 이 부분이 안전하다.

## 4. 🎯 가장 중요한 질문: "BW 7,444 → 7,483 돌파 시 즉시 블록 7,483 생성되는가?"

이것을 흐름도로 분자 단위로 추적한다:

```

        ↓
[MiningController.ts L229~285] syncMiningData()

 2. 채굴 보상 증가: accumulatedReward += rate * diffSeconds

        ↓
[BlockMiningService.ts L235~237] syncGlobalBlocks()

        ↓
[BlockMiningService.ts L136~228] auditAndSyncGlobalBlocks()
```

## ✅ 수정 후 코드 (완성본 — L23 이하 전체)

```typescript
public static async onMiningBlock(walletAddress: string, session?: any): Promise<BlockMiningResult> {
    try {
        // ══════════════════════════════════════════════════════════════════
        // [절대 상한선 가드 — Global Cap Guard]
        // 목적: 어떤 경로로 onMiningBlock()이 호출되든,
        //       현재 총 물리 블록 수 >= 실시간 참값 총 BW 발행량 정수이면
        //       블록 생성을 100% 원천 차단한다. (이중 안전장치)
        // 집계 공식: stats.ts / auditAndSyncGlobalBlocks()와 동일한 공식 적용
        // ══════════════════════════════════════════════════════════════════
        const _networkDb = mongoose.connection.useDb('bitwish_network');
        const _miningDb = mongoose.connection.useDb('bitwish_mining');

        // [가드 1] 현재 DB 물리 블록 수 조회
        const _currentBlockCount = await _networkDb.collection('blocks').countDocuments({});

        // [가드 2] 실시간 참값 총 발행량 산출
        // 2-1. MiningState 채굴 누적 합계
        const _msAgg = await _miningDb.collection('miningstates').aggregate([
            { $group: { _id: null, total: { $sum: { $toDouble: '$accumulatedReward' } } } }
        ]).toArray();
        let _totalMined = new Decimal(_msAgg[0]?.total || 0);

        // 2-2. 실시간 채굴 중인 유저 liveBoost 보정
        const _activeStates = await _miningDb.collection('miningstates').find({ isMining: true }).toArray();
        const _nowMs = Date.now();
        let _liveBoost = new Decimal(0);
        for (const _miner of _activeStates) {
            const _lastSync = _miner.lastSyncTime ? new Date(_miner.lastSyncTime).getTime() : _nowMs;
            const _elapsed = Math.max(0, (_nowMs - _lastSync) / 1000);
            if (_elapsed > 0) {
                _liveBoost = _liveBoost.plus(
                    new Decimal(_miner.currentTotalRate || '0.25').div(3600).mul(_elapsed)
                );
            }
        }

                    _id: null,

                    b: { $sum: { $toDouble: { $ifNull: ['$referralBonusStorage', '0'] } } },
```
