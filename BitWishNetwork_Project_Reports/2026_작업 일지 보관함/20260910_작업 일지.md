## 🔬 2. 문제점 정밀 분석 (1번~4번 이미지 기반 + 소스코드 교차 검증)

### 🚨 문제 1 - 나의 지갑: 모달이 화면을 꽉 채워 허접해 보임
**소스코드 원인 확인:**
- `MyWalletModal.css` line 19: `width: 800px` → 1920px 화면에서 800px이면 화면 폭의 **42%** 를 차지함
- `MyWalletModal.css` line 27: `max-height: 90vh` → 세로의 **90%** 까지 확장 가능
- `MyWalletModal.tsx` line 143~144: 초기 Y좌표가 `300px`으로 고정 → 화면 상단에 너무 가까움
- 헤더 `padding: 20px 32px` + 콘텐츠 `padding: 32px` + 카드 내부 `padding: 24px` → **3중 패딩 누적**으로 체감 크기가 더욱 비대해짐
- 결론: **800px 폭 + 90vh 높이 + 두꺼운 패딩 = 화면 꽉 채움**

### 🚨 문제 2 - 나의 지갑: 스크롤 시 홈페이지만 올라가고 지갑은 고정됨
**소스코드 원인 확인:**
- `MyWalletModal.tsx` line 335~343: 오버레이에 `pointerEvents: 'none'` 설정
- `MyWalletModal.tsx` line 340: `backgroundColor: 'transparent'` → 오버레이가 투명함 (배경 스크롤 잠금 처리 없음)
- `document.body.style.overflow = 'hidden'` 처리가 **전혀 없음** → 모달이 열려도 홈페이지 배경이 자유롭게 스크롤됨
- 결론: **Body Scroll Lock 코드 완전 누락**이 원인

### 🚨 문제 3 - 마이닝 페이지: 동일한 크기 문제
**소스코드 원인 확인:**
- `MiningStatusModal.css` line 26: `width: 600px`
- `MiningStatusModal.css` line 28: `max-height: 88vh`
- `MiningStatusModal.tsx` line 91: Y위치 `450px` → 홈페이지에서 `⛓️ 실시간 BW 채굴 상태 현황` 타이틀(`HomePage.tsx` line 746)이 화면 상단 약 `400~450px` 지점에 위치하는데, 현재 450px 고정이면 타이틀과 겹치지 않고 타이틀 **아래**에 뜰 가능성이 높음

### 🚨 문제 4 - 나의 지갑 위치: WalletAuthModal 아래에 떠야 함
**소스코드 원인 확인:**
- `WalletAuthModal.css` line 19: `max-width: 500px` → 이 모달은 `fixed + center` 방식
- `MyWalletModal.tsx` line 143~144: 나의 지갑은 현재 `y: 300` 고정 → **WalletAuthModal이 닫히고 난 후 나의 지갑이 뜨는 위치가 y:300으로 항상 고정**됨

  2. **강제 줄바꿈 및 파괴**: 수치가 공간 부족으로 인해 다음 줄로 밑도 끝도 없이 밀려 떨어지면서 카드 높이가 무너지고 UI가 완전히 파괴됨.

## 🛠️ 채굴 수량이 100만 BW 이상 올라가도 절대 밀리지 않는 근본 해결 구조

2열 카드 형태를 유지하면서 수치가 아무리 커져도 절대 밀리거나 깨지지 않으려면, **라벨과 수치를 가로 배치가 아닌 상하(수직) 배치로 전환**해야 합니다.

### [수정 전: 가로 1행 구조 (수치 커지면 충돌/밀림)]
```
실시간 누적 보상: 12345.67890123 BW  <-- 공간 부족으로 충돌 및 아래로 밀림!
```

### [수정 후: 상하 2행 완벽 보존 구조 (수치가 아무리 올라가도 100% 안전)]
```
실시간 누적 보상
12345.67890123 BW  <-- 가로 전체 폭(100%)을 수치가 독점 사용하므로 절대 안 밀림!
```

현재 작업을 정지한 상태입니다. 

위와 같이 라벨을 위로 올리고 **수치가 가로 전체 공간을 여유롭게 사용할 수 있도록 상하 구조로 정돈**하면 수치가 1,000,000 BW 이상 올라가도 절대 밀리지 않습니다. 지시해 주시면 이 대안으로 보정하여 진행하겠습니다.

## 🔍 [문제 1] 마이닝 모달이 정중앙이 아니고 좌측으로 100px 쏠린 이유

### 1. 현상 분석 (1번 이미지 스크린샷 증명)
- 스크린샷을 보시면 마이닝 모달이 화면 세로 높이는 맞으나, **화면 좌측으로 약 100px 정도 쏠려서 배치**되어 있습니다.

### 2. 기술적/수학적 발생 원인
- 4공정에서 CSS([`MiningStatusModal.css`](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/src/components/MiningStatusModal/MiningStatusModal.css))의 모달 폭을 `400px`로 먼저 축소 적용했습니다.
- 그러나 위치 계산을 담당하는 TSX([`MiningStatusModal.tsx`](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/src/components/MiningStatusModal/MiningStatusModal.tsx))는 아직 5공정이 적용되기 전이어서 **기존 600px 기준 공식**인 `const width = 600; const x = (window.innerWidth - 600) / 2;`로 X좌표를 계산하고 있었습니다.
- **수학적 쏠림 증명**:
  - 모달의 시작 위치(Left)가 `화면 중앙 - 300px` 지점으로 잡힙니다.
  - 모달 실제 폭이 400px이므로, 모달 영역은 `[화면 중앙 - 300px]` ~ `[화면 중앙 + 100px]` 지점을 차지하게 됩니다.
  - 그 결과 모달이 **정확히 화면 중앙에서 좌측으로 100px만큼 치우치게 보이는 것**입니다.

> **💡 해결 방안**: 5공정에서 TSX의 `width` 기준값을 `400px`로 수정하면 X좌표가 `화면 중앙 - 200px`가 되어, 모달이 `[화면 중앙 - 200px]` ~ `[화면 중앙 + 200px]`에 안착하며 **완벽한 좌우 정중앙 정렬**이 완성됩니다.

## 🔍 [문제 2] 상단 4개 버튼("출석", "추천", "가맹점", "프로필 설정") 글자 잘림 및 오버플로우 이유

### 1. 현상 분석 (1번 이미지 스크린샷 증명)
- 상단 4개 버튼 중 4번째 `🔑 프로필 설정` 버튼의 텍스트가 버튼 박스를 뚫고 모달 우측 경계 밖으로 튀어나가 절반 이상 잘리는 현상이 발생하고 있습니다.

### 2. 수치적 발생 원인
- 모달 전체 폭이 `400px`일 때, 내부 양쪽 패딩(`15px × 2 = 30px`)을 제외하면 버튼들이 사용할 수 있는 실제 가로 폭은 **`370px`**입니다.
- 370px를 4개 버튼으로 나눌 때(버튼 간 갭 8px × 3 = 24px 제외), **버튼 1개가 가질 수 있는 최대 폭은 불과 `86.5px`**에 불과합니다.
- `86.5px`라는 극소 폭 안에서 아이콘(`🔑`) + 글자(`프로필 설정` 5글자, `가맹점 등록 보너스` 8글자)를 한 줄(`white-space: nowrap`)로 나란히 밀어 넣다 보니, **버튼 박스 가로 폭을 넘어서서 모달 오른쪽 밖으로 텍스트가 잘려나가는 결함**이 생겼습니다.

### 3. 근본적 해결 대안 구조 (버튼 글자 잘림 100% 원천 차단)
단순히 가로 한 줄에 글자를 억지로 밀어 넣는 방식으로는 86.5px 폭을 극복할 수 없습니다. 따라서 아래 **2가지 대안 중 하나로 보정**해야 합니다:

- **[대안 A: 상하(수직) 배치 전환 (추천)]**
  - 버튼 내부 아이콘을 위, 텍스트를 아래로 배치 (`flex-direction: column; align-items: center; gap: 2px;`)하고 폰트를 `0.68rem`으로 조정하여 86.5px 폭 안에서도 글자가 절대 잘리지 않도록 정돈.
- **[대안 B: 2×2 반응형 그리드 배치]**
  - 1행 4열 대신 `[출석 보너스 | 추천 보너스]` (1행), `[가맹점 등록 | 프로필 설정]` (2행) 2×2 배치로 전환하여 각 버튼 폭을 `180px`로 넉넉하게 확보.

## 🔍 [문제 1] 마이닝 모달이 정중앙이 아니고 좌측으로 100px 쏠린 이유

### 1. 현상 분석 (1번 이미지 스크린샷 증명)
- 스크린샷을 보시면 마이닝 모달이 화면 세로 높이는 맞으나, **화면 좌측으로 약 100px 정도 쏠려서 배치**되어 있습니다.

### 2. 기술적/수학적 발생 원인
- 4공정에서 CSS([`MiningStatusModal.css`](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/src/components/MiningStatusModal/MiningStatusModal.css))의 모달 폭을 `400px`로 먼저 축소 적용했습니다.
- 그러나 위치 계산을 담당하는 TSX([`MiningStatusModal.tsx`](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/src/components/MiningStatusModal/MiningStatusModal.tsx))는 아직 5공정이 적용되기 전이어서 **기존 600px 기준 공식**인 `const width = 600; const x = (window.innerWidth - 600) / 2;`로 X좌표를 계산하고 있었습니다.
- **수학적 쏠림 증명**:
  - 모달의 시작 위치(Left)가 `화면 중앙 - 300px` 지점으로 잡힙니다.
  - 모달 실제 폭이 400px이므로, 모달 영역은 `[화면 중앙 - 300px]` ~ `[화면 중앙 + 100px]` 지점을 차지하게 됩니다.
  - 그 결과 모달이 **정확히 화면 중앙에서 좌측으로 100px만큼 치우치게 보이는 것**입니다.

> **💡 해결 방안**: 5공정에서 TSX의 `width` 기준값을 `400px`로 수정하면 X좌표가 `화면 중앙 - 200px`가 되어, 모달이 `[화면 중앙 - 200px]` ~ `[화면 중앙 + 200px]`에 안착하며 **완벽한 좌우 정중앙 정렬**이 완성됩니다.

## 🔍 [문제 2] 상단 4개 버튼("출석", "추천", "가맹점", "프로필 설정") 글자 잘림 및 오버플로우 이유

### 1. 현상 분석 (1번 이미지 스크린샷 증명)
- 상단 4개 버튼 중 4번째 `🔑 프로필 설정` 버튼의 텍스트가 버튼 박스를 뚫고 모달 우측 경계 밖으로 튀어나가 절반 이상 잘리는 현상이 발생하고 있습니다.

### 2. 수치적 발생 원인
- 모달 전체 폭이 `400px`일 때, 내부 양쪽 패딩(`15px × 2 = 30px`)을 제외하면 버튼들이 사용할 수 있는 실제 가로 폭은 **`370px`**입니다.
- 370px를 4개 버튼으로 나눌 때(버튼 간 갭 8px × 3 = 24px 제외), **버튼 1개가 가질 수 있는 최대 폭은 불과 `86.5px`**에 불과합니다.
- `86.5px`라는 극소 폭 안에서 아이콘(`🔑`) + 글자(`프로필 설정` 5글자, `가맹점 등록 보너스` 8글자)를 한 줄(`white-space: nowrap`)로 나란히 밀어 넣다 보니, **버튼 박스 가로 폭을 넘어서서 모달 오른쪽 밖으로 텍스트가 잘려나가는 결함**이 생겼습니다.

### 3. 근본적 해결 대안 구조 (버튼 글자 잘림 100% 원천 차단)
단순히 가로 한 줄에 글자를 억지로 밀어 넣는 방식으로는 86.5px 폭을 극복할 수 없습니다. 따라서 아래 **2가지 대안 중 하나로 보정**해야 합니다:

- **[대안 A: 상하(수직) 배치 전환 (추천)]**
  - 버튼 내부 아이콘을 위, 텍스트를 아래로 배치 (`flex-direction: column; align-items: center; gap: 2px;`)하고 폰트를 `0.68rem`으로 조정하여 86.5px 폭 안에서도 글자가 절대 잘리지 않도록 정돈.
- **[대안 B: 2×2 반응형 그리드 배치]**
  - 1행 4열 대신 `[출석 보너스 | 추천 보너스]` (1행), `[가맹점 등록 | 프로필 설정]` (2행) 2×2 배치로 전환하여 각 버튼 폭을 `180px`로 넉넉하게 확보.
