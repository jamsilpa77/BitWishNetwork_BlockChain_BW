# 📋 BitWish Network 모달 팝업 레이아웃 및 스크롤 UX 개선 분석 보고서

## 1. 현재 발생 중인 2대 핵심 문제점 분석

### 🚨 [문제 1] 모달 창의 과도한 비대함으로 인한 UI 둔탁화 (Visual Bloat)
* **현상**:
  - 데스크톱 화면에서 `MyWalletModal`(나의 지갑)과 `MiningStatusModal`(마이닝 현황)이 모니터 화면의 절반 이상을 거대하게 가로막아 시각적으로 매우 답답하고 허접해 보이는 현상이 발생함.
  - 모달의 가로 폭(`width`) 및 세로 높이가 과도하게 크게 설정되어 있고, 내부 카드 및 폰트 여백(Padding)이 넓어 하이테크 블록체인 지갑 본연의 슬림하고 정교한 맛이 사라짐.
  - 창 자체가 비대하다 보니, 상단 바를 마우스로 잡고 이동(드래그)시킬 때 둔탁하고 화면 전체가 흔들리는 듯한 무거운 느낌을 줌.

---

### 🚨 [문제 2] 모달 오픈 시 배경 휠 스크롤 간섭 현상 (Background Scroll Bleed)
* **현상**:
  - 지갑이나 마이닝 모달이 켜져 있는 상태에서 사용자가 지갑 내부나 바깥쪽을 마우스 휠로 스크롤할 때, **모달 창은 제자리에 고정(`fixed`)되어 있고 뒤쪽 메인 홈페이지 화면만 위아래로 덜컥거리며 움직이는 현상**이 발생함.
  - 이는 모달 팝업이 활성화되었을 때 메인 브라우저의 배경 스크롤을 잠그는 `Body Scroll Lock` 처리(`document.body.style.overflow = 'hidden'`)가 빠져 있어 발생하는 전형적인 UX 레이어 결함입니다.

---

## 2. 문제 해결을 위한 초정밀 개선 수복 방안

이 두 가지 문제점을 완벽히 수복하여 고급스럽고 현대적인 메인넷 지갑 UX를 완성하기 위한 기술적 표준 해결 공정입니다.

---

### 🛠️ [개선책 1] 슬림 & 하이테크 컴팩트 팝업 비율로 규격 축소

1. **`MyWalletModal` (나의 지갑 모달) 규격 최적화**:
   - 기존의 거대한 폭(약 850px~900px)을 **최적의 680px ~ 720px 슬림 사이즈**로 축소.
   - 잔액 카드, 추천 보너스 카드, 송금/수신 버튼의 여백과 폰트 크기를 12~15% 조여 한눈에 쏙 들어오는 명품 블록체인 지갑 UI로 리사이징.

2. **`MiningStatusModal` (마이닝 현황 모달) 규격 최적화**:
   - 기존 폭을 **540px ~ 580px 컴팩트 규격**으로 축소.
   - 중앙에 한눈에 쏙 들어오도록 정돈하여 드래그 시에도 매우 가볍고 부드럽게 이동되도록 개선.

---

### 🛠️ [개선책 2] 배경 스크롤 완전 차단 (Body Scroll Lock) 적용

1. **배경 스크롤 잠금 회로 주입**:
   - `MyWalletModal` 및 `MiningStatusModal`이 열릴 때(`isOpen === true`), 브라우저 전체 배경의 스크롤을 강제로 일시 정지시킵니다:
     ```typescript
     useEffect(() => {
         if (isOpen) {
             document.body.style.overflow = 'hidden'; // 배경 스크롤 완전 잠금
         } else {
             document.body.style.overflow = 'unset';  // 모달 닫히면 원복
         }
         return () => {
             document.body.style.overflow = 'unset';
         };
     }, [isOpen]);
     ```
   - 이 처리를 적용하면 모달이 열려 있을 때 마우스 휠을 아무리 돌려도 **뒤쪽 홈페이지가 덜컥거리며 따로 움직이는 현상이 100% 완벽하게 차단**됩니다.

---

### 🛠️ [개선책 3] 딥 블루 하이테크 오버레이 & 블러(Blur) 효과 강화

- 모달 뒤쪽 메인 홈페이지 배경에 은은한 딥 블루 다크 투명 오버레이(`rgba(15, 23, 42, 0.75)`)와 고급스러운 유리 질감의 `backdrop-filter: blur(12px)`를 적용.
- 모달과 메인 화면 간의 시각적 공간 분리감을 확실히 주어, 지갑 모달이 한층 더 입체적이고 전자기기 앱처럼 세련되게 보이도록 개선합니다.

### 🚨 [문제 1] 강렬한 헤더 배경과 파편화된 상단 요소
- **현상**:
  - 상단의 강렬한 파란-보라 글래디언트 배경(`나의 지갑` 타이틀 영역)이 지나치게 강렬하여 사용자의 시선을 부자연스럽게 빼앗음.
  - 헤더 내부에 `나의 지갑` 제목, `🟢 활성` 배지, `로그아웃` 버튼, `🔄` 새로고침 버튼, `지갑 주소`, `주소복사`, `⛏ 마이닝 시작` 버튼 등 **총 7개 이상의 상이한 요소를 한 공간에 밀어 넣어 극심한 산만함**을 유발함.

### 🚨 [문제 2] 6개 탭 메뉴의 밋밋함과 시각적 구분 부족
- **현상**:
  - `개요`, `거래내역`, `채굴 보상 내역`, `추천 보너스 내역`, `블록 트랜잭션`, `설정` 6개 탭이 좁은 영역에 텍스트만 밋밋하게 늘어서 있어, 사용자가 현재 어느 탭을 보고 있는지 한눈에 들어오지 않음.

### 🚨 [문제 3] 2대 카드(잔액 & 추천 보너스)의 공간 낭비 및 둔탁함
- **현상**:
  - **잔액 카드**: `0.00000000 BW` 수치 표시는 큰데 단위(`BW`)가 어색하게 겹쳐 보임. 그 아래 분홍색(`실시간 마이닝 보사의...`) 및 하늘색 안내 박스가 카드 면적의 절반 이상을 가로막아 화면이 조잡해 보임.
  - **추천 보너스 카드**: 하늘색 `추천인 코드: REF9F5FF0090DC5` 박스가 혼자 뜬금없는 색상으로 떠 있어 지갑 전체 톤앤매너와 어울리지 않음.

### 🚨 [문제 4] 하단 2x2 버튼군의 색상 무지개화 (Visual Weight Collapse)
- **현상**:
  - `↓ 송금받기 ↓` (파란색), `↑ 송금하기 ↑` (빨간색), `🔑 OTP 설정` (보라색), `🛡️ KYC 인증...` (주황색) 버튼이 파랑/빨강/보라/주황 원색으로 난잡하게 튀어 뜸.
  - 모든 버튼이 똑같은 크기와 강렬한 원색을 사용하여, **사용자가 가장 자주 쓰는 [송금/수신]이 무엇인지, 보조 기능인 [OTP/KYC]가 무엇인지 시각적 우선순위가 전혀 구분되지 않음.**

### 🚨 [문제 5] 지갑 주소 영역의 불필요한 중복 표출
- **현상**:
  - 상단 헤더에서도 `지갑 주소: BW9F5F...`를 보여주는데, 하단 영역에서도 열쇠 아이콘과 함께 거대한 박스로 `BW9F5FF090231...` 전체 주소를 또 보여줌.
  - 동일한 지갑 주소가 모달 하나에 **두 번 중복 표출**되어 세로 공간만 무의미하게 가로막고 모달을 둔하게 만듦.

### 4) 🚨 [문제 4] 하단 3개 버튼의 모호한 우선순위
- **현상**:
  - `⚡ 마이닝 시작` (보라), `🔑 나의 지갑` (청록), `❌ 닫기` (어두운 회색) 버튼 중, 사용자가 가장 핵심으로 눌러야 하는 **[마이닝 시작]** 버튼이 차별화되어 강조되지 않음.

## 3. 초정밀 UI/UX 대개조 종합 수복 설계안

단순히 모달 껍데기 크기만 줄이는 것이 아니라, **내부의 텍스트, 버튼, 카드, 탭, 색상을 블록체인 메인넷 수준에 맞게 완벽히 재설계**합니다.

---

### 🎨 [대개조 1] `MyWalletModal` 디테일 디자인 체계 수복

1. **헤더 & 주소 바 슬림화 및 정돈**:
   - 헤더의 강렬한 보라색 배경을 **심플하고 절제된 딥 다크 인디고 톤**으로 교체.
   - 불필요한 하단 지갑 주소 중복 박스를 삭제하고, 상단 헤더에 깔끔한 **클립보드 복사 아이콘이 포함된 주소 배지 1개로 통합**.

2. **탭 메뉴 타이포그래피 강화**:
   - 활성화된 탭에는 **하이테크 인디고 네온 하단 라인**과 볼드 폰트를 적용하고, 비활성 탭은 톤다운하여 현재 위치를 1초 만에 파악하도록 정돈.

3. **잔액 & 보너스 카드 모던화**:
   - 소수점 8자리 수치(`0.00000000`)에 **가독성 높은 모노스페이스(Monospace) 폰트**를 적용하여 칼같이 정렬.
   - 조잡하게 면적을 차지하던 핑크/블루 안내 박스를 **은은한 마이크로 툴팁 메시지**로 슬림화하여 카드 내부 답답함 제거.

4. **하단 버튼군 버튼 가중치(Visual Priority) 재정립**:
   - **1차 주요 기능 [송금 / 수신]**: 눈에 가장 잘 띄는 **프라이머리 입체 블루 버튼**으로 전면 배치.
   - **2차 보조 기능 [OTP 설정 / KYC 신청]**: 톤다운된 **세컨더리 엠보싱 메탈 버튼**으로 전환하여 4개 버튼의 난잡한 원색 충돌 해결.

---

### 🎨 [대개조 2] `MiningStatusModal` 디테일 디자인 체계 수복

1. **상단 4대 퀵 버튼 톤앤매너 통일**:
   - 알록달록한 장난감 파스텔 색상을 제거하고, **고급스러운 메탈릭 다크 칩(Badge)** 형태로 통합.
   - `Logout` 영어를 다국어 엔진과 연동된 일관된 텍스트로 수정.

2. **채굴 상태 그리드 대시보드화**:
   - 빽빽했던 2열 문자를 **[기본 채굴률 / 출석 보너스 / 추천 보너스 / 최종 연산 보상률]** 의 계층 구조 표(Card Metric)로 재배치.
   - `OFF`, `미등록` 같은 빨간 글자를 **신호등 라이브 배지(`🟢 ON`, `⚪ 미등록`)** 로 바꿔 직관성 대폭 향상.

3. **실시간 누적 보상 박스 동적 라이브화**:
   - 1초 단위 실시간 채굴 시 숫자 주변에 은은한 **네온 펄스 링(Neon Pulse Ring) 애니메이션**을 추가하여 활발히 채굴 중임을 직관적으로 체감하게 개선.

4. **하단 3종 버튼 시각 강조 정립**:
   - **[⚡ 마이닝 시작]** 버튼을 모달 전체에서 가장 돋보이는 **메인 액션 글로우 버튼**으로 격상하고, [나의 지갑] 및 [닫기]는 깔끔한 서브 버튼으로 정돈.

## 🛠️ [1단계] 모달 외곽 레이아웃 규격 축소 & 배경 스크롤 잠금 엔진 설치

### 1-1. 배경 스크롤 잠금 (Body Scroll Lock) 회로 수술
- **작업 내용**:
  - `MyWalletModal.tsx` 및 `MiningStatusModal.tsx` 모달 컴포넌트의 `useEffect` 생명주기에 `document.body.style.overflow` 제어 로직을 주입.
  - `isOpen === true` 시 `document.body.style.overflow = 'hidden'`을 실행하여 뒤쪽 메인 홈페이지의 마우스 휠 스크롤을 100% 완전히 고정/잠금.
  - `isOpen === false` 또는 컴포넌트 언마운트 시 `document.body.style.overflow = 'unset'`으로 원복하여 휠 스크롤 간섭 버그 차단.

### 1-2. `MyWalletModal` 팝업 껍데기 규격 슬림화
- **작업 내용**:

### 1-4. 오버레이 백드롭 블러(Backdrop Blur) 효과 고급화
