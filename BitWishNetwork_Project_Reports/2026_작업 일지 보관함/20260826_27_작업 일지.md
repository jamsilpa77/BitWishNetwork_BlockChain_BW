* **실패 이유**: 모바일 스마트폰(아이폰, 갤럭시 등 모바일 크롬 브라우저)은 상하단 주소창 크기가 유동적으로 변합니다.
* 이전 개발자는 모달 최상위 컨테이너에 모바일 전용 `inset: 0; margin: auto; width: calc(100vw - 32px); box-sizing: border-box;`와 같은 모바일 뷰포트 밀착 고정 공정을 전혀 적용하지 않고, PC 기준의 `position: fixed`와 `max-width: 95%`만 유지했습니다. 이로 인해 모바일 스마트폰에 들어가는 순간 모달 창 전체가 **우측 상단으로 밀려나 반의 반토막(1/4 크기)만 보이는 치명적 렌더링 붕괴**가 지속된 것입니다.

## 1. ⛏️ 마이닝 시스템 전체 개발 상황 파악 (`repopack-output.txt` 분석)

[repopack-output.txt](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/repopack-output.txt) 소스 코드 통화 합본 파일을 바탕으로 검증한 마이닝 시스템의 구체적인 개발 상황은 다음과 같습니다.

1. **프론트엔드 및 UI 시스템**:
   - **핵심 컴포넌트**: `HomePage`, `MiningPage`, `MiningStatusModal`, `MyWalletModal`, `ExplorerPage`, `BWCommunityWindow` 등 프론트엔드 전체 UI 모듈이 구축되어 있습니다.
   - **정밀 연산 연동**: `Decimal.js` (50자리 정밀 연산) 기반의 [PrecisionCalculator.ts](file:///c:/BitWishNetwork_BlockChainMainnet/BitWishNetwork_MiningSystem/src/utils/PrecisionCalculator/PrecisionCalculator.ts)와 연동되어 UI 상에서는 8자리 소수점으로 채굴 보상이 정확히 계산 및 표시됩니다.
   - **다국어 및 상태 관리**: `LanguageManager`를 통해 한국어 포함 12개 국어가 지원되며 `RealTimeSyncService`를 통해 1초 단위 마이닝 상태 모니터링이 작동 중입니다.

2. **백엔드 및 데이터베이스 시스템**:
   - **서버 및 API**: Node.js / Express 기반 Express 라우터 (`/api/mining`, `/api/referral`, `/api/attendance`, `/api/user` 등)와 TypeScript 컨트롤러가 세팅되어 있습니다.
   - **보너스 중첩 수식**: 출석 보너스, 추천 보너스(6%), 가맹점 보너스가 곱셈 중첩 방식으로 연산되도록 서버 컨트롤러 및 서비스 로직이 구현되어 있습니다.
   - **MongoDB 스키마**: `MiningState`, `BonusRecord`, `User`, `Transaction` 등 회원 상태 및 마이닝 이력을 보존하는 DB 데이터 스키마가 완비되어 있습니다.

## 2. 📱 GitHub 푸시 전, 핸드폰(스마트폰)으로 로컬 개발 서버 접속하여 사전 확인하는 방법

Vultr 서버 배포나 GitHub 커밋/푸시 전에, 현재 개발 중인 컴퓨터의 화면을 **대표님 스마트폰으로 직접 접속하여 눈으로 먼저 확인하는 2가지 방법**을 정밀하게 알려드립니다.

---

### 🔹 [방법 1] 동일한 Wi-Fi (공유기) 네트워크 접속 방식 (가장 간편한 방법)

컴퓨터와 스마트폰이 **동일한 Wi-Fi (또는 동일한 공유기)**에 연결되어 있을 때 사용하는 방법입니다.

1. **PC의 내부 IP 주소 확인**:
   - PC의 `명령 프롬프트(cmd)` 또는 PowerShell을 열어 `ipconfig` 명령어 입력.
   - `IPv4 주소` 항목의 4자리 숫자 확인 (예: `192.168.0.15` 또는 `192.168.1.100`).

2. **개발 서버 실행 및 포트 확인**:
   - 현재 마이닝 시스템 프론트엔드 개발 서버가 실행 중인 포트 확인 (기본값: `3000`번 또는 `8080`번 포트).

3. **스마트폰으로 접속**:
   - 대표님 스마트폰의 웹 브라우저(크롬, 사파리 등)를 엽니다.
   - 주소창에 아래와 같이 입력하여 접속합니다:
     ```text
     http://<PC의 IPv4 주소>:<포트번호>
     예시: http://192.168.0.15:3000
     ```

---

### 🔹 [방법 2] IDE / VS Code 포트 포워딩(Port Forwarding) 기능 활용 방식 (어디서나 접속 가능)

동일한 Wi-Fi가 아니거나 LTE/5G 모바일 데이터 환경에서도 스마트폰으로 바로 접속할 수 있는 가장 확실한 외부 테스트 주소 생성 방법입니다.

1. **VS Code 하단 [PORTS (포트)] 탭 클릭**:
   - 개발 에디터(VS Code / Antigravity IDE) 하단 터미널 옆의 **`PORTS` (포트)** 탭을 선택합니다.

2. **포트 추가 (Forward a Port)**:
   - `+ Forward a Port` 버튼을 누르고 개발 서버 포트 번호(`3000`)를 입력합니다.

3. **접속 권한을 Public(공개)으로 변경**:
   - 포워딩된 `3000` 포트 항목에서 `Visibility` 속성을 마우스 우클릭하여 **`Public`**으로 전환합니다.

4. **생성된 URL 주소로 스마트폰 접속**:
   - `Forwarded Address`에 생성된 인터넷 전용 주소(예: `https://xxxx-3000.app.github.dev` 또는 `https://xxxx.devtunnels.ms`)를 스마트폰 카카오톡이나 브라우저에 입력하여 접속하면 **실제 스마트폰에서 최적화된 마이닝 모달과 익스플로러 화면을 즉시 확인**하실 수 있습니다.

## 2. 🚀 Vultr 서버 라이브 배포 명령어 (Vultr 콘솔 실행용)

```bash
# 1. GitHub 최신 수복 코드 다운로드
git pull origin main

# 2. 빌드 실행 및 정적 웹사이트 경로 복사
npm run build && cp -r dist/* /var/www/html/

# 3. Nginx 웹서버 설정 재로드
systemctl reload nginx
```
