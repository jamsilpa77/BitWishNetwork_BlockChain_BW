## 1. 실시간 랭킹 산출 엔진 (`RankingService.ts`)

### 1.1 LiveBoost 실시간 가산 및 O(log N) 파이프라인
BitWish 랭킹 시스템은 정적 DB 값에 머무르지 않고, 유저가 마이닝 중일 때 마지막 동기화 시각부터 현재까지의 실시간 증분량(LiveBoost)을 가산하여 진정한 실시간 순위를 산출합니다.

$$\text{LiveTotal} = \text{accumulatedReward} + \left( \frac{\text{currentTotalRate}}{3600} \right) \times (\text{now} - \text{lastSyncTime})$$

- 상위 100위(Top 100) 랭킹을 10초 주기 인메모리 캐싱하여 DB 부하를 원천 방지합니다.
- 결정론적 Tie-breaking: 동점자 발생 시 `miningStartTime`이 빠른 유저, 그래도 동일할 경우 `walletAddress`의 사전순(Lexicographical order)으로 순위를 확정합니다.

## 2. 블록체인 익스플로러 검색 엔진 (`ExplorerPage.tsx`)

### 2.1 다중 색인 검색 파이프라인
단일 통합 검색창을 통해 4가지 형태의 쿼리를 지능적으로 식별하여 즉시 라우팅합니다:
1. **정수 쿼리 (`^\d+$`)**: 블록 인덱스(Block Height) 검색 -> 해당 블록 세부 정보 표출
2. **64자리 16진수 (`^[0-9a-fA-F]{64}$`)**:
   - 블록 해시 검색 우선 조회
   - 미발견 시 트랜잭션 해시(TX ID) 대조 조회
3. **BW 주소 (`^BW[0-9a-zA-Z]{40,64}$`)**: 지갑 주소 계좌 검색 -> 보유 잔고, 누적 채굴량, 참여 블록, 송수신 이력 표출
4. **미인식 쿼리**: 유사 주소 또는 최신 블록 추천 피드백 제공
