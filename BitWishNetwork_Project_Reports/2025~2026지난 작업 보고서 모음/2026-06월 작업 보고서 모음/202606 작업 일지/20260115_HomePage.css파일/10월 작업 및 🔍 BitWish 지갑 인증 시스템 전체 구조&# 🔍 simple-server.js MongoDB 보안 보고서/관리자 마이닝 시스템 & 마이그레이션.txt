**마이닝 시스템 & 마이그레이션션**
"마이닝 시작" 버튼 클릭하면 영구적으로 멈춤없이 사업이 망하고 서버가 닫히는 날까지 멈추지 않는다.(설명일뿐 적시하지 않는다.)

**"마이닝 시작" 버튼 클릭하면:
1. 마이닝 시작: 마이닝 정지 버튼 클릭 전에는 절대 마이닝 시작은 멈추지 않고 설정된 기본 채굴 보상으로 가상 BW를 실시간 채굴한다.
2. 마이닝 정징: 마이닝 정지 버튼 클릭하면 실시간 채굴하던 총 채굴량과 마이닝 시간과 헤시레이트는 증시 반영됐던 수치 그대로 일시 정지하고, 다시 마이닝 시작 버튼 클릭하면 그대로 이어서 채굴 시작된다.

3. 마이닝 기본 보상: 기본 채굴률 = 시간당 0.25BW, 일일 보상 = 6BW

4, 유저/관리자 마이닝 페이지 중 유저는 개개인의 회원들은 2번 마이닝 기본 보상이 설정된 마이닝 페이지를 가지게 된다.
4-1. 유저/관리자 중 관리자는 2번 마이닝 기본 보상이 설정된 마이닝 페이지를 가지며 완벽하게 독립되어 블록체인과 지갑과 모든 관계를 끊고 완벽하게 마이닝 페이지로만 사용되는 테스트 기능을 하게된다.

5. 유저 개개인 회원들 마이닝 페이지는 완벽한 개인 소유이며 마이닝 시작 시에는 개인의 BW채굴 보상이 "총 채굴량"에 실시간 누적되며 영원히 누적된다.
5-1 관리자 마이닝 페이지는 완벽하게 독립되어 관리자 마이닝 페이지테스트로 운영되고 저장되며 마이닝 페이지 그 어떤 경우에도 블록체인과 지갑과는 연결되지 않는다.

6. 유저/관리자 마이닝 페이지는 BW채굴은 실제 BW네트워크 블록체인 실제 토큰이 아니며 가상 BW를 채굴하는 마이닝 페이지이다.
