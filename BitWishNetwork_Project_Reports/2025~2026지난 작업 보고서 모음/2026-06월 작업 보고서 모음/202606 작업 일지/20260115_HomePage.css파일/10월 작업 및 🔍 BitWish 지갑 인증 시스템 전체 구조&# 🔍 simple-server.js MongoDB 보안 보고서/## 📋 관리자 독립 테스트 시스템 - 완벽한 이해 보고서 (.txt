```
┌──────────────────────────────────────────────────────┐
│  ⚠️  절대적 원칙 (ABSOLUTE RULES)                    │
├──────────────────────────────────────────────────────┤
│  1. 관리자 테스트 ≠ 유저 데이터                      │
│  2. 관리자 전용 주소로만 작동                         │

```

### **🔧 관리자 설정창 기능 (완벽한 독립 테스트):**

---

#### **1️⃣ 출석 보너스 테스트 (Attendance Test Control)**

| 기능 | 설명 | 대상 |
|------|------|------|
| **강제 출석** | 관리자 주소만 즉시 출석 처리 | ✅ `BW2E45DA460B70E2BFE25D3E6B8070593A4107A540` 만 |
| **보너스 적용** | 관리자 주소만 5% 보너스 활성화 | ✅ `BW2E45DA460B70E2BFE25D3E6B8070593A4107A540` 만 |
| **보너스 해제** | 관리자 주소만 5% 보너스 비활성화 | ✅ `BW2E45DA460B70E2BFE25D3E6B8070593A4107A540` 만 |

**API:**
```javascript
// 관리자 전용 - 자신의 데이터만 수정
POST /api/admin/test/attendance/force-check
{
  walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540"  // 고정!
}

// MongoDB 쿼리:
await collection.updateOne(
  { 
    walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540",
    userType: "admin"  // ← 절대적 필터
  },
  { $set: { "miningBreakdown.attendance.isCheckedToday": true } }
);
```

---

#### **2️⃣ 추천인 보너스 테스트 (Referral Test Control)**

| 기능 | 설명 | 대상 |
|------|------|------|
| **추천인 추가** | 테스트용 가상 추천인 관계 생성 | ✅ 관리자 주소만 |
| **보상 지급** | 테스트용 1BW + 2% 보너스 지급 | ✅ 관리자 주소만 |
| **보너스 적용** | 테스트용 2% 영구 보너스 활성화 | ✅ 관리자 주소만 |
| **전체 해제** | 테스트 데이터 삭제 | ✅ 관리자 주소만 |

**API:**
```javascript
// 관리자 테스트 전용
POST /api/admin/test/referral/add
{
  adminWallet: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540",  // 고정!
  testReferralAddress: "BW_TEST_REFERRAL_001"  // 테스트용 가상 주소
}

// MongoDB: 관리자 주소에만 테스트 데이터 추가
await collection.updateOne(
  { 
    walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540",
    userType: "admin"
  },
  { $inc: { "miningBreakdown.referralPermanent.activeReferrals": 1 } }
);
```

#### **3️⃣ 마이닝 제어 (Mining Test Control)**

| 기능 | 설명 | 대상 |
|------|------|------|
| **마이닝 정지** | 관리자 테스트 마이닝 정지 + 결과 출력 | ✅ 관리자 주소만 |
| **마이닝 초기화** | 관리자 테스트 데이터 완전 리셋 | ✅ 관리자 주소만 |

**API:**
```javascript
// 관리자 테스트 정지
POST /api/admin/test/mining/stop
{
  walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540"
}

// 관리자 테스트 초기화
POST /api/admin/test/mining/reset
{
  walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540"
}

// MongoDB: 관리자 데이터만 초기화
await collection.updateOne(
  { 
    walletAddress: "BW2E45DA460B70E2BFE25D3E6B8070593A4107A540",
    userType: "admin"
  },
  { 
    $set: { 
      totalMined: { amount: "0.00000000000000000000000000000000000000000000000000" },
      miningStatus: { isActive: false },
      miningBreakdown: { /* 모든 값 0으로 */ }
    } 
  }
);
```

### **✅ 절대 준수사항:**

| 항목 | 관리자 테스트 | 유저 실제 |
|------|--------------|-----------|
| **지갑 주소** | `BW2E45DA460B70E2BFE25D3E6B8070593A4107A540` (고정) | 홈페이지 로그인 주소 |
| **userType** | `admin` | `user` |
| **데이터베이스** | `admin_user_mining_data` (admin 필터) | `admin_user_mining_data` (user 필터) |
| **API 접근** | `/api/admin/test/*` | `/api/admin/bitwish/*` |
| **데이터 공유** | ❌ **절대 없음** | ❌ **절대 없음** |
| **초기화** | ✅ 언제든지 가능 | ❌ 불가능 |
| **목적** | 테스트 → 검증 → 코드 업데이트 | 실제 유저 마이닝 |

```

   └─> 설정창에서 출석/추천인 강제 설정
   └─> 마이닝 시작
   └─> 계산 로직 테스트
   └─> 마이닝 정지
   └─> 50자리 정밀도 결과 확인
   └─> 초기화 버튼으로 데이터 리셋

2️⃣ 코드 검증 완료:
   └─> 유저 페이지/API 코드 업데이트
   └─> 유저는 완벽하게 검증된 로직만 사용

3️⃣ 데이터 분리:
   └─> 관리자 테스트 데이터 (userType: 'admin')
   └─> 유저 실제 데이터 (userType: 'user')
   └─> ❌ 절대 섞이지 않음!
```
