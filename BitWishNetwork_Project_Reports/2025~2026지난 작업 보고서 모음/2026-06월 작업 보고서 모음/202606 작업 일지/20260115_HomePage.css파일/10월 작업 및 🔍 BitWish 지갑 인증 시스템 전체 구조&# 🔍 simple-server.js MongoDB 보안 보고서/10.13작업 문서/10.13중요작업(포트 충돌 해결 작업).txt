## 🎯 **문제 상황**
```
Error: listen EADDRINUSE: address already in use :::4001
```

**원인**: 백그라운드에서 Node.js 프로세스가 포트 4001을 계속 점유하고 있음

---

## 💡 **해결 방법 (2가지 옵션)**

### **옵션 1: 포트 점유 프로세스 강제 종료 (권장 ✅)**

#### **1단계: 모든 Node.js 프로세스 종료**
```powershell
taskkill /F /IM node.exe
```
- `/F`: 강제 종료
- `/IM node.exe`: node.exe 프로세스 모두 종료

#### **2단계: 3초 대기**
```powershell
Start-Sleep -Seconds 3
```
- 프로세스가 완전히 종료될 때까지 대기

#### **3단계: 포트 해제 확인**
```powershell
netstat -ano | findstr ":4001"
```
- 결과가 없으면 → 포트 해제 완료 ✅
- 결과가 있으면 → PID 확인 후 개별 종료

#### **4단계: 서버 재시작**
```powershell
cd Node_HomePage
node simple-server.cjs
```

---

### **옵션 2: 포트 번호 변경 (대안)**

#### **변경할 위치**
```javascript
// simple-server.cjs 4916줄
const PORT = process.env.PORT || 4001;  // ← 이 부분

// 변경 예시
const PORT = process.env.PORT || 4002;  // ← 4002로 변경
```

**장점**: 기존 프로세스와 충돌 없음  
**단점**: 프론트엔드 API URL도 함께 변경 필요
