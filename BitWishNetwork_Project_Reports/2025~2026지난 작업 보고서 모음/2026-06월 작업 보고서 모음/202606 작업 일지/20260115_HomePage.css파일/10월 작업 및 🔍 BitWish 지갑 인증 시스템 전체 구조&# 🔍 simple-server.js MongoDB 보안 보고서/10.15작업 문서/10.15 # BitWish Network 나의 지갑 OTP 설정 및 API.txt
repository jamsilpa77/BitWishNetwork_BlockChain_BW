# BitWish Network "나의 지갑" OTP 설정 및 API 404 오류 분석 보고서

## 📋 분석 개요

BitWish Network의 "나의 지갑" 페이지에서 발생하는 OTP 설정 문제와 API 404 오류에 대한 상세 분석을 수행했습니다.

## 🔍 발견된 주요 문제점

### 1. **API 엔드포인트 불일치 문제**

#### 문제 상황:
- **프론트엔드 호출**: `http://localhost:4001/bitwish/wallet/balance/{address}` (255번째 줄)
- **백엔드 실제 라우트**: `/api/bitwish/wallet/balance/:address` (2551번째 줄)

#### 근본 원인:
```typescript
// MyWalletPage.tsx:255 - 잘못된 API 경로
const balanceResponse = await fetch(`http://localhost:4001/bitwish/wallet/balance/${address}`);

// simple-server.cjs:2551 - 실제 백엔드 라우트
app.get('/api/bitwish/wallet/balance/:address', async (req, res) => {
```

**차이점**: 프론트엔드에서 `/api` 접두사가 누락되어 404 오류 발생

### 2. **OTP 설정 기능 분석**

#### OTP 설정 프로세스:
1. **시크릿 생성**: 프론트엔드에서 32자리 Base32 시크릿 생성
2. **QR 코드 생성**: `otpauth://` 프로토콜 사용
3. **2단계 검증**: 
   - 1단계: `/api/bitwish/wallet/otp/setup` (시크릿 저장)
   - 2단계: `/api/bitwish/wallet/otp/verify` (6자리 코드 검증)

#### OTP 관련 백엔드 라우트:
- ✅ `/api/bitwish/wallet/otp/setup` (4753번째 줄) - 존재
- ✅ `/api/bitwish/wallet/otp/verify` (4902번째 줄) - 존재

### 3. **추천 보너스 API 문제**

#### 문제 상황:
- **프론트엔드 호출**: `http://localhost:4001/api/admin/bitwish/referral/vault/{address}` (426번째 줄)
- **백엔드 실제 라우트**: `/api/admin/bitwish/referral/vault/:walletAddress` (7371번째 줄)

#### 근본 원인:
API 경로는 일치하지만, 백엔드에서 파라미터명이 `walletAddress`로 되어 있어 `address` 파라미터를 받지 못함

## 🚨 서버 상태 확인

### 포트 4001 상태:
```
TCP    0.0.0.0:4001           0.0.0.0:0              LISTENING
TCP    [::]:4001              [::]:0                 LISTENING
```
- ✅ 서버는 정상적으로 포트 4001에서 실행 중
- ✅ 여러 연결이 TIME_WAIT, FIN_WAIT_2 상태로 활성 연결 존재

## 📊 오류 로그 분석

### 콘솔에서 확인된 오류들:
1. **404 Not Found**: `/api/bitwish/wa...` 경로 오류
2. **SyntaxError**: HTML 응답을 JSON으로 파싱 시도
3. **지갑 동기화 실패**: `<!DOCTYPE html>` 응답으로 인한 JSON 파싱 오류

## 🔧 해결 방안

### 1. **즉시 수정 필요한 사항**

#### MyWalletPage.tsx 수정:
```typescript
// 255번째 줄 수정
// 기존: http://localhost:4001/bitwish/wallet/balance/${address}
// 수정: http://localhost:4001/api/bitwish/wallet/balance/${address}
const balanceResponse = await fetch(`http://localhost:4001/api/bitwish/wallet/balance/${address}`);
```

### 2. **OTP 설정 기능 상태**

#### 현재 상태:
- ✅ **백엔드 API**: 정상 구현됨
- ✅ **프론트엔드 로직**: 정상 구현됨
- ✅ **2FA 매니저**: 완전한 TOTP 구현 (BitWish2FAManager.cjs)

#### OTP 설정이 작동하지 않는 이유:
API 404 오류로 인해 지갑 정보 로드가 실패하여 OTP 설정 모달이 제대로 동작하지 않을 가능성

### 3. **추가 확인 사항**

#### 백엔드 라우트 파라미터 일치성:
```javascript
// simple-server.cjs:7371 - 파라미터명 확인 필요
app.get('/api/admin/bitwish/referral/vault/:walletAddress', async (req, res) => {
    const { walletAddress } = req.params; // address가 아닌 walletAddress
```

## 📈 영향도 평가

### 높은 영향도:
1. **지갑 잔액 조회 실패** - 사용자 경험 심각한 저하
2. **지갑 동기화 실패** - 실시간 데이터 업데이트 불가
3. **추천 보너스 조회 실패** - 수익 관련 기능 장애

### 중간 영향도:
1. **OTP 설정 지연** - 보안 기능 설정 지연 (API 수정 후 정상 작동 예상)

## 🎯 권장 조치사항

### 즉시 조치 (우선순위 1):
1. **MyWalletPage.tsx 255번째 줄 수정**: `/api` 접두사 추가
2. **백엔드 라우트 파라미터 일치성 확인**: `address` vs `walletAddress`

### 단기 조치 (우선순위 2):
1. **API 응답 형식 통일**: HTML 오류 페이지 대신 JSON 오류 응답
2. **오류 처리 개선**: 프론트엔드에서 404 오류 시 사용자 친화적 메시지

### 장기 조치 (우선순위 3):
1. **API 문서화**: 모든 엔드포인트의 정확한 경로와 파라미터 명시
2. **통합 테스트**: 프론트엔드-백엔드 API 호출 테스트 자동화

## 📋 결론

**주요 문제**: API 경로 불일치로 인한 404 오류가 핵심 원인
**OTP 설정 상태**: 백엔드와 프론트엔드 모두 정상 구현되어 있으나, API 오류로 인해 동작하지 않음
**해결 가능성**: 높음 (단순 경로 수정으로 대부분 해결 가능)

이 분석을 바탕으로 API 경로 수정을 통해 "나의 지갑" 페이지의 모든 기능이 정상 작동할 것으로 예상됩니다.
