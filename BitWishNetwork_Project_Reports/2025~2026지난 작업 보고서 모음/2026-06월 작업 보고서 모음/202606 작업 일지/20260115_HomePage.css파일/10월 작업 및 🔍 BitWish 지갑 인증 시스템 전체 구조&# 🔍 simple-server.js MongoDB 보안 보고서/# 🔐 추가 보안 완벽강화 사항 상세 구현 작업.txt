# 🔐 추가 보안 권장 사항 상세 설명

현재 `simple-server.js`는 **S+ 등급**의 보안을 갖추고 있지만, 프로덕션 환경에서 더욱 완벽한 보안을 위한 추가 권장 사항입니다:

---

## 1️⃣ **HTTPS 필수 적용**

### **현재 상황:**
- HTTP로 통신 중 (평문 전송)
- 네트워크 스니핑 공격에 취약

### **권장 구현:**

```javascript
// simple-server.js에 HTTPS 적용
const https = require('https');
const fs = require('fs');

// SSL 인증서 로드
const httpsOptions = {
  key: fs.readFileSync('path/to/private-key.pem'),
  cert: fs.readFileSync('path/to/certificate.pem')
};

// HTTPS 서버 생성
const server = https.createServer(httpsOptions, app);

server.listen(4001, () => {
  console.log('🔒 HTTPS 서버 시작: https://localhost:4001');
});
```
### **중요성:**
- ✅ 네트워크 전송 시 암호화
- ✅ 중간자 공격(MITM) 방어
- ✅ 해시된 비밀번호도 안전하게 전송

## 2️⃣ **클라이언트 측 해싱 강화**

### **현재 상황:**
- 클라이언트에서 이미 해싱 구현됨 (`BitWishWalletAuthModal.tsx`)
- 서버도 해싱 지원

### **권장 개선:**

```typescript
// Node_HomePage/src/utils/passwordHasher.ts (신규 파일)
import crypto from 'crypto';

export class ClientPasswordHasher {
  private static ITERATIONS = 100000;
  private static KEY_LENGTH = 64;
  
  // 클라이언트 측 PBKDF2 해싱
  static async hashPassword(password: string): Promise<string> {
    // 1. 랜덤 솔트 생성
    const salt = crypto.randomBytes(32).toString('hex');
    
    // 2. PBKDF2 해싱
    return new Promise((resolve, reject) => {
      crypto.pbkdf2(
        password,
        salt,
        this.ITERATIONS,
        this.KEY_LENGTH,
        'sha512',
        (err, derivedKey) => {
          if (err) reject(err);
          else resolve(`${salt}:${derivedKey.toString('hex')}`);
        }
      );
    });
  }
  
  // 추가: 비밀번호 강도 검증
  static validatePasswordStrength(password: string): {
    valid: boolean;
    score: number;
    feedback: string[];
  } {
    const feedback: string[] = [];
    let score = 0;
    
    // 길이 검증 (8자 이상)
    if (password.length >= 8) score += 1;
    else feedback.push('최소 8자 이상 필요합니다');
    
    // 대문자 포함
    if (/[A-Z]/.test(password)) score += 1;
    else feedback.push('대문자를 포함해야 합니다');
    
    // 소문자 포함
    if (/[a-z]/.test(password)) score += 1;
    else feedback.push('소문자를 포함해야 합니다');
    
    // 숫자 포함
    if (/[0-9]/.test(password)) score += 1;
    else feedback.push('숫자를 포함해야 합니다');
    
    // 특수문자 포함
    if (/[@$!%*?&]/.test(password)) score += 1;
    else feedback.push('특수문자를 포함해야 합니다');
    
    return {
      valid: score >= 5,
      score: score,
      feedback: feedback
    };
  }
}
```

### **사용 예시:**

```typescript
// BitWishWalletAuthModal.tsx에서 사용
import { ClientPasswordHasher } from '../utils/passwordHasher';

const handleAuthenticate = async () => {
  // 1. 비밀번호 강도 검증
  const strengthCheck = ClientPasswordHasher.validatePasswordStrength(password);
  if (!strengthCheck.valid) {
    setError(strengthCheck.feedback.join(', '));
    return;
  }
  
  // 2. 클라이언트 측 해싱
  const hashedPassword = await ClientPasswordHasher.hashPassword(password);
  
  // 3. 서버로 해시만 전송
  const response = await fetch('https://localhost:4001/api/bitwish/integrated/wallet/authenticate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      walletAddress: walletAddress,
      password: hashedPassword  // ✅ 해시만 전송
    })
  });
};
```

  max: 100, // 100회 요청
  message: {
    success: false,

  }
});

// 2. 비밀번호 검증 API 강화 레이트 리미팅
const passwordLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15분
  max: 5, // 5회만 허용
  message: {
    success: false,
    error: '비밀번호 시도 횟수 초과. 15분 후 다시 시도하세요.'
  },
  skipSuccessfulRequests: true // 성공 시 카운트 안 함
});

// 3. 지갑 생성 레이트 리미팅
const walletCreationLimiter = rateLimit({
  windowMs: 60 * 60 * 1000, // 1시간
  max: 3, // 3개만 생성 가능
  message: {
    success: false,
    error: '지갑 생성 제한 초과. 1시간 후 다시 시도하세요.'
  }
});

// 적용
app.use('/api/bitwish/', generalLimiter);
app.use('/api/bitwish/integrated/wallet/authenticate', passwordLimiter);
app.use('/api/bitwish/integrated/wallet/verify-password', passwordLimiter);
app.use('/api/bitwish/wallet/create', walletCreationLimiter);

console.log('✅ 레이트 리미팅 적용 완료');

# ✅ 4번 작업 완료: 보안 로깅 (Security Logging)

## 📊 작업 완료 보고서

### **구현된 보안 기능:**

#### **1. BitWishSecurityLogger 클래스 생성** ✅
- **파일**: `Node_HomePage/BitWishSecurityLogger.js` (634줄)
- **기능**:
  - **15가지 로그 타입**:
    - `auth_failure`, `auth_success` (인증)
    - `attack_sql_injection`, `attack_xss`, `attack_nosql_injection` (공격)
    - `rate_limit_exceeded` (레이트 리미팅)
    - `blacklist_added`, `blacklist_removed` (블랙리스트)
    - `wallet_created`, `transaction_created`, `password_changed` (데이터 변경)
    - `system_error`, `system_start`, `system_stop` (시스템)
    - `api_call`, `invalid_input` (API)
  - **4가지 심각도 레벨**: INFO, WARNING, ERROR, CRITICAL
  - **메모리 버퍼**: 최근 1000개 로그 저장
  - **실시간 통계**: 타입별, 심각도별, IP별
  - **위험 IP 자동 감지**: 10회 이상 로그 + CRITICAL/ERROR 조건
  - **MongoDB 영구 저장**: 서버 종료 시 자동 저장
  - **로그 필터링**: 타입, 심각도, IP, 시간 범위
  - **실시간 콘솔 출력**: 이모지 포함 (ℹ️⚠️❌🚨)

#### **2. 자동 로깅 통합** ✅
**적용 위치:**
1. **Input Validator 미들웨어**:
   - NoSQL Injection 차단 시 → `logNoSQLInjectionAttempt()`
   - SQL Injection 차단 시 → `logSQLInjectionAttempt()`
   - XSS 공격 차단 시 → `logXSSAttempt()`

2. **Rate Limiter 미들웨어**:
   - 일반 API 제한 초과 시 → `logRateLimitExceeded()`

3. **비밀번호 검증 API** (`/api/bitwish/integrated/wallet/verify-password`):
   - 성공 시 → `logAuthSuccess()`
   - 실패 시 → `logAuthFailure()`

4. **지갑 생성 API** (`/api/bitwish/wallet/create`):
   - 지갑 생성 시 → `logWalletCreated()`

5. **트랜잭션 생성 API** (`/api/bitwish/transaction/create`):
   - 트랜잭션 생성 시 → `logTransactionCreated()`

6. **시스템 초기화**:
   - 서버 시작 시 → `logSystemStart()`

7. **시스템 종료** (SIGINT, SIGTERM):
   - 서버 종료 시 → `logSystemStop()`
   - MongoDB에 로그 자동 저장

2. **`GET /api/bitwish/security-logs/statistics`**
   - 통계 조회
   - 총 로그 수, 인증 실패 수, 공격 시도 수
   - 타입별/심각도별 분포
   - 상위 IP 목록

3. **`GET /api/bitwish/security-logs/suspicious-ips`**
   - 위험 IP 감지
   - 임계값 기반 필터링 (기본 10)
   - 위험 레벨 (high, medium)

4. **`POST /api/bitwish/security-logs/save`**
   - 수동 로그 저장
   - MongoDB에 현재 버퍼 저장

# ✅ 5번 작업 완료: 세션 보안 강화 (Session Security Enhancement)

## 📊 작업 완료 보고서

### **구현된 보안 기능:**

#### **1. BitWishSessionManager 클래스 생성** ✅
- **파일**: `Node_HomePage/BitWishSessionManager.js` (634줄)
- **핵심 기능**:
  - **JWT 토큰 시스템** (수동 구현, 외부 라이브러리 없음)
    - Header: `{ "alg": "HS256", "typ": "JWT" }`
    - Payload: Base64URL 인코딩
    - Signature: HMAC-SHA256 서명
  - **Access Token**: 15분 유효 (단기 인증)
  - **Refresh Token**: 7일 유효 (토큰 갱신 전용)
  - **CSRF 토큰**: 32바이트 랜덤 hex (CSRF 공격 방어)
  - **세션 하이재킹 방어**:
    - IP 주소 검증
    - User-Agent 검증
    - 불일치 시 즉시 거부 + 보안 로그 기록
  - **토큰 블랙리스트**: 무효화된 토큰 관리
  - **메모리 세션 저장소**: 활성 세션 Map 관리
  - **통계 추적**: 총 세션, 활성 세션, 만료/무효화 카운트

#### **2. 세션 관리 API 엔드포인트** ✅
1. **`POST /api/bitwish/session/login`**
   - 비밀번호 검증 후 세션 생성
   - Access Token, Refresh Token, CSRF Token 발급
   - 보안 로그 기록 (성공/실패)

2. **`POST /api/bitwish/session/refresh`**
   - Refresh Token으로 Access Token 갱신
   - 기존 Access Token 블랙리스트 추가
   - 세션 하이재킹 감지

3. **`POST /api/bitwish/session/logout`**
   - 세션 무효화
   - Access/Refresh Token 블랙리스트 추가
   - 메모리에서 세션 삭제

4. **`POST /api/bitwish/session/verify`**
   - Access Token 검증
   - IP 및 User-Agent 검증
   - 하이재킹 시도 자동 감지

5. **`POST /api/bitwish/session/verify-csrf`**
   - CSRF 토큰 검증
   - 불일치 시 403 Forbidden + 보안 로그

6. **`GET /api/bitwish/session/active`**
   - 활성 세션 목록 조회
   - 지갑 주소 필터링 지원

7. **`GET /api/bitwish/session/statistics`**
   - 세션 통계 조회
   - 총/활성/만료/무효화 세션 수

8. **`POST /api/bitwish/session/revoke-all`**
   - 특정 지갑의 모든 세션 무효화
   - 보안 조치용

#### **3. 자동 세션 관리** ✅
- **세션 복원**: 서버 시작 시 MongoDB에서 자동 로드
- **세션 저장**: 서버 종료 시 MongoDB에 자동 저장 (SIGINT, SIGTERM)
- **자동 정리**: 1시간마다 만료된 세션 삭제
- **메모리 최적화**: 정리 시 통계 자동 업데이트

#### **4. 세션 하이재킹 방어** ✅
**감지 조건:**
```javascript
// IP 주소 불일치
if (session.clientIP !== clientIP) {
  // 하이재킹 시도 감지 → 보안 로그 기록
  return { valid: false, hijackingAttempt: true };
}

// User-Agent 불일치
if (session.userAgent !== userAgent) {
  // 하이재킹 시도 감지 → 보안 로그 기록
  return { valid: false, hijackingAttempt: true };
}
```

**보안 조치:**
- 즉시 요청 거부 (401 Unauthorized)
- 보안 로그 자동 기록 (ERROR 레벨)
- IP 및 User-Agent 정보 저장

    - ±30초 윈도우 허용 (총 90초 유효)

    - 시크릿 키 생성 및 변환

  - **QR 코드 URL 생성**
    - otpauth:// 프로토콜
    - Google Authenticator, Authy 호환

    - 10개의 8자리 코드
    - xxxx-xxxx 형식
    - 1회용 (사용 시 자동 소진)
  - **통계 추적**: 총 사용자, 활성화 사용자, 검증 시도/성공/실패율

#### **2. 2FA API 엔드포인트** ✅
1. **`POST /api/bitwish/2fa/setup`**
   - 시크릿 키, QR 코드 URL, 백업 코드 생성
   - 아직 활성화되지 않은 상태로 저장

2. **`POST /api/bitwish/2fa/enable`**
   - TOTP 코드 검증 후 2FA 활성화
   - 보안 로그 기록

3. **`POST /api/bitwish/2fa/disable`**
   - TOTP 또는 백업 코드 검증 후 비활성화
   - 보안 로그 기록

4. **`POST /api/bitwish/2fa/verify`**
   - TOTP 코드 또는 백업 코드 검증
   - 성공 시 사용 방법 (totp/backup_code) 반환
   - 보안 로그 기록 (성공/실패)

5. **`GET /api/bitwish/2fa/status/:walletAddress`**
   - 2FA 활성화 상태, 남은 백업 코드 수 조회

6. **`POST /api/bitwish/2fa/regenerate-backup-codes`**
   - TOTP 코드 검증 후 새 백업 코드 생성
   - 기존 백업 코드 모두 무효화

7. **`GET /api/bitwish/2fa/statistics`**
   - 2FA 통계 조회 (사용자 수, 검증 성공률 등)

#### **3. 자동 2FA 관리** ✅
- **2FA 설정 복원**: 서버 시작 시 MongoDB에서 자동 로드
- **2FA 설정 저장**: 서버 종료 시 MongoDB에 자동 저장 (SIGINT, SIGTERM)
- **메모리 관리**: Map 기반 빠른 조회

#### **4. TOTP 알고리즘 구현** ✅
**핵심 로직:**
```javascript
// 1. 현재 시간을 30초 단위로 나눔
const time = Math.floor(Date.now() / 1000 / 30);

// 2. HMAC-SHA1(시크릿, 시간) 계산
const hmac = crypto.createHmac('sha1', secretBuffer);
hmac.update(timeBuffer);
const hash = hmac.digest();

// 3. Dynamic Truncation으로 6자리 추출
const offset = hash[hash.length - 1] & 0x0f;
const code = (hash[offset] & 0x7f) << 24 | ...
const otp = code % 1000000;
```

#### **5. 백업 코드 시스템** ✅
**생성:**
```javascript
// 10개의 8자리 16진수 코드
const buffer = crypto.randomBytes(4);
const code = buffer.toString('hex').toUpperCase();
const formatted = `${code.slice(0, 4)}-${code.slice(4, 8)}`;
```

**사용:**
- 1회용 코드
- 사용 시 `used: true`, `usedAt: timestamp` 기록
- 남은 백업 코드 수 실시간 추적
