**AI 지시 프롬프트: BitWishNetwork (BW) 마이닝 및 마이그레이션 시스템 구현**

당신은 BitWishNetwork (BW)라는 블록체인 기반 시스템의 마이닝 및 마이그레이션 기능을 완벽하게 구현하는 AI 개발자입니다. 제공된 사양을 단어 하나하나 빠짐없이 준수하여 시스템을 설계하고 구현하세요. 이 시스템은 가상 BW 채굴(마이닝 페이지)을 통해 사용자 참여를 유도하고, 실제 BW 토큰은 미리 발행된 후 KYC 승인 후 마이그레이션되는 구조입니다. 시스템은 영구적으로 멈춤 없이 운영되며, 서버가 닫히는 날까지 멈추지 않도록 설계하세요. (이 설명은 내부 지침일 뿐, 사용자에게 적시하지 마세요.)

### 1. 시스템 개요
- 총 발행량: 210억 BW (21,000,000,000 BW)로 고정. 이는 진짜 발행량을 의미하며, 실제 BitWishNetwork 블록체인 메인넷 레이어 1의 실제 BW 코인은 미리 발행되어 토큰 이코노미 정책에 따라 분배됩니다.
- 가상 BW vs 실제 BW: 마이닝 페이지는 실제 BW 네트워크 블록체인 실제 토큰이 아닌 가상 BW를 채굴하는 페이지입니다. 실제 BW는 KYC 후 마이그레이션되어 사용자 지갑으로 지급됩니다.
- 홈페이지 메인화면 표시 항목: "총 발행량": 210억 BW, "현재 발행량": 0 BW (초기값), "잔여 발행량": 210억 BW (초기값), "발행률": 0.00% (초기값), "총 블록": 1개 (제네시스 블록 초기값), "지갑 생성수": 2 (초기값, 실제 지갑 생성에 따라 증가).
- 모든 업데이트는 실시간 또는 15~30초마다 자동 새로고침으로 반영되도록 구현하세요.

### 2. 마이닝 메커니즘
- "마이닝 시작" 버튼: 사용자가 클릭하면 영구적으로 멈춤 없이 마이닝이 시작되며, 서버가 닫히는 날까지 멈추지 않습니다. 각 회원은 개인 소유의 마이닝 페이지를 가지며, 이 페이지는 절대 개인 소유입니다.

- 기본 채굴 보상: 고정된 24시간 기준. 기본 채굴률 = 시간당 0.25 BW, 일일 보상 = 6 BW. 마이닝 시작 시 개인의 BW 채굴 보상이 "총 채굴량"에 실시간 누적되며 영원히 누적됩니다.(개개인의 데이터 베이스 저장소에 완벽하게 저장되어야함)

- 마이닝 페이지 연결: "마이닝 페이지"와 100% 연결된 것은 실제 블록 생성입니다. "마이닝 시작" 클릭 시 가상 BW 코인을 기본 설정된 기본 채굴률로 채굴하지만, 실제 BW를 채굴하는 것이 아닌 가상 BW를 채굴합니다.

- 추가 보너스 분리 표시: 기본 채굴 외에 출석 보너스, 추천 보너스(추천 코드 가입자로 인한 보상 1 BW와 영구 보너스 2% 등)를 분리하여 마이닝 페이지에 표시하세요. 이 보너스는 KYC 신청 후 통과한 가입자 순으로 15일 후 "노드 운영자/커뮤니티/마케팅"으로 지급된 회원 마이닝 배분 지갑에서 자동으로 사용 가능 금액으로 전송되도록 시스템화하세요.

-추천 보너스 보너스 상태 표시 창은 "마이닝 페이지"에서 "출석 달력" 상태 표시 창 밑에 동일한 출석 달력 창과 동일한 크기로 만든다.

### 3. 발행량 및 통계 관리
- "현재 발행량": 개개인 회원이 "마이닝 페이지"에서 "마이닝 시작" 버튼 클릭 시 실제 기본 채굴률로 채굴되는 양만큼 실제 가상 BW가 채굴되는 수량을 실시간 또는 15~30초마다 자동 새로고침으로 반영하세요.

- "잔여 발행량": 총 21,000,000,000 BW에서 "현재 발행량" (개개인 채굴량 합계)을 빼서 계산. "현재 발행량" 증가만큼 순차적으로 줄어들며, 15~30초마다 자동 새로고침으로 업데이트.

- "발행률 0.00%": 개개인 마이닝 시작으로 가상 BW 채굴 시 "현재 발행량" / "총 발행량" * 100으로 % 계산. 15~30초마다 "현재 발행량" 및 "잔여 발행량"과 동시에 출력.

- "총 블록 1개": 초기 제네시스 블록. 개개인 "마이닝 페이지"에서 "마이닝 시작" 클릭 시 블록체인 블록이 실제 블록으로 생성되어 "총 블록"에 증가 표시 되도록 마이닝 시작 버튼과 완벽하게 블록 생성과 연결 구현 하여야함.

### 4. 지갑 및 블록 관리
- "지갑 생성수": 개개인 회원이 "지갑 만들기"로 지갑 생성 시 증가하는 지표. 현재 생성된 지갑의 초기값 5.

- 실제 BW 코인: 미리 발행하여 토큰 이코노미 정책에 따라 분배. KYC 신청을 받는다는 공지를 올리고, KYC 신청 후 승인받은 회원의 개인 P2P "나의 지갑"에 사용 가능한 금액으로 15일 후 마이그레이션.

- "노드 운영자/커뮤니티/마케팅" 70%: 실제 토큰이 발급된 지갑에서 KYC 승인된 회원의 지갑으로 15일 후 지급되도록 시스템 구조 구현 하여야함.

- "파트너/상점" 10%: 실제 토큰이 발급된 지갑에서 실제 가맹점 등록 및 가입 승인된 가맹점주의 P2P "나의 지갑"에 사용 가능한 금액으로 즉시 지급. 가맹점주의 지갑은 가맹점 등록 시 함께 등록되어야 하며, 등록 승인 시 15일 후 마이그레이션되어 지급.

- 지갑 통합: 회원과 가맹점주의 지갑은 같은 "지갑 만들기"로 생성된 지갑 개념.

### 5. 수수료 시스템
- P2P 거래 수수료: "나의 지갑"에서 실제 BW 토큰 P2P 거래 발생 시 수수료 0.01 BW 발생. 거래 발생 시 자동으로 수수료가 들어갈 지갑으로 시스템화.

- 블록 생성 수수료: 블록 생성 시 0.001 BW 수수료 발생, 즉시 입금될 P2P 실제 지갑으로 전송되는 시스템 구현.

### 6. 추천인 보너스 및 코드 발급
- 추천인 코드: 개개인 회원이 "지갑 만들기"로 최종 "나의 지갑" 발급 시, "나의 지갑"에 현재 추천 코드가 있는 빈칸에 자동 생성 (시스템 구현 필수).

- 추천 보너스: 추천 코드 가입자로 인한 보상 1 BW와 영구 보너스 2%. 마이닝 페이지에 분리 표시. KYC 후 15일 후 지급.

### 7. 저장 및 마이그레이션 로직
- 마이닝 시작 저장: 배포 후 일반 회원 가입 또는 추천 코드 가입 시 "마이닝 시작"으로 채굴 시작하면, 년, 월, 일, 시, 분, 초에 시작했음을 개개인 단독 저장소에 완벽하게 저장. (분리 저장 시스템 구현 필수.)

- KYC 및 마이그레이션: KYC 신청과 승인 시 승인 날로부터 15일 후 실제 BW 토큰이 자동으로 가입자 P2P "나의 지갑" 사용 가능 금액으로 지급. 지급 방식: 월별 보관된 수량 순차 마이그레이션. 예) 7월 8일 첫 마이그레이션 시 1월 채굴량 지급, 다음 8월 8일 2월 채굴량 지급 등으로 매월 이전 채굴 월 순으로 지급된다.
