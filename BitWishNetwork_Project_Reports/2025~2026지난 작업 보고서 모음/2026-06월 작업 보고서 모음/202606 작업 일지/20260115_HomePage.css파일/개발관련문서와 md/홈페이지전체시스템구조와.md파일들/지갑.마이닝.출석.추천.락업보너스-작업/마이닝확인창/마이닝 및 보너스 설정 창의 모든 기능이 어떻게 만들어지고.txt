## **   "마이닝 및 보너스 설정" 창 완벽한 분석 보고서**

### **📋 시스템 개요**
**"마이닝 및 보너스 설정" 창은 BitWishNetwork의 핵심 마이닝 시스템으로, 출석, 추천, 락업, 가맹 보너스를 통합하여 실시간으로 계산하고 표시하는 완벽한 시스템입니다.**

---

## **  ️ 1. 시스템 아키텍처 및 데이터 흐름**

### **1.1 전체 시스템 구조**
```
┌─────────────────────────────────────────────────────────────┐
│                🎯 마이닝 및 보너스 설정 창                    │
├─────────────────────────────────────────────────────────────┤
│  📊 실시간 데이터 관리 시스템                                │
│  ├─ realTimeBlockchainData (상태 관리)                      │
│  ├─ calculateTotalMiningReward (통합 계산)                  │
│  └─ calculateAccumulatedRewardDecimal (누적 보상)           │
├─────────────────────────────────────────────────────────────┤
│  🎁 보너스 시스템 (4개 통합)                                │
│  ├─ 출석 보너스 (calculateAttendanceBonus)                  │
│  ├─ 추천 보너스 (calculateReferralBonusDecimal)             │
│  ├─ 락업 보너스 (calculateLockupBonus)                      │
│  └─ 가맹 보너스 (calculateMerchantBonus)                    │
├─────────────────────────────────────────────────────────────┤
│  📈 실시간 표시 시스템                                      │
│  ├─ 마이닝 상태 확인                                        │
│  ├─ 추천 보너스 현황                                        │
│  └─ 실시간 마이닝 보상                                      │
└─────────────────────────────────────────────────────────────┘
```

### **1.2 데이터 흐름 다이어그램**
```
사용자 설정 → 보너스 계산 → 통합 계산 → 실시간 표시 → 누적 보상
     ↓              ↓           ↓          ↓          ↓
출석/추천/락업 → 각각 계산 → 총 보상률 → UI 업데이트 → 보관함 분배
```

## **🎁 2. 보너스 시스템 상세 분석**

### **2.1 출석 보너스 시스템**
**위치**: `calculateAttendanceBonus` 함수 (라인 2867-2946)
**데이터 흐름**:
```typescript
consecutiveAttendanceDays → calculateAttendanceBonus() → bonusRate
```

**계산 로직**:
- **30일 이상**: 17% 보너스
- **BigDecimal 기반**: 정확한 부동소수점 계산
- **실시간 반영**: `realTimeBlockchainData.attendanceBonus` 업데이트

### **2.2 추천 보너스 시스템**
**위치**: `calculateReferralBonusDecimal` 함수 (라인 2949-3122)
**데이터 흐름**:
```typescript
referralCount → calculateReferralBonusDecimal() → totalBonusRate
```

**계산 로직**:
- **백서 정책 100% 준수**: 구간별 보너스율 적용
- **1~30명**: 1.875%, **31~60명**: 1.5%, **61~90명**: 1.125%, **91명 이상**: 0.75%
- **BigDecimal 기반**: 누적 계산으로 정확성 보장

### **2.3 락업 보너스 시스템**
**위치**: `calculateLockupBonus` 함수 (라인 3272-3404)
**데이터 흐름**:
```typescript
lockupRatio + lockupMonths → calculateLockupBonus() → monthlyRate
```

**계산 로직**:
- **백서 기반 APY**: 정확한 연간 수익률 계산
- **월 보상률**: APY ÷ 12
- **등록 상태 확인**: `isLockupRegistered` 플래그로 제어

### **2.4 가맹 보너스 시스템**
**위치**: `calculateMerchantBonus` 함수 (라인 3393-3421)
**데이터 흐름**:
```typescript
isMerchantRegistered → calculateMerchantBonus() → bonusRate
```

**계산 로직**:
- **가맹점 등록 시**: 추가 보너스율 적용
- **BigDecimal 기반**: 정확한 계산

## **⚡ 3. 실시간 마이닝 보상 시스템**

### **3.1 통합 계산 함수**
**위치**: `calculateTotalMiningReward` 함수 (라인 2539-2568)
**핵심 로직**:
```typescript
const totalEnhancedRate = baseRate * (1 + attendanceBonus + referralBonus + lockupBonus);
```

**데이터 흐름**:
1. **기본 채굴률**: 0.25 BW/시간
2. **보너스 통합**: 출석 + 추천 + 락업 + 가맹
3. **강화된 채굴률**: 기본률 × (1 + 총 보너스율)
4. **시간당/일일 보상**: 강화된 채굴률 × 시간

### **3.2 실시간 업데이트 시스템**
**위치**: `useEffect` (라인 3454-3492)
**업데이트 주기**: 1초마다
**업데이트 내용**:
- 경과 시간 계산
- 보상 재계산
- `realTimeBlockchainData` 상태 업데이트
- UI 강제 리렌더링
