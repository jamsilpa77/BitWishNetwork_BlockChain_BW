##    App.tsx 마이닝 시스템 문제점 분석 보고서

###    발견된 주요 문제점들

#### **1. 유저용 마이닝 상태 지속성 문제 (심각)**
- **문제**: 유저용 마이닝 상태(`userIsMiningActive`, `userMiningStartTime`, `userMiningRewards`)가 localStorage에 저장되지 않음
- **영향**: 새로고침 시 마이닝 상태가 완전히 초기화됨
- **위치**: 라인 1498-1501 (유저용 상태 변수 선언)
- **해결 필요**: localStorage 기반 상태 저장/복원 시스템 구현

#### **2. 마이닝 정지 시 진행 시간 초기화 문제**
- **문제**: `stopUserMining()` 함수에서 `userMiningStopTime`만 설정하고, 정지된 상태에서 진행 시간 계산 로직이 잘못됨
- **영향**: 마이닝 정지 시 진행 시간이 0으로 초기화됨
- **위치**: 라인 10386-10460 (실시간 마이닝 보상 표시 부분)
- **세부 문제**: 
  ```typescript
  // 현재 코드 (문제)
  if (!userIsMiningActive || !userMiningStartTime) return '00:00:00';
  
  // 정지 상태에서도 정지 시간까지의 진행 시간을 표시해야 함
  ```

#### **3. 마이닝 재시작 시 데이터 초기화 문제**
- **문제**: `startUserMining()` 함수에서 이전 마이닝 데이터를 보존하지 않음
- **영향**: 마이닝 재시작 시 누적 보상과 진행 시간이 0에서 다시 시작됨
- **위치**: 라인 5954-5966 (startUserMining 함수)
- **세부 문제**: 
  ```typescript
  // 현재 코드 (문제)
  setUserMiningStartTime(new Date()); // 항상 새로운 시간으로 설정
  
  // 이전 마이닝 데이터를 보존해야 함
  ```

#### **4. 실시간 업데이트 시스템 부재**
- **문제**: 유저용 마이닝에 대한 실시간 업데이트 useEffect가 없음
- **영향**: 마이닝 진행 중에도 UI가 실시간으로 업데이트되지 않음

#### **문제점**
- 유저용 마이닝 상태가 localStorage에 저장되지 않아 새로고침 시 초기화됨

**1-1. 유저용 마이닝 상태 localStorage 저장 함수 추가**
```typescript
// 라인 1498-1501 근처에 추가
//    유저용 마이닝 상태 localStorage 저장 함수
const saveUserMiningState = () => {
  try {
    const userMiningState = {
      isMiningActive: userIsMiningActive,
      miningStartTime: userMiningStartTime?.toISOString() || null,
      miningStopTime: userMiningStopTime?.toISOString() || null,
      miningRewards: userMiningRewards,
      lastUpdated: new Date().toISOString()
    };
    localStorage.setItem('userMiningState', JSON.stringify(userMiningState));
    console.log('💾 유저용 마이닝 상태 저장됨:', userMiningState);
  } catch (error) {
    console.error('❌ 유저용 마이닝 상태 저장 실패:', error);
  }
};

//    유저용 마이닝 상태 localStorage 복원 함수
const loadUserMiningState = () => {
  try {
    const savedState = localStorage.getItem('userMiningState');
    if (savedState) {
      const userMiningState = JSON.parse(savedState);
      setUserIsMiningActive(userMiningState.isMiningActive || false);
      setUserMiningStartTime(userMiningState.miningStartTime ? new Date(userMiningState.miningStartTime) : null);
      setUserMiningStopTime(userMiningState.miningStopTime ? new Date(userMiningState.miningStopTime) : null);
      setUserMiningRewards(userMiningState.miningRewards || 0);
      console.log('✅ 유저용 마이닝 상태 복원됨:', userMiningState);
    }
  } catch (error) {
    console.error('❌ 유저용 마이닝 상태 복원 실패:', error);
  }
};
```

#### **문제점**
- 마이닝 정지 시 진행 시간이 0으로 초기화됨

#### **해결 방법**

**2-1. stopUserMining 함수 수정**
```typescript
// 라인 5968-5987 stopUserMining 함수 수정
const stopUserMining = () => {
  if (!userIsMiningActive) {
    console.log('⚠️ 유저용 마이닝이 진행 중이 아닙니다.');
    return;
  }
  
  setUserIsMiningActive(false);
  setUserMiningStopTime(new Date());
  
  //    누적 보상 계산 (고정값 기반: 시간당 0.25 BW)
  if (userMiningStartTime) {
    const elapsedMs = new Date().getTime() - userMiningStartTime.getTime();
    const elapsedHours = elapsedMs / (1000 * 60 * 60);
    const accumulatedReward = elapsedHours * 0.25; // 고정값: 시간당 0.25 BW
    setUserMiningRewards(prev => prev + accumulatedReward);
  }
  
  console.log('🛑 유저용 마이닝 정지됨 (고정값 기반)');
};
```

**2-2. 실시간 마이닝 보상 표시 로직 수정**
```typescript
// 라인 10435-10448 진행 시간 계산 부분 수정
{(() => {
  tick; // tick을 참조하여 tick 변경 시 재계산 유발
  
  if (!userMiningStartTime) return '00:00:00';
  
  const currentTime = new Date();
  let totalElapsedTime = 0;
  
  if (userIsMiningActive) {
    // 🎯 마이닝 진행 중: 실시간으로 경과 시간 계산
    totalElapsedTime = currentTime.getTime() - userMiningStartTime.getTime();
  } else {
    // 🎯 마이닝 정지됨: 정지 시간까지만 계산 (고정)
    totalElapsedTime = userMiningStopTime ? 
      userMiningStopTime.getTime() - userMiningStartTime.getTime() : 
      currentTime.getTime() - userMiningStartTime.getTime();
  }
  
  // 🎯 유저용 시간 계산 (고정값 기반)
  const hours = Math.floor(totalElapsedTime / (1000 * 60 * 60));
  const minutes = Math.floor((totalElapsedTime % (1000 * 60 * 60)) / (1000 * 60));
  const seconds = Math.floor((totalElapsedTime % (1000 * 60)) / 1000);
  
  return `${hours.toString().padStart(2, '0')}:${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}`;
})()}
```

```typescript
// 라인 5954-5966 startUserMining 함수 수정
const startUserMining = () => {
  if (userIsMiningActive) {
    console.log('⚠️ 유저용 마이닝이 이미 진행 중입니다.');
    return;
  }
  
  // 🎯 이전 마이닝 데이터 보존하여 재시작
  if (userMiningStartTime && userMiningStopTime) {
    // 이전 마이닝이 있었던 경우: 정지된 시간만큼 시작 시간을 앞으로 이동
    const pausedDuration = Date.now() - userMiningStopTime.getTime();
    const adjustedStartTime = new Date(userMiningStartTime.getTime() + pausedDuration);
    setUserMiningStartTime(adjustedStartTime);
  } else if (!userMiningStartTime) {
    // 처음 마이닝 시작하는 경우
    setUserMiningStartTime(new Date());
  }
  // 이미 시작 시간이 있고 정지 시간이 없는 경우는 그대로 유지
  
  setUserIsMiningActive(true);
  setUserMiningStopTime(null);
  
  console.log('✅ 유저용 마이닝 시작됨 (고정값 기반)');
};
```

### 🔍 1번: 마이닝 정지 시 0.007포인트 상승 문제 분석

#### **문제 발견: 중복 보상 계산 문제**

**원인 분석:**
1. **stopUserMining 함수에서 누적 보상 계산** (라인 6057-6061):
   ```typescript

   const elapsedHours = elapsedMs / (1000 * 60 * 60);
   const accumulatedReward = elapsedHours * 0.25;
   setUserMiningRewards(prev => prev + accumulatedReward);
   ```

2. **실시간 보상 표시에서도 동일한 계산** (라인 10539-10543):
   ```typescript

   const elapsedHours = elapsedMs / (1000 * 60 * 60);
   const currentReward = elapsedHours * 0.25;

   ```

**문제점:**
- 마이닝 정지 시 `stopUserMining`에서 이미 `userMiningRewards`에 보상을 누적함
- 그런데 실시간 표시 로직에서 또 다시 `userMiningRewards + currentReward`로 계산
- 결과적으로 **이중 계산**되어 0.007포인트 정도의 중복 보상이 발생

**해결 방법:**

### 핵심 해결 방법:

**재시작 시 시작 시간을 정지한 시간만큼 앞으로 이동시켜서 정지한 시간을 제외하고 이어서 진행**

### 구체적인 해결 방법:

#### 1. startUserMining 함수 수정:

```typescript
const startUserMining = () => {
  if (userIsMiningActive) {
    console.log('⚠️ 유저용 마이닝이 이미 진행 중입니다.');
    return;
  }
  
  // 🎯 재시작 시 정지한 시간만큼 시작 시간을 앞으로 이동
  if (userMiningStartTime && userMiningStopTime) {
    // 정지한 시간 계산
    const pausedDuration = Date.now() - userMiningStopTime.getTime();
    // 시작 시간을 정지한 시간만큼 앞으로 이동
    const adjustedStartTime = new Date(userMiningStartTime.getTime() + pausedDuration);
    setUserMiningStartTime(adjustedStartTime);
  } else if (!userMiningStartTime) {
    // 처음 시작하는 경우
    setUserMiningStartTime(new Date());
  }
  
  setUserIsMiningActive(true);
  setUserMiningStopTime(null);
  
  console.log('✅ 유저용 마이닝 시작됨 (고정값 기반)');
};
```

#### 2. 동작 원리:

**예시 시나리오:**
1. **10:00 마이닝 시작** → `userMiningStartTime = 10:00`
2. **10:10 마이닝 정지** → `userMiningStopTime = 10:10`, 정지 시점: 0.0500000BW, 00:10:10
3. **10:20 마이닝 재시작** → 
   - 정지한 시간: 10분 (10:10~10:20)
   - 조정된 시작 시간: 10:00 + 10분 = 10:10
   - 결과: 10:10부터 현재까지 계산하므로 정지한 10분 제외

#### 3. 결과:

- **재시작 시**: 0.0500000BW, 00:10:10에서 이어서 진행
- **정지한 시간**: 계산에서 제외됨
- **실시간 진행**: 재시작 시점부터 정상 진행

```typescript
const calculateConsecutiveDaysFromCalendar = (calendar: {[key: string]: boolean}, currentTime: Date = new Date()): number => {
  const dates = Object.keys(calendar).sort();
  if (dates.length === 0) return 0;

  let maxConsecutive = 0;
  let currentConsecutive = 1; // 첫 출석일은 1일로 시작
  const resetTimeHour = 9; // AM 09:00:00 기준

  for (let i = 0; i < dates.length; i++) {
    const currDate = new Date(dates[i]);
    
    // 현재 날짜와 비교하여 연속성 확인 (마지막 출석일인 경우)
    if (i === dates.length - 1) {
      const currentDateStart = new Date(currentTime.getFullYear(), currentTime.getMonth(), currentTime.getDate(), resetTimeHour, 0, 0);
      const diffTime = currentDateStart.getTime() - currDate.getTime();
      const diffHours = diffTime / (1000 * 60 * 60);
      
      if (diffHours <= 24) {
        currentConsecutive++;
      } else {
        currentConsecutive = 1;
      }
    } else {
      // 이전 출석일과의 연속성 확인
      if (i > 0) {
        const prevDate = new Date(dates[i - 1]);
        const diffTime = currDate.getTime() - prevDate.getTime();
        const diffDays = Math.ceil(diffTime / (1000 * 60 * 60 * 24));
        
        if (diffDays === 1) {
          currentConsecutive++;
        } else {
          currentConsecutive = 1;
        }
      }
    }
    
    maxConsecutive = Math.max(maxConsecutive, currentConsecutive);
  }
  
  return maxConsecutive;
};
```
**✅ 정상:** 제가 이해한 내용과 일치

```typescript
const calculateAdminConsecutiveDays = (): number => {
  const dates = Object.keys(adminAttendanceCalendar).sort();
  if (dates.length === 0) return 0;

  // 오늘부터 역순으로 연속성 확인

      const diffTime = currentDate.getTime() - nextDate.getTime();
      const diffDays = Math.floor(diffTime / (1000 * 60 * 60 * 24));
      
      if (diffDays === 1) {
        consecutiveDays++;
      } else {
        break;
      }
    }
  }
```

```typescript
useEffect(() => {
  const checkAdminConsecutiveDays = () => {
    const now = new Date();
    const resetTime = new Date(now.getFullYear(), now.getMonth(), now.getDate(), 9, 0, 0);
    
    // AM 09:00:00 자동 초기화 체크
    checkAttendanceReset();
    
    // 마지막 출석일 확인
    const dates = Object.keys(adminAttendanceCalendar).sort();
    if (dates.length === 0) {
      setAdminConsecutiveAttendanceDays(0);
      return;
    }

    const lastAttendanceDate = new Date(dates[dates.length - 1]);
    const diffTime = now.getTime() - lastAttendanceDate.getTime();
    const diffDays = Math.floor(diffTime / (1000 * 60 * 60 * 24));

    if (diffDays > 1) {
      setAdminConsecutiveAttendanceDays(0); // 연속성 초기화
      console.log('🔄 관리자용 연속성 초기화 - 마지막 출석일로부터 1일 이상 경과');
    } else {
      const consecutiveDays = calculateAdminConsecutiveDays();
      setAdminConsecutiveAttendanceDays(consecutiveDays);
      console.log('   관리자용 출석 달력 변경 감지 - 연속 출석일 수 업데이트:', consecutiveDays);
    }
  };

  checkAdminConsecutiveDays();
}, [adminAttendanceCalendar]); // 관리자용 출석 달력 변경 시에만 실행
```
