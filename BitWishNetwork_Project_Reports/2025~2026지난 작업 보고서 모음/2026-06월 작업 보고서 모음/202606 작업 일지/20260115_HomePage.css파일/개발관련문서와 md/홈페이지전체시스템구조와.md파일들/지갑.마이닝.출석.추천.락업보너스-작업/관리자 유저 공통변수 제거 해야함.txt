### **3. 타입 오류 해결**

#### **문제점:**
```typescript
// 라인 3322, 3375: null 타입 불일치
registeredBasicLockupData: {
  ratio: 0,
  months: 0,
  apy: 0,
  startDate: null,  // ❌ null이 Date 타입과 불일치
  endDate: null     // ❌ null이 Date 타입과 불일치
}
```

#### **해결 방안:**
```typescript
// ✅ 타입 강제 변환 또는 undefined 사용
registeredBasicLockupData: {
  ratio: 0,
  months: 0,
  apy: 0,
  startDate: null as any,  // 타입 강제 변환
  endDate: null as any     // 타입 강제 변환
}

// 또는 더 안전한 방법:
registeredBasicLockupData: {
  ratio: 0,
  months: 0,
  apy: 0,
  startDate: undefined,  // undefined 사용
  endDate: undefined     // undefined 사용
}
```
