#### **1. 백서 정책 vs 구현 상태 비교**

##### **✅ 백서 정책 (완벽 구현됨)**
- **추천인 보너스 체계**: 1~30명(1.875%), 31~60명(1.5%), 61~90명(1.125%), 91명 이상(0.75%)
- **즉시 보너스**: 추천인코드 발급자와 가입자 각 **1 BW 즉시 지급**
- **영구 보너스율**: 발급자는 **1.2% 영구 적용**, 가입자는 **가입 시 1회 1.2% 적용**
- **1회 제한**: 가입자는 **1회만** 보너스 받을 수 있음
- **지속적 보너스**: 본인 코드로 가입자를 가입시키면 똑같이 1BW와 1.2% 영구 보너스 받음

  bonusRate: Decimal;
  enhancedRate: Decimal;
  description: string;
  maxBonus: number;
  instantBonus: Decimal;
  permanentBonusRate: Decimal;

  cumulativeBonusRate: Decimal; // 🆕 누적 보너스율
  segmentInfo: {
    currentSegment: string;
    segmentStart: number;
    segmentEnd: number;
    segmentRate: number;
    cumulativeFromPrevious: Decimal;
    additionalInCurrent: Decimal;
  };
} => {
  //    백서 정책: 즉시 보너스 1 BW + 영구 보너스율 1.2% × 추천인 수
  const decimalInstantBonus = new Decimal(1.0);
  const decimalPermanentBonusRate = new Decimal(0.012).times(referralCount); // 1.2% × N명
  
  // 🎯 구간별 누적 보너스율 계산 (BigDecimal 기반) - 2025년 1월 4일 업데이트
  let decimalCumulativeBonusRate = new Decimal(0);
  
  if (referralCount >= 91) {
    //    구간 4: 91명 이상 (0.75% × N명)
    // 누적: 30명(56.25%) + 30명(45%) + 30명(33.75%) + (N-90)명(0.75%)
    const segment1Bonus = new Decimal(30).times(0.01875); // 30명: 56.25%
    const segment2Bonus = new Decimal(30).times(0.015); // 31-60명: 45%
    const segment3Bonus = new Decimal(30).times(0.01125); // 61-90명: 33.75%
    const segment4Bonus = new Decimal(referralCount - 90).times(0.0075); // 91명 이상: 0.75% × (N-90)
    
    decimalCumulativeBonusRate = segment1Bonus.plus(segment2Bonus).plus(segment3Bonus).plus(segment4Bonus);
    
    return {
      bonusRate: decimalCumulativeBonusRate,
      enhancedRate: new Decimal(0.25).times(new Decimal(1).plus(decimalCumulativeBonusRate)),
      description: '🏆 대규모 커뮤니티 구축',
      maxBonus: decimalCumulativeBonusRate.times(100).toNumber(),
      instantBonus: decimalInstantBonus,
      permanentBonusRate: decimalPermanentBonusRate,
      totalBonusRate: decimalPermanentBonusRate.plus(decimalCumulativeBonusRate), // 🎯 영구 + 구간별
      cumulativeBonusRate: decimalCumulativeBonusRate,
      segmentInfo: {
        currentSegment: '91명 이상 (대규모 커뮤니티)',
        segmentStart: 91,
        segmentEnd: Infinity,
        segmentRate: 0.0075,
