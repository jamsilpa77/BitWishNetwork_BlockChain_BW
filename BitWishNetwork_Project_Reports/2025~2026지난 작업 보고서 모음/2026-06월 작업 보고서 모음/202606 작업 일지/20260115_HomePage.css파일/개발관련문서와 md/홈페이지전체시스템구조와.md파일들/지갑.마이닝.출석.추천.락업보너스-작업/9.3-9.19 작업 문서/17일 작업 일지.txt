## **문제 분석 보고서**

### **문제 상황:**
유저용 마이닝 정지 버튼 클릭 시 보상이 0으로 돌아가고, 다시 마이닝 시작하면 0에서 다시 시작하는 현상

### **문제 원인 분석:**

#### **1. 실시간 보상 계산 로직의 문제 (라인 10366-10368):**
```typescript
if (!userIsMiningActive || !userMiningStartTime) {
  return userMiningRewards.toFixed(8); // ❌ 문제: 마이닝이 정지되면 userMiningRewards만 표시
}
```

#### **2. 마이닝 정지 시 보상 누적 로직 (라인 5978-5984):**
```typescript
// 🎯 누적 보상 계산 (고정값 기반: 시간당 0.25 BW)
if (userMiningStartTime) {
  const elapsedMs = new Date().getTime() - userMiningStartTime.getTime();
  const elapsedHours = elapsedMs / (1000 * 60 * 60);
  const accumulatedReward = elapsedHours * 0.25; // 고정값: 시간당 0.25 BW
  setUserMiningRewards(prev => prev + accumulatedReward); // ✅ 정상: 누적 보상 추가
}
```

### **실제 문제:**

**마이닝이 진행 중일 때:**
- `userMiningRewards` (이전 누적값) + `currentReward` (현재 실시간 계산값) = `totalReward` 표시 ✅

**마이닝이 정지되면:**
- `userMiningRewards` (이전 누적값 + 정지 시 누적값) 만 표시 ✅

**마이닝을 다시 시작하면:**
- `userMiningRewards` (이전 누적값 + 정지 시 누적값) + `currentReward` (새로운 실시간 계산값) = `totalReward` 표시 ✅

### **왜 0으로 돌아가는가?**

**가능한 원인들:**
1. **`userMiningStartTime`이 null로 리셋됨** - 마이닝 시작 시 새로운 시간으로 설정되지만, 정지 시에는 null로 설정되지 않음
2. **`userMiningRewards`가 실제로 0으로 리셋됨** - 어딘가에서 초기화되고 있을 가능성
3. **상태 업데이트 타이밍 문제** - React의 비동기 상태 업데이트로 인한 문제

### **정확한 원인을 찾기 위해 확인해야 할 것:**
1. `userMiningStartTime`이 마이닝 정지 후에도 유지되는지
2. `userMiningRewards`가 실제로 누적되는지
3. 마이닝 재시작 시 이전 값들이 제대로 유지되는지
