## **   KYC 관련 시스템 구조:**

### **🎯 1. KYC 상태 관리 시스템:**
```typescript
// KYC 상태 타입 정의
interface KYCStatus {
  isApplied: boolean;        // KYC 신청 여부
  isApproved: boolean;       // KYC 승인 여부
  applicationDate: Date;     // 신청일
  approvalDate: Date;        // 승인일
  rejectionReason?: string;  // 거부 사유 (선택사항)
  documents: string[];       // 제출 서류 목록
}
```

### **   2. KYC 신청 프로세스:**
- **신청 단계**: 사용자가 KYC 신청 버튼 클릭
- **서류 제출**: 신분증, 주소 증명서 등 필수 서류 업로드
- **검토 단계**: 관리자가 서류 검토 및 승인/거부 결정
- **결과 통지**: 승인/거부 결과를 사용자에게 알림

### **   3. KYC 상태에 따른 기능 제한:**
- **미신청 상태**: 락업 해제 불가, 사용가능 금액 사용 불가
- **신청 대기 상태**: 락업 해제 가능, 사용가능 금액 사용 불가
- **승인 완료 상태**: 모든 기능 사용 가능

### **🎯 4. 락업 해제 시 KYC 확인 로직:**
```typescript
const handleLockupRelease = async () => {
  // 1. KYC 상태 확인
  const kycStatus = await checkKYCStatus(walletAddress);
  
  if (!kycStatus.isApplied) {
    alert('KYC 신청이 필요합니다.');
    return;
  }
  
  // 2. 락업 해제 확인 창 표시
  const confirmed = confirm(`
    락업을 해제 하시겠습니까?
    
    락업 해제 하시면 15일 후 자동으로 
    '나의 지갑', '사용가능 금액'으로 이동합니다.
    
    '단' '사용가능 금액'을 사용 하기 위해서는 
    KYC선택 후 KYC본인 인증을 승인 받아야 사용 가능합니다.
    
    현재 KYC 상태: ${kycStatus.isApproved ? '승인 완료' : '승인 대기 중'}
  `);
  
  if (confirmed) {
    // 3. 15일 후 이동 스케줄링
    setTimeout(() => {
      moveToAvailableBalance(amount, kycStatus.isApproved);
    }, 15 * 24 * 60 * 60 * 1000);
  }
};
```

### **🎯 5. 사용가능 금액 이동 시 KYC 확인:**
```typescript
const moveToAvailableBalance = (amount: number, isKYCApproved: boolean) => {
  // localStorage 업데이트
  const currentState = JSON.parse(localStorage.getItem('miningState') || '{}');
  const updatedState = {
    ...currentState,
    availableBalance: (currentState.availableBalance || 0) + amount,
    kycStatus: isKYCApproved ? 'approved' : 'pending'
  };
  localStorage.setItem('miningState', JSON.stringify(updatedState));
  
  // KYC 상태에 따른 알림
  if (isKYCApproved) {
    alert(`✅ 락업 금액 ${amount} BW가 사용가능 금액으로 이동되었습니다!\n\n사용 가능합니다.`);
  } else {
    alert(`✅ 락업 금액 ${amount} BW가 사용가능 금액으로 이동되었습니다!\n\n⚠️ KYC 승인 후 사용 가능합니다.`);
  }
};
```
