### 1. **문제점 발견 ✅**

```typescript
  if (referralCount <= 0) return 0;
  
  // 기본 채굴률: 0.25 BW/시간
  const baseRate = 0.25;
  
  if (referralCount <= 30) {
    return baseRate * 0.01875 * referralCount; // 1-30명: 1.875% × N명
  } else if (referralCount <= 60) {
    // 31-60명: 누적 + 추가 계산
    return baseRate * (0.01875 * 30 + 0.015 * (referralCount - 30));
  }
  // ... 구간별 누적 계산
};
```
