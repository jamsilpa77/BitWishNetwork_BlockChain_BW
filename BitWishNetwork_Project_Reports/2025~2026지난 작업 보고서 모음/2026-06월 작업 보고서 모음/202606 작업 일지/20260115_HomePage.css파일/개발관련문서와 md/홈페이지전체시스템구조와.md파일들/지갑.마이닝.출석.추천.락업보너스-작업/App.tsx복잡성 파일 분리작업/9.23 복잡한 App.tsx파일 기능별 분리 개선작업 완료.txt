## ❌ **문제 발견! 추천인 보너스 수치가 백서와 완전히 다릅니다!**

### **   백서 vs 현재 구현 비교**

#### **📋 백서의 정확한 수치 (1차 BitWishNetwork 백서)**
```
1~30명:   1.875% (0.01875) × N명 = 최대 56.25%
31~60명:  1.5% (0.015) × N명 = 최대 90%  
61~90명:  1.125% (0.01125) × N명 = 최대 101.25%
91명 이상: 0.75% (0.0075) × N명 = 무제한
```

#### **❌ 현재 구현의 잘못된 수치**
```
1~5명:    5% (0.05)
6~10명:   10% (0.1) 
11~20명:  15% (0.15)
21~50명:  20% (0.2)
51명 이상: 25% (0.25)
```

### **🚨 심각한 문제점들**

1. **구간별 수치 완전히 다름**: 백서는 4단계 구간, 현재는 5단계 구간
2. **보너스율 완전히 다름**: 백서는 1.875%~0.75%, 현재는 5%~25%
3. **계산 방식 다름**: 백서는 누적 계산, 현재는 단순 구간별 계산
4. **즉시 보너스 누락**: 백서는 1 BW 즉시 보너스 + 1.2% 영구 보너스

        localStorage.setItem(key, JSON.stringify(value));
        resolve(true);
      }, 0);
    });
  }
  
  static async getItem(key: string) {
    return new Promise((resolve) => {
      setTimeout(() => {
        const item = localStorage.getItem(key);
        resolve(item ? JSON.parse(item) : null);
      }, 0);
    });
  }
