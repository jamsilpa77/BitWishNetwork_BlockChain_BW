```typescript
// 라인 4000-4200: 기본 락업 등록 핸들러
const handleLockupRegistration = async () => {
  try {
    if (!authenticatedWalletAddress) {
      alert('지갑 주소가 필요합니다');
      return;
    }

    if (lockupRatio === 0 || lockupMonths === 0) {
      alert('락업 비율과 기간을 선택해주세요');
      return;
    }

    const response = await fetch('http://localhost:4001/lockup/create', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        walletAddress: authenticatedWalletAddress,
        userId: authenticatedWalletAddress,
        amount: 1000, // 기본 락업은 잔액 차감 없이 보너스만 적용
        lockPeriod: lockupMonths
      })
    });

    const result = await response.json();
    
    if (response.ok && result.success) {
      // 성공 시 등록 완료 처리
      setIsLockupRegistered(true);
      setRegisteredLockupData({
        ratio: lockupRatio,
        months: lockupMonths,
        apy: calculateLockupAPY(lockupMonths),
        startDate: new Date(),
        endDate: new Date(Date.now() + lockupMonths * 30 * 24 * 60 * 60 * 1000)
      });
      
      setSuccessMessage('✅ 기본 락업 설정 등록 완료!');
      setShowSuccessModal(true);
    }
  } catch (error) {
    console.error('기본 락업 설정 오류:', error);
    setSuccessMessage(`❌ 기본 락업 설정 오류: ${error instanceof Error ? error.message : '알 수 없는 오류'}`);
    setShowSuccessModal(true);
  }
};
```

### **🎯 전체 구조 개요**

**"락업 보너스 설정" 모달**은 두 개의 주요 섹션으로 구성되어 있습니다:
1. **기본 락업 설정** (Primary Lockup System)
2. **추가 락업 설정** (Secondary Lockup System)

---

### **🔒 1. 기본 락업 설정 (Primary Lockup System)**

#### **1.1 락업 비율 설정 (Lockup Ratio)**
- **UI 요소**: 슬라이더 (Range Input)
- **설정 가능한 값**: 20%, 50%, 75%, 100% (4단계)
- **제한사항**: 0%는 이동 불가, 창 열림 시 20% 고정
- **실시간 계산**: 선택된 비율에 따른 채굴률 증가 표시
- **상태 관리**: `lockupRatio` 상태 변수
- **비활성화 조건**: `isLockupRegistered`가 true일 때

#### **1.2 락업 기간 설정 (Lockup Period)**
- **UI 요소**: 클릭형 선택 버튼
- **설정 가능한 값**: 1개월, 6개월, 12개월, 36개월 (4단계)
- **APY 값**: 1개월(2.7%), 6개월(4.2%), 12개월(5.7%), 36개월(7.2%)
- **상태 관리**: `lockupMonths` 상태 변수
- **비활성화 조건**: `isLockupRegistered`가 true일 때

#### **1.3 실시간 계산 표시**
- **채굴률 계산**: `0.25 * (1 + APY * 락업비율)`
- **증가율 표시**: 기본 채굴률 대비 증가 퍼센트
- **APY 상세 정보**: 호버 시 상세 APY 정보 표시

#### **1.4 기본 락업 해제 버튼**
- **상태 관리**: `getLockupReleaseButtonState()` 함수
- **카운트다운**: 시한폭탄 스타일의 실시간 카운트다운
- **해제 조건**: KYC 승인 필요, 15일 후 사용 가능 금액으로 이동
- **버튼 상태**: 
  - 해제 가능: 녹색 버튼
  - 락업 중: 회색 비활성화 버튼 + 카운트다운

#### **1.5 설정 등록 버튼**
- **기능**: 기본 락업 설정을 실제로 등록
- **API 호출**: `http://localhost:4001/lockup/create`
- **등록 후**: 버튼 비활성화, "✅ 설정 완료" 표시
- **localStorage 저장**: 등록 정보 자동 저장

#### **1.6 테스트용 기능들**
- **테스트 지갑 생성**: 가상 Stellar G 지갑 생성
- **지갑 관리**: 테스트 지갑 목록 관리
- **락업 초기화**: 테스트용 락업 설정 초기화

### **📊 5. 계산 시스템**

#### **5.1 기본 락업 계산**
- **공식**: `총_노드_보상 × (1 + APY × 락업비율)`
- **APY**: 기간별 차등 (1개월: 2.7%, 6개월: 4.2%, 12개월: 5.7%, 36개월: 7.2%)
- **실시간 계산**: 설정 변경 시 즉시 계산 결과 표시

#### **5.2 추가 락업 계산**
- **공식**: `기본_락업_남은_금액 × 추가_락업_비율 × APY`
- **APY**: 기간별 차등 (3개월: 2.1%, 6개월: 3.5%, 12개월: 4.9%, 36개월: 7.5%)
- **계산 기준**: 기본 락업에서 남은 BW 기준
