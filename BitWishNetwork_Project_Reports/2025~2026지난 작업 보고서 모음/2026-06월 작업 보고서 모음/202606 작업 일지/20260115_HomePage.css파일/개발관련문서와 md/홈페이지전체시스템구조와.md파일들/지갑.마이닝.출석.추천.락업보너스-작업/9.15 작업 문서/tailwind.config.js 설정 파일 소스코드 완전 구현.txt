## **1.    컨텐츠 경로 설정**
```javascript
content: [
  "./index.html",
  "./src/**/*.{js,ts,jsx,tsx}",
  "./public/**/*.html",
  "./node_modules/react-flow-renderer/dist/esm/**/*.js",
  "./node_modules/@headlessui/react/**/*.js",
  "./node_modules/@heroicons/react/**/*.js"
]
```
- **목적**: Tailwind가 CSS 클래스를 찾을 파일 경로 지정
- **포함**: React 컴포넌트, HTML 파일, 외부 라이브러리 컴포넌트
- **효과**: 사용하지 않는 CSS 자동 제거로 번들 크기 최적화

## **2.    다크 모드 설정**
```javascript
darkMode: 'class'
```
- **방식**: 클래스 기반 다크 모드
- **사용법**: `<html class="dark">`로 다크 모드 활성화
- **장점**: JavaScript로 동적 전환 가능

## **3.    BitWish 브랜드 컬러**
```javascript
primary: {
  50: '#eff6ff',   // 가장 밝은 파란색
  500: '#3b82f6',  // 메인 블루
  900: '#1e3a8a'   // 가장 어두운 파란색
}
```
- **체계**: 50-900 단계별 색상 팔레트
- **용도**: 버튼, 링크, 강조 요소에 사용
- **일관성**: 브랜드 아이덴티티 유지

## **4.    스텔라 블록체인 컬러**
```javascript

  500: '#0ea5e9',  // 스텔라 메인 컬러
  700: '#0369a1'   // 스텔라 어두운 컬러

```
- **목적**: 스텔라 블록체인 연동 UI 구분
- **사용처**: 지갑, 트랜잭션 관련 컴포넌트

## **5. 🎯 상태별 컬러 시스템**

- **용도**: 알림, 상태 표시, 피드백
- **접근성**: 색상만으로는 의미 전달하지 않고 텍스트와 함께 사용
