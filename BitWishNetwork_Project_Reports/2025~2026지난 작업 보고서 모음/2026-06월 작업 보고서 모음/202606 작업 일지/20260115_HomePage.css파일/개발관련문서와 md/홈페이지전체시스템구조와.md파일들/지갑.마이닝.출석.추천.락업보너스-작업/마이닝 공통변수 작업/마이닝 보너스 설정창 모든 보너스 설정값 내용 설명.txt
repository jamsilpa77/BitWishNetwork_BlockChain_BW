## ** 마이닝 보너스 시스템 완전 분석 보고서 (수정판)**

### ** 1. 출석 보너스 단순화 (백서 기준 변경)**
```
기존 백서: 단계별 출석 보너스 (1일 2%, 7일 3.5% 등)
신규 단순화: 매일 5% 고정 보너스
```

### ** 2. 출석 체크 시간 제한 시스템**

#### **A. 활성화 시간:**
- **시작**: 당일 오전 9시 정각
- **종료**: 다음날 오전 8시 59분 59초
- **총 시간**: 23시간 59분 59초

#### **B. 달력 상태 변화:**
- **활성화**: 파란색 (클릭 가능)
- **비활성화**: 회색 (클릭 불가) - 출석하지 않은 날짜
- **출석 완료**: 빨간색 (클릭 불가) - 출석한 날짜는 영원히 빨간색
- **자동 전환**: 매일 오전 9시 정각에 전날 비활성화, 당일 활성화

### ** 3. 출석 체크 보너스 적용**

#### **A. 보너스 획득 조건:**
- **시간 내 체크**: 오전 9시 ~ 다음날 오전 8시 59분 59초
- **보너스율**: 5% (24시간 고정)
- **적용 방식**: 기본 채굴률에 곱하여 반영

#### **B. 보너스 초기화:**
- **초기화 시간**: 매일 오전 9시 정각
- **초기화 후**: 당일 날짜 활성화
- **연속성**: 전날 출석하지 않아도 당일 출석 가능

### ** 4. 출석 체크 시나리오**

#### **시나리오 1: 정상 출석**
```
1일 오전 9시 → 1일 날짜 활성화 (파란색)
1일 오후 3시 → 출석 체크 → 5% 보너스 획득 → 1일 날짜 빨간색으로 변경
2일 오전 8시 59분 59초 → 여전히 5% 보너스 유지
2일 오전 9시 정각 → 1일 날짜 비활성화 (빨간색 - 출석 완료), 2일 날짜 활성화 (파란색)
```

#### **시나리오 2: 출석 실패**
```
1일 오전 9시 → 1일 날짜 활성화 (파란색)
1일 하루 종일 → 출석 체크 안함
2일 오전 9시 정각 → 1일 날짜 비활성화 (회색 - 출석 실패), 2일 날짜 활성화 (파란색)
2일 오전 10시 → 2일 출석 체크 → 5% 보너스 획득 → 2일 날짜 빨간색으로 변경
```

### ** 5. 락업 보너스 시스템 (백서 기준)**

#### **A. 기본 락업 보너스:**
```
기본값: 0.000000% (고정 시작)
설정 후: 백서 기준 16가지 선택에 따른 실시간 반영
```
- **설정창**: "락업 보너스 설정" → "기본 락업 설정"

- **표시**: "보너스 상태 확인" 창 "기본 락업 보너스" %와 "기본 락업 보관함 BW"

#### **B. 추가 락업 보너스:**
```
기본값: 0.000000% (고정 시작)
설정 후: 백서 기준 설정값에 따른 실시간 반영
```
- **설정창**: "락업 보너스 설정" → "추가 락업 설정"
- **실시간 반영**: "설정 등록" 버튼 클릭 시 즉시 적용
- **표시**: "보너스 상태 확인" 창 "추가 락업 보너스" %와 "추가 락업 보관함 BW"

### ** 6. 추천 보너스 시스템 (백서 기준)**
```
기본값: 모든 항목 0 (고정 시작)
가입 발생 시: 백서 기준 실시간 반영
```
- **트리거**: 본인 추천코드로 가입자 발생
- **반영**: 즉시 백서 기준 설정값으로 실시간 적용
- **창**: "추천 보너스 상황" 창에서 확인
- **백서 기준**: 4단계 누적 보너스 시스템, 즉시 보너스, 영구 보너스 (1.2% 고정)

### ** 7. 실시간 반영 시스템**
```
출석 체크 → 즉시 5% 보너스 적용
락업 설정 → 즉시 백서 기준 보너스 적용
추천인 가입 → 즉시 백서 기준 보너스 적용
↓
기본 채굴률 (0.25 BW/시간) × (1 + 출석보너스 + 락업보너스 + 추천보너스)
↓
일일 보상 = 시간당 보상 × 24시간
↓
"마이닝 상태 확인" 창에 실시간 반영
↓
"실시간 마이닝 보상" 창에 누적 보상 계산 (50단위 부동소수점)
```

```typescript
  onAttendanceCheck: (date: string) => void;

  checkedDates,

}) => {
  const [today, setToday] = useState(new Date());
  const [activeDate, setActiveDate] = useState<string | null>(null);

  //    출석 가능 시간 체크 (오전 9시 ~ 다음날 오전 8시 59분 59초)
  const isAttendanceTimeValid = (date: string): boolean => {
    const targetDate = new Date(date);
    const now = new Date();
    const today9AM = new Date(now.getFullYear(), now.getMonth(), now.getDate(), 9, 0, 0);
    const tomorrow9AM = new Date(today9AM.getTime() + 24 * 60 * 60 * 1000);
    
    return now >= today9AM && now < tomorrow9AM && targetDate.toDateString() === now.toDateString();
  };

  //    달력 날짜 상태 결정
  const getDateStatus = (date: string): 'active' | 'inactive' | 'checked' => {

    if (isAttendanceTimeValid(date)) return 'active'; // 파란색 (출석 가능)
    return 'inactive'; // 회색 (출석 불가)
  };

  // 🎯 출석 체크 핸들러
  const handleAttendanceCheck = (date: string) => {
    if (getDateStatus(date) === 'active') {
      onAttendanceCheck(date);
      setActiveDate(date);
    }
  };

  return (
    <div className="attendance-calendar">
      {/* 달력 UI 구현 */}
      {calendarDates.map((date) => (
        <div
          key={date}
          className={`calendar-date ${getDateStatus(date)}`}

        </div>
      ))}
    </div>
  );
};
```

```typescript
    const checkedDates = JSON.parse(localStorage.getItem('attendanceCheckedDates') || '[]');
    if (!checkedDates.includes(date)) {
      checkedDates.push(date);
      localStorage.setItem('attendanceCheckedDates', JSON.stringify(checkedDates));
    }
  }

  // 🎯 출석 체크된 날짜 목록 조회
  static getCheckedDates(): string[] {
    return JSON.parse(localStorage.getItem('attendanceCheckedDates') || '[]');
  }
```

#### **B. 락업 보너스 서비스 수정**
```typescript
// Node_HomePage/src/services/lockupService.ts
export class LockupService {
  // 🎯 기본 락업 보너스 계산 (백서 기준)
  static calculateBasicLockupBonus(ratio: number, months: number): {
    apy: number;
    totalAPY: number;
    monthlyRate: number;
    enhancedRate: number;
    description: string;
    lockedAmount: number;
  } {
    if (ratio === 0 || months === 0) {
      return {
        apy: 0,
        totalAPY: 0,
        monthlyRate: 0,
        enhancedRate: 0.25,
        description: '락업하지 않음',
        lockedAmount: 0
      };
    }

    // 🎯 백서 기준 APY 계산
    let baseAPY = 0;
    if (months >= 36) {
      baseAPY = 0.072; // 7.2%
    } else if (months >= 12) {
      baseAPY = 0.057; // 5.7%
    } else if (months >= 6) {
      baseAPY = 0.042; // 4.2%
    } else {
      baseAPY = 0.027; // 2.7%
    }

    const ratioBonus = ratio * 0.01; // 1% per 1% ratio
    const totalAPY = baseAPY + ratioBonus;
    const monthlyRate = totalAPY / 12;
    const enhancedRate = 0.25 * (1 + totalAPY * (ratio / 100));

    // 🎯 락업된 금액 계산 (예시: 총 보유량의 비율)
    const totalBalance = this.getTotalBalance();
    const lockedAmount = totalBalance * (ratio / 100);

    return {
      apy: baseAPY,
      totalAPY: totalAPY,
      monthlyRate: monthlyRate,
      enhancedRate: enhancedRate,
      description: `${months}개월 락업 (${(totalAPY * 100).toFixed(1)}% APY)`,
      lockedAmount: lockedAmount
    };
  }

  // 🎯 추가 락업 보너스 계산
  static calculateAdditionalLockupBonus(ratio: number, months: number): {
    apy: number;
    totalAPY: number;
    monthlyRate: number;
    enhancedRate: number;
    description: string;
    lockedAmount: number;
  } {
    // 기본 락업과 동일한 로직
    return this.calculateBasicLockupBonus(ratio, months);
  }

  // 🎯 락업 설정 저장
  static saveLockupSettings(type: 'basic' | 'additional', ratio: number, months: number): void {
    const key = `lockup_${type}_settings`;
    const settings = { ratio, months, timestamp: Date.now() };
    localStorage.setItem(key, JSON.stringify(settings));
  }

  // 🎯 락업 설정 로드
  static loadLockupSettings(type: 'basic' | 'additional'): { ratio: number; months: number } | null {
    const key = `lockup_${type}_settings`;
    const settings = localStorage.getItem(key);
    return settings ? JSON.parse(settings) : null;
  }

  // 🎯 총 보유량 조회 (예시)
  private static getTotalBalance(): number {
    return parseFloat(localStorage.getItem('totalBalance') || '0');
  }
}
```

### ** 4. 실시간 마이닝 보상 계산 시스템**

#### **A. 마이닝 보상 계산 서비스**
```typescript
// Node_HomePage/src/services/miningRewardService.ts
export class MiningRewardService {
  // 🎯 실시간 마이닝 보상 계산 (50단위 부동소수점)
  static calculateMiningReward(
    startTime: Date,
    baseRate: number = 0.25,
    attendanceBonus: number = 0,
    referralBonus: number = 0,
    lockupBonus: number = 0,
    franchiseBonus: number = 0
  ): {
    elapsedTime: number; // 진행 시간 (초)
    hourlyReward: number; // 시간당 보상
    dailyReward: number; // 일일 보상
    totalReward: number; // 누적 보상
    bonusBreakdown: {
      base: number;
      attendance: number;
      referral: number;
      lockup: number;
      franchise: number;
      total: number;
    };
  } {
    const now = new Date();
    const elapsedTime = Math.floor((now.getTime() - startTime.getTime()) / 1000); // 초 단위

    // 🎯 총 보너스율 계산
    const totalBonusRate = attendanceBonus + referralBonus + lockupBonus + franchiseBonus;
    
    // 🎯 최종 채굴률 계산
    const finalMiningRate = baseRate * (1 + totalBonusRate);
    
    //    시간당 보상 계산 (50단위 부동소수점)
    const hourlyReward = this.roundToPrecision(finalMiningRate, 50);
    
    // 🎯 일일 보상 계산
    const dailyReward = this.roundToPrecision(hourlyReward * 24, 50);
    
    // 🎯 누적 보상 계산
    const totalReward = this.roundToPrecision(
      (hourlyReward * elapsedTime) / 3600, // 시간당 보상 × 경과 시간(시간)
      50
    );

    // 🎯 보너스 세부 내역
    const bonusBreakdown = {
      base: this.roundToPrecision(baseRate, 50),
      attendance: this.roundToPrecision(baseRate * attendanceBonus, 50),
      referral: this.roundToPrecision(baseRate * referralBonus, 50),
      lockup: this.roundToPrecision(baseRate * lockupBonus, 50),
      franchise: this.roundToPrecision(baseRate * franchiseBonus, 50),
      total: this.roundToPrecision(baseRate * totalBonusRate, 50)
    };

    return {
      elapsedTime,
      hourlyReward,
      dailyReward,
      totalReward,
      bonusBreakdown
    };
  }

  // 🎯 50단위 부동소수점 반올림
  private static roundToPrecision(value: number, precision: number = 50): number {
    const factor = Math.pow(10, precision);
    return Math.round(value * factor) / factor;
  }

  // 🎯 시간 포맷팅 (HH:MM:SS)
  static formatTime(seconds: number): string {
    const hours = Math.floor(seconds / 3600);
    const minutes = Math.floor((seconds % 3600) / 60);
    const secs = seconds % 60;
    
    return `${hours.toString().padStart(2, '0')}:${minutes.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`;
  }
}
```
