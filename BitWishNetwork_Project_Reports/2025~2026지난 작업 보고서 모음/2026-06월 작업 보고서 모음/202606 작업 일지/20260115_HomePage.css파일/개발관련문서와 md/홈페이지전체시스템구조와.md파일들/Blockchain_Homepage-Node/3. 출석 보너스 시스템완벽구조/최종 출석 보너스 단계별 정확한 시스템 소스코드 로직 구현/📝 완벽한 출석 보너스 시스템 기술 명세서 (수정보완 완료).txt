## **📝 완벽한 출석 보너스 시스템 기술 명세서 (수정/보완)**

### **   1. 정밀 시간 제어 시스템 (Precision Time Control System)**

#### **1.1 출석 활성화 시간 제어 (정확한 구현)**
```typescript
// 출석 체크 활성화 조건 (정확한 시간 범위)
const isAttendanceTimeValid = (targetDate?: Date): boolean => {
  const koreanTime = getKoreanTime();
  const currentTime = koreanTime.getTime();
  const checkDate = targetDate || new Date();
  
  // 전날 AM 09:00:00 계산
  const yesterday = new Date(checkDate);
  yesterday.setDate(yesterday.getDate() - 1);
  yesterday.setHours(9, 0, 0, 0); // AM 09:00:00
  
  // 다음날 AM 08:59:59 계산
  const tomorrow = new Date(checkDate);
  tomorrow.setDate(tomorrow.getDate() + 1);
  tomorrow.setHours(8, 59, 59, 999); // AM 08:59:59
  
  // 현재 시간이 정확한 범위 내인지 확인
  return currentTime >= yesterday.getTime() && currentTime <= tomorrow.getTime();
};
```

**핵심 특징:**
- **활성화 시간**: 전날 AM 09:00:00 ~ 다음날 AM 08:59:59
- **정밀도**: 밀리초 단위 정확한 시간 제어
- **1초만 남아도**: 출석 체크 가능하고 보너스 적용
- **실시간 검증**: 1초마다 정확한 시간 범위 체크

### **   2. 24시간 유예 기간 시스템 (24-Hour Grace Period System)**

#### **2.1 24시간 유예 기간 정확한 로직**
```typescript
// 24시간 유예 기간 계산 (관리자용)
const isAdminWithin24HoursFromLastAttendance = (): boolean => {
  const koreanTime = getKoreanTime();
  const now = koreanTime.getTime();
  
  const lastAttendanceDate = getAdminLastAttendanceDate();
  if (!lastAttendanceDate) return false;
  
  // 24시간 = 86,400,000ms (정확한 밀리초 계산)
  const twentyFourHours = 24 * 60 * 60 * 1000;
  const timeDiff = now - lastAttendanceDate.getTime();
  
  return timeDiff <= twentyFourHours;
};

// 24시간 유예 기간 계산 (유저용)
const isUserWithin24HoursFromLastAttendance = (): boolean => {

  if (!lastAttendanceDate) return false;

  const twentyFourHours = 24 * 60 * 60 * 1000;
  const timeDiff = now - lastAttendanceDate.getTime();
  
  return timeDiff <= twentyFourHours;
};
```

**핵심 특징:**
- **24시간 유예**: 연속성 상실 시 24시간 회복 기회 제공
- **정확한 계산**: 밀리초 단위 정밀한 시간 차이 계산
- **관리자용/유저용 분리**: 각각 독립적인 유예 기간 관리

#### **7.2 출석 보너스 정밀 계산 (정확한 구현)**
```typescript
// 관리자용 출석 보너스 계산 (완벽한 부동소수점 처리)
const calculateAdminAttendanceBonus = (consecutiveDays: number): { 
  bonusRate: number; 
  enhancedRate: number; 
  description: string;
  decimalBonusRate: Decimal;
  decimalEnhancedRate: Decimal;
} => {
  if (consecutiveDays >= 30) {
    const decimalBonusRate = new Decimal(0.17); // 17% (30일 이상)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 최고 등급 지속 참여자',
      decimalBonusRate,
      decimalEnhancedRate
    };
  } else if (consecutiveDays >= 29) {
    const decimalBonusRate = new Decimal(0.12); // 12% (29일)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 장기 참여자 보상',
      decimalBonusRate,
      decimalEnhancedRate
    };
  } else if (consecutiveDays >= 22) {
    const decimalBonusRate = new Decimal(0.068); // 6.8% (22일 이상)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 꾸준한 참여 보상',
      decimalBonusRate,
      decimalEnhancedRate
    };
  } else if (consecutiveDays >= 15) {
    const decimalBonusRate = new Decimal(0.05); // 5% (15일 이상)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 중간 참여자 보상',
      decimalBonusRate,

    };
  } else if (consecutiveDays >= 8) {

    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 초기 참여자 보상',
      decimalBonusRate,
      decimalEnhancedRate
    };
  } else if (consecutiveDays >= 1) {
    const decimalBonusRate = new Decimal(0.02); // 2% (1일 이상)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 신규 참여자 보상',
      decimalBonusRate,
      decimalEnhancedRate
    };
  } else {
    const decimalBonusRate = new Decimal(0); // 0%
    const decimalEnhancedRate = new Decimal(0.25); // 기본값
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: '❌ 출석 보너스 없음 (0일)',
```
