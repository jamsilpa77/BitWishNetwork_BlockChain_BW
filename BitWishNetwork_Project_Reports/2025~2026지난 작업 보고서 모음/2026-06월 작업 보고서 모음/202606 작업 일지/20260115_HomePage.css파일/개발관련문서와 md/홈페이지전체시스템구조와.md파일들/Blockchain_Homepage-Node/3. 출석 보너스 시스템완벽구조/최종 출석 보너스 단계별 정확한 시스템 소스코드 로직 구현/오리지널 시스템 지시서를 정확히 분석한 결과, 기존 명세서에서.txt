### **   1. 정밀 시간 제어 시스템 (Precision Time Control System)**

#### **1.1 출석 활성화 시간 제어 (정확한 구현)**
```typescript
// 출석 체크 활성화 조건 (정확한 시간 범위)
const isAttendanceTimeValid = (targetDate?: Date): boolean => {
  const koreanTime = getKoreanTime();
  const currentTime = koreanTime.getTime();
  const checkDate = targetDate || new Date();
  
  // 전날 AM 09:00:00 계산
  const yesterday = new Date(checkDate);
  yesterday.setDate(yesterday.getDate() - 1);
  yesterday.setHours(9, 0, 0, 0); // AM 09:00:00
  
  // 다음날 AM 08:59:59 계산
  const tomorrow = new Date(checkDate);
  tomorrow.setDate(tomorrow.getDate() + 1);
  tomorrow.setHours(8, 59, 59, 999); // AM 08:59:59
  
  // 현재 시간이 정확한 범위 내인지 확인
  return currentTime >= yesterday.getTime() && currentTime <= tomorrow.getTime();
};
```

**핵심 특징:**
- **활성화 시간**: 전날 AM 09:00:00 ~ 다음날 AM 08:59:59
- **정밀도**: 밀리초 단위 정확한 시간 제어
- **1초만 남아도**: 출석 체크 가능하고 보너스 적용
- **실시간 검증**: 1초마다 정확한 시간 범위 체크

#### **7.2 출석 보너스 정밀 계산 (정확한 구현)**
```typescript
// 관리자용 출석 보너스 계산 (완벽한 부동소수점 처리)
const calculateAdminAttendanceBonus = (consecutiveDays: number): { 
  bonusRate: number; 
  enhancedRate: number; 
  description: string;
  decimalBonusRate: Decimal;
  decimalEnhancedRate: Decimal;
} => {
  if (consecutiveDays >= 30) {
    const decimalBonusRate = new Decimal(0.17); // 17% (30일 이상)
    const decimalEnhancedRate = new Decimal(0.25).times(new Decimal(1).plus(decimalBonusRate));
    return {
      bonusRate: decimalBonusRate.toDecimalPlaces(8).toNumber(),
      enhancedRate: decimalEnhancedRate.toDecimalPlaces(8).toNumber(),
      description: ' 최고 등급 지속 참여자',
      decimalBonusRate,
      decimalEnhancedRate
    };
```
