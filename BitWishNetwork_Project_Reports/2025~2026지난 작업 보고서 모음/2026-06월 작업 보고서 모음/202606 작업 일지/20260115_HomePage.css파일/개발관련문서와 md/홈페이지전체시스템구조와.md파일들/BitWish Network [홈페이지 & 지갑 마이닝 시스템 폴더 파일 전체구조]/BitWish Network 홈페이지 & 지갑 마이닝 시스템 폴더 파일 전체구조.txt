### **5. 핵심 기능별 파일 분류**

#### **5.1 지갑 시스템**
- **생성**: `WalletCreation.tsx` (3단계 프로세스)
- **관리**: `WalletBalance.tsx` (잔액, QR코드, 거래)
- **복구**: `WalletRecovery.tsx` (시드문구로 복구)
- **설정**: `WalletSettings.tsx` (지갑 설정)
- **거래**: `WalletTransaction.tsx` (송금/받기)

#### **5.2 마이닝 시스템**
- **사용자 마이닝**: `UserLockupBonus.tsx`, `UserHalvingSystem.tsx`
- **마이닝 서비스**: `miningService.ts`
- **마이닝 상태**: `useMiningState.ts`

#### **5.3 보너스 시스템**
- **출석 보너스**: `attendanceService.ts`, `useAttendanceSystem.ts`
- **추천 보너스**: `referralService.ts`, `useReferralSystem.ts`
- **락업 보너스**: `lockupService.ts`, `useLockupSystem.ts`

#### **5.4 다국어 지원**
- **설정**: `i18n/index.ts`
- **언어 파일**: `locales/ko.json`, `en.json`, `zh.json`, `ja.json`

### **6. API 엔드포인트 구조**
```
simple-server.js (포트 4001)
├── POST /wallet/create           # 지갑 생성
├── GET /wallet/balance           # 잔액 조회
├── GET /wallet/transactions      # 트랜잭션 조회
├── POST /wallet/send             # 송금
├── POST /wallet/recover          # 지갑 복구
├── POST /wallet/kyc              # KYC 인증
├── POST /wallet/otp              # OTP 설정
└── GET /health                   # 헬스 체크
```

### **7. 개발 환경 설정**
- **프론트엔드**: Vite + React + TypeScript + Tailwind CSS
- **백엔드**: Node.js + Express + Stellar SDK
- **데이터베이스**: MongoDB (로컬)
- **다국어**: react-i18next
- **상태관리**: React Hooks

### **8. 빌드 및 배포**
- **개발 서버**: `npm run dev` (포트 4000)
- **백엔드 서버**: `node simple-server.js` (포트 4001)
- **빌드**: `npm run build`
- **배포**: `dist/` 폴더

이 구조는 홈페이지와 지갑 마이닝 시스템을 완벽하게 지원하는 모듈화된 아키텍처입니다.
