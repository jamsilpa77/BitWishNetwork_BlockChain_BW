# 🔐 BitWish Network 지갑 시스템 완전 가이드

## 📋 전체 시스템 구조 개요

BitWish Network의 지갑 시스템은 **홈페이지 상단 지갑 이모지(💼) 클릭**부터 시작하여 **"나의 지갑" 페이지**까지 이어지는 완전한 워크플로우를 제공합니다.

### 🎯 핵심 워크플로우
1. **홈페이지** → 💼 지갑 이모지 클릭
2. **지갑 드롭다운** → "지갑 만들기" 또는 "나의 지갑" 선택
3. **지갑 만들기** → 4단계 지갑 생성 과정
4. **지갑 인증** → 3단계 인증 과정 (기존 지갑 접근시)
5. **나의 지갑** → 4개 탭으로 구성된 지갑 관리 페이지

#### **2단계: 시드문구 생성 (seedphrase)**
```tsx
const handleStartWalletCreation = async () => {
  try {
    setIsLoading(true);
    setError('');
    setSecurityWarnings([]);

    // 보안 경고 메시지 설정 (4개국 언어)
    const warnings = [
      t('wallet.securityWarning1', '시드문구는 절대 다른 사람과 공유하지 마세요.'),
      t('wallet.securityWarning2', '시드문구를 안전한 곳에 저장하세요.'),
      t('wallet.securityWarning3', '시드문구를 분실하면 지갑을 복구할 수 없습니다.'),
      t('wallet.securityWarning4', '화면을 스크린샷으로 저장하지 마세요.')
    ];
    setSecurityWarnings(warnings);

    // 24단어 BIP39 시드문구 생성
    const seedPhrase = await generateStellarSeedPhrase();
    
    // 검증 인덱스 랜덤 생성 (4개 단어)
    const indices: number[] = [];
    while (indices.length < 4) {
      const randomIndex = Math.floor(Math.random() * 24);
      if (!indices.includes(randomIndex)) {
        indices.push(randomIndex);
      }
    }
    indices.sort((a: number, b: number) => a - b);
    setVerificationIndices(indices);
    setVerificationInputs(['', '', '', '']);

    // 지갑 데이터 업데이트
    setWalletData(prev => ({
      ...prev,
      seedPhrase: seedPhrase,
      createdAt: new Date().toISOString()
    }));

    setCurrentStep('seedphrase');
    setSuccess(t('wallet.seedPhraseGenerated', '시드문구가 성공적으로 생성되었습니다.'));
  } catch (error) {
    setError(error instanceof Error ? error.message : t('wallet.errors.walletCreationFailed', '지갑 생성에 실패했습니다'));
  } finally {
    setIsLoading(false);
  }
};
```

**핵심 기능:**
- **24단어 BIP39 시드문구 생성**: `generateStellarSeedPhrase()`
- **보안 경고 메시지 표시**: 4개국 언어 지원
- **랜덤 검증 인덱스 생성**: 4개 단어를 랜덤 선택
- **시드문구 표시 화면으로 이동**

#### **검증 완료 처리:**
```tsx
const handleVerificationComplete = async () => {
  try {
    setIsLoading(true);
    setError('');

    // 검증 입력 검증
    const validation = validateVerificationInputs();
    if (!validation.isValid) {
      setError(validation.error || t('wallet.errors.verificationFailed', '검증에 실패했습니다'));
      return;
    }

    // 스텔라 블록체인 지갑 생성
    const walletInfo = await createStellarWallet(walletData.seedPhrase);
    
    // 추천코드 생성
    const referralCode = referralInput && referralInput.trim() !== '' 
      ? await validateAndGenerateReferralCode(walletInfo.walletAddress, referralInput)
      : '';

    // 최종 지갑 데이터 업데이트
    const finalWalletData: PerfectWalletData = {
      ...walletData,
      publicKey: walletInfo.publicKey,
      privateKey: walletInfo.privateKey,
      walletAddress: walletInfo.walletAddress,
      referralCode: referralCode
    };

    setWalletData(finalWalletData);
    setCurrentStep('myWallet');
    setSuccess(t('wallet.creationComplete', '지갑이 성공적으로 생성되었습니다!'));

  } catch (error) {
    if (error instanceof Error && error.message.includes('referralCodeValidationFailed')) {
      setError(t('wallet.referralCodeValidationFailed', '추천코드 검증에 실패했습니다'));
    } else {
      setError(error instanceof Error ? error.message : t('wallet.errors.verificationFailed', '검증에 실패했습니다'));
    }
  } finally {
    setIsLoading(false);
  }
};
```

**핵심 기능:**
- **검증 입력 정확성 확인**
- **스텔라 블록체인 지갑 생성**: `createStellarWallet()`

#### **인증 처리 로직:**
```tsx
const handleAuthentication = async () => {
  try {
    setIsLoading(true);
    setError('');

    // 차단 상태 확인
    if (isBlocked) {
      setError(t('auth.accountBlocked', '계정이 일시적으로 차단되었습니다. 잠시 후 다시 시도해주세요.'));
      return;
    }

    // 최대 시도 횟수 확인
    if (authData.loginAttempts >= authData.maxAttempts) {
      setIsBlocked(true);
      setBlockTimeRemaining(300); // 5분 차단
      setError(t('auth.maxAttemptsReached', '최대 시도 횟수를 초과했습니다. 5분 후 다시 시도해주세요.'));
      return;
    }

    // 비밀번호 인증
    const authResult = await authenticatePassword(authData.walletAddress, authData.password);
    
    if (authResult.isValid) {
      // 성공 시 로그인 시도 기록 업데이트
      await updateLoginAttempts(authData.walletAddress, true);
      
      setAuthData(prev => ({
        ...prev,
        userType: authResult.userType,
        isAuthenticated: true,
        lastLogin: new Date().toISOString(),
        loginAttempts: 0
      }));
      
      setCurrentStep('success');
      setSuccess(t('auth.authSuccess', '인증이 성공적으로 완료되었습니다!'));
    } else {
      // 실패 시 로그인 시도 기록 업데이트
      await updateLoginAttempts(authData.walletAddress, false);
      
      setAuthData(prev => ({
        ...prev,
        loginAttempts: prev.loginAttempts + 1
      }));
      
      setError(t('auth.authFailed', '인증에 실패했습니다. 지갑 주소와 2차 비밀번호를 확인해주세요.'));
    }
  } catch (error) {
    setError(error instanceof Error ? error.message : t('auth.authError', '인증 중 오류가 발생했습니다.'));
  } finally {
    setIsLoading(false);
  }
};
```
