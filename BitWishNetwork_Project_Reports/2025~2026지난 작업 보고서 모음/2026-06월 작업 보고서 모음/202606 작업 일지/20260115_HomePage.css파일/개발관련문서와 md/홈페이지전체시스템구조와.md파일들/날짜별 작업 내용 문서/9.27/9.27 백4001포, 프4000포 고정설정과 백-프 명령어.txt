1. **포트 검증 미들웨어**: 다른 포트 접근 시 403 에러
2. **CORS 제한**: 포트 4000만 허용

4. **포트 보호 스크립트**: `port-protection.js`

### **🚀 실행 명령어:**

```powershell
# 1. 포트 보호 모드로 실행 (권장)
npm run start:protected

# 2. 개별 실행
npm run backend    # 백엔드만 (4001포트)
npm run frontend   # 프론트엔드만 (4000포트)

# 3. 수동 실행
node simple-server-new.js  # 백엔드
npm run dev               # 프론트엔드
```

- ✅ 다른 포트 사용 완전 차단

- ✅ 허용된 포트만 접근 가능
- ✅ CORS로 프론트엔드 포트만 허용
