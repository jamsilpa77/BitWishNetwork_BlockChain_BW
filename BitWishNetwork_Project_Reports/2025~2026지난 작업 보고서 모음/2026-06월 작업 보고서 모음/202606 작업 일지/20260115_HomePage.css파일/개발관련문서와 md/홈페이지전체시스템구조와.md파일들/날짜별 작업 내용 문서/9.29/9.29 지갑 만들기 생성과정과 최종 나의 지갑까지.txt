## 🔍 **시스템 구조 완전 분석**

### **1단계: 스텔라 오리지널 지갑 생성**
- **위치**: 홈페이지 상단 네비게이션 지갑 이모지 → "지갑 만들기"
- **기술 명세**:
  - **BIP39 표준**: 24단어 시드문구 생성 (업계 표준)
  - **Stellar SDK**: 공개키/비밀키 쌍 생성
  - **클라이언트 측 생성**: 서버는 절대 비밀키를 저장하지 않음
  - **AES-256 암호화**: 시드문구를 안전하게 로컬 저장
- **진행 과정**:
  1. 24단어 BIP39 시드문구 자동 생성
  2. 시드문구 확인 (4개 단어 검증)
  3. Stellar 키페어 생성
  4. 지갑 생성 완료 및 마이닝 시작

### **2단계: 추천코드 발급 시스템**
- **위치**: "나의 지갑" → "추천 보너스"창
- **기능**: bitwishnetwork에 인증된 노드 마이닝 채굴 페이지에서 추천코드 발급
- **개인별 분리**: 지갑 주소별 완전 독립 시스템

### **3단계: 2차 비밀번호 설정**
- **진입**: "마이닝 & 보너스"버튼 → "지갑 주소 인증" → "2차 비밀번호설정"
- **입력 항목**:
  - 스텔라 블록체인 오리지널 발급된 지갑 주소
  - 2차 비밀번호
  - 비밀번호 확인
- **보안**: Google OTP 2단계 인증으로 추가 보안 강화

### **4단계: 지갑 주소 인증**
- **입력 항목**:
  - 2차 비밀번호 설정 시 사용한 오리지널 지갑 주소
  - 비밀번호
- **결과**: 즉시 유저 마이닝 페이지로 진입

### **5단계: 개인별 노드 채굴 마이닝 페이지 진입**
- **대상**: 유저(나만의 채굴 노드 마이닝 페이지)
- **기능**: 마이닝 시작 버튼 클릭
- **결과**: "마이닝 보너스 설정"창 전체 시스템구조와 소스코드 로직으로 구현된 노드 채굴형 마이닝 페이지에서 BW포인트 채굴

- **파일**: `Node_HomePage/simple-server-new.js` 수정
- **구현 내용**:
  ```javascript
  // POST /user/mining/start/:walletAddress - 마이닝 시작
  app.post('/user/mining/start/:walletAddress', async (req, res) => {
    try {
      const { walletAddress } = req.params;
      
      // 마이닝 상태 확인
      const existingMining = userMiningStates.get(walletAddress);
      if (existingMining && existingMining.isMining) {
        return res.json({ success: false, error: '이미 마이닝 중입니다.' });
      }

      // 마이닝 시작
      const miningData = {
        walletAddress,
        isMining: true,
        startTime: new Date().toISOString(),
        totalRewards: '0',
        miningRate: '0.25'
      };

      userMiningStates.set(walletAddress, miningData);

      res.json({ 
        success: true, 
        message: '마이닝이 시작되었습니다.',
        data: miningData
      });
    } catch (error) {
      res.status(500).json({ success: false, error: error.message });
    }
  ```

  ```typescript
  const LOCKUP_POLICY = {
    basicLockupRate: 0.20,        // 기본락업 20%
    additionalLockupRate: 0.25,   // 추가락업 25%
    basicAPY: 0.027,              // 기본락업 APY 2.7%
    additionalAPY: 0.021,         // 추가락업 APY 2.1%

  const calculateLockupBonus = (walletAddress: string) => {
    const basicLockupAmount = new Decimal(LOCKUP_POLICY.miningRate)
      .times(LOCKUP_POLICY.basicLockupRate)
      .times(LOCKUP_POLICY.basicAPY)
      .toDecimalPlaces(50);
    
    const additionalLockupAmount = new Decimal(LOCKUP_POLICY.miningRate)
      .times(1 - LOCKUP_POLICY.basicLockupRate)
      .times(LOCKUP_POLICY.additionalLockupRate)
      .times(LOCKUP_POLICY.additionalAPY)
      .toDecimalPlaces(50);
    
    return {
      basicLockup: basicLockupAmount,
      additionalLockup: additionalLockupAmount,
      totalLockup: basicLockupAmount.plus(additionalLockupAmount)
    };
  };
  ```

  ```typescript
  // 개인별 데이터 저장소 (완전 분리)
  class PersonalDataService {
    private static personalDataStores = new Map<string, Map<string, any>>();
    
    static getPersonalStore(walletAddress: string): Map<string, any> {
      if (!this.personalDataStores.has(walletAddress)) {
        this.personalDataStores.set(walletAddress, new Map());
      }
      return this.personalDataStores.get(walletAddress)!;
    }
    
    static savePersonalData(walletAddress: string, key: string, value: any) {
      const store = this.getPersonalStore(walletAddress);
      store.set(key, value);
      localStorage.setItem(`personal_${walletAddress}_${key}`, JSON.stringify(value));
    }
    
    static loadPersonalData(walletAddress: string, key: string) {
      const store = this.getPersonalStore(walletAddress);
      if (store.has(key)) {
        return store.get(key);
      }
      
      const data = localStorage.getItem(`personal_${walletAddress}_${key}`);
      if (data) {
        const parsed = JSON.parse(data);
        store.set(key, parsed);
        return parsed;
      }
      return null;
    }
  }
  ```
