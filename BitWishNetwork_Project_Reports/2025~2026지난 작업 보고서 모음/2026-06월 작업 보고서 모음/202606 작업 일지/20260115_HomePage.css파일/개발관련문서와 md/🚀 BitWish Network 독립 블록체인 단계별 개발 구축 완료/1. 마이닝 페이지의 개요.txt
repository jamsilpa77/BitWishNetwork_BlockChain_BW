1. 마이닝 페이지의 개요:
마이닝 페이지에서 "마이닝 시작"을 클릭하면 블록체인 BW토큰 채굴이 아닌 가상 포인트 BW를 채굴하는 시스템임을 명확히한다.

2. 단 "마이닝 시작"클릭시 실제 BW토큰이 아닌 가상 포인트 BW를 채굴하는 것이지만 블록체인 BW 실제 블록은 실제 생성 되도록 연결 해야하며 "마이닝 시작"버튼 바로위 "마이닝 및 보너스 설정"텍스트형 버튼은 상단 메뉴 "마이닝 및 보너스 설정"이 있으니 제거해 알겠어?
2-1. "마이닝 및 보너스 설정"안에 "기본 보상 비률"텍스트를 "시간당 채굴률"로 텍스트 변경하고, 시간당 채굴률은 0.25BW개 이며, 일일보상 6BW 개 이고 "일일 보상" 상태표시도 추가 구현 하도록한다. 그래서 비율 1은 잘 못 표기 된 것이다.
2-2. "시간당 채굴률"로 0.25BW로 수정하고 비활성화 시키고,
2-3. "일일 보상"을 추가해서 일일보상을 6BW로 표시하고 비활성화 시켜 알겠어?
2-4. 그러니 마이닝 시작을 클릭하면 50단위 부동소수점 계산으로 기본적인 고정 채굴률 시간당 0.25BW이며, 고정 일일 보상은 6BW이다.
2-5. 여기서 출석 보너스와 추천인 보너스가 추가되면 50단위 부동소수점으로 계산되어 "마이닝 상탱" 총 채굴량에 누적 된다.
2-6. 이것이 마이닝 시작버튼의 기본 시스템구조와 소스코드 로직을 구현해야한다. 알겠어?

3. 마이닝 페이지 서버 리부팅, 로그아웃, 페이지 상단 오른쪽 X버튼, 새로고침 하면 마이닝 페이지는 닫히고 다시 마이닝 페이지로 접속하려면 지갑 주소를 입력과 비밀번호 입력 후 마이닝 페이지로 접속 하도록 만들어야지 왜 서버를 끄고 자고 왔는데 접속하니 마이닝 페이지가 그대로 열려 있는거야? 이러면 안되 알겠어?

4. 그리고 서버 리부팅, 로그아웃, 페이지 상단 오른쪽 X버튼, 새로고침한다고 기존 마이닝 실시간 채굴량 데이터, 출석 체크와 보너스 데이터, 추천 보너스 데이터, 절대 초기화되서 는 안된다. 

5. 유저/관리자에 각각 독자 적으로 운영되야하고 모든 시스템은 분리되어야하고 모든 저장은 각각 데이터 베이스 MongDB등 마이닝 페이지의 모든 전체 데이터는 절대 공통 저장되어선 안되고 각각 무조건 분리되어 저장되어야하고,

6. 유저는 가입하는 모든 유저들은 각각 개인 마이닝 페이지를 기본 채굴률이 유지되고 출석, 추천, 가맹은 0(제로)가 된 상태에서 개인 가입자들에게 개인 마이닝 페이지가 지급되며 개개인은 자기 마이닝 채굴 BW는 완벽하게 개인 저장소를 가지면 절대 새로고침, 업데이트, 로그아웃등이 되더라도 초기화는 절대 되지않으며 모든 데이터는 안전하게 저장된다.

### **1. 마이닝 시작 시 기본값 설정**

```typescript
// 마이닝 시작 버튼 클릭 시 실행되는 함수
const handleMiningStart = async () => {
  try {
    // Decimal.js 50단위 부동소수점 정밀도 설정
    const Decimal = require('decimal.js');
    Decimal.set({ precision: 50 });
    
    // 기본 고정값 설정
    const baseMiningRate = new Decimal('0.25'); // 기본 채굴률 0.25 BW/시간
    const dailyReward = new Decimal('6'); // 일일 보상 6 BW
    
    // 마이닝 데이터 초기화
    const miningData = {
      isActive: true,
      startTime: new Date().toISOString(),
      baseMiningRate: baseMiningRate.toString(),
      dailyReward: dailyReward.toString(),
      attendanceBonus: new Decimal('0').toString(), // 출석 보너스 초기값 0%
      totalMinedAmount: new Decimal('0').toString(), // 총 채굴량 초기값
      currentMiningRate: baseMiningRate.toString() // 현재 채굴률 (기본값)
    };
    
    // 백엔드에 마이닝 시작 요청
    const response = await fetch('http://localhost:4001/api/mining/start', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        walletAddress,
        miningData
      })
    });
    
    if (response.ok) {
      console.log('✅ 마이닝 시작 완료 - 기본값 설정됨');
      console.log('📊 기본 채굴률:', baseMiningRate.toString(), 'BW/시간');
      console.log('📊 일일 보상:', dailyReward.toString(), 'BW');
    }
  } catch (error) {
    console.error('❌ 마이닝 시작 오류:', error);
  }
};
```

작업 시작하고 절대 작업 범위 벗어나지말고 제대로 구현 하도록하고 절대 전역/공통 변수 함수 전역 모달 클래스등 절대 포함 되서는 안되고 이전 작업에도 전역/공통 변수 함수 등 전역 모달등 이 있는지 작업 후 체크하고 있다면 보고해 알겠어?
