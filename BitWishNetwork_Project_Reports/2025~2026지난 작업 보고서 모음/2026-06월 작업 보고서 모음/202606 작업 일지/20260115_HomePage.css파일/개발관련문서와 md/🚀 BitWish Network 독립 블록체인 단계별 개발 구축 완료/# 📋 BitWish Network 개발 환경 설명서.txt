# 📋 **BitWish Network 개발 환경 설명서**

## 🎯 **프로젝트 개요**

### **📁 현재 개발 폴더**
```
📁 BitWish_BlockChain_Mainnet/Node_HomePage/
├── 📁 src/ (React 프론트엔드)
├── 📄 simple-server.js (BitWish 블록체인 API 서버)
└── 📄 simple-server-backup.js (백업 파일)
```

### **🚀 BitWish Network 시스템**
- **완전 독립 블록체인**: 스텔라 의존성 완전 제거
- **BW 토큰 전용**: BitWish Network 전용 블록체인
- **50자리 정밀도**: Decimal.js 기반 정밀 계산
- **4개국 언어**: 한국어, 영어, 일본어, 중국어 지원

---

## 🔧 **시스템 구성**

### **✅ Backend (simple-server.js)**
- **BitWishBlockchainCore**: 블록체인 코어 엔진
- **BitWishWalletSystem**: BW 지갑 시스템
- **BitWishMiningSystem**: 마이닝 시스템
- **BitWishMongoDB**: 데이터베이스 연동
- **50개 API 엔드포인트**: 완전한 REST API
- **WebSocket**: 실시간 통신

### **✅ Frontend (@src/)**
- **React 앱**: BitWish Network 홈페이지
- **BitWish 지갑**: 지갑 생성/관리
- **마이닝 페이지**: 유저/관리자 마이닝
- **나의 지갑**: 지갑 정보 조회
- **i18n**: 4개국 언어 지원

---

## 🚀 **실행 방법**

### **1. BitWish 블록체인 서버 시작**
```bash
# Node_HomePage 폴더에서
node simple-server.js
```
- **포트**: 4001
- **API**: http://localhost:4001
- **WebSocket**: ws://localhost:4001

### **2. React 프론트엔드 시작**
```bash
# 새 터미널에서
cd src
npm install  # (필요시)
npm start
```
- **포트**: 4000
- **웹사이트**: http://localhost:4000

## 📊 **주요 API 엔드포인트**

### **블록체인 API**
- `POST /api/bitwish/blockchain/initialize` - 블록체인 초기화
- `GET /api/bitwish/blockchain/status` - 네트워크 상태
- `GET /api/bitwish/blockchain/block/:height` - 블록 조회
- `GET /api/bitwish/blockchain/transaction/:hash` - 트랜잭션 조회
- `GET /api/bitwish/blockchain/balance/:address` - 잔액 조회

### **지갑 API**
- `POST /api/bitwish/wallet/create` - 지갑 생성
- `POST /api/bitwish/wallet/verify` - 지갑 검증
- `GET /api/bitwish/wallet/:address` - 지갑 정보
- `POST /api/bitwish/wallet/set-password` - 비밀번호 설정
- `POST /api/bitwish/wallet/verify-password` - 비밀번호 검증

### **마이닝 API**
- `POST /api/bitwish/mining/start` - 마이닝 시작
- `POST /api/bitwish/mining/stop` - 마이닝 중지
- `GET /api/bitwish/mining/sessions` - 마이닝 세션 목록
- `GET /api/bitwish/mining/stats` - 마이닝 통계
