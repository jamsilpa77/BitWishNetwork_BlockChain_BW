### 📋 프롬프트 지시서 기반 "나의 지갑" 요구사항

#### 🏠 메인 지갑 페이지 (`/wallet`)
1. **상단 오른쪽**: `t('wallet.getSeed')` 버튼
2. **시드문구 모달**:
   - 24단어 표시 (12개씩 2열)
   - 경고 메시지 (빨간색 Alert)
   - 복사/취소/확인 버튼
   - AES-256 암호화 저장 (OTP 비밀키 사용)

3. **지갑 대시보드**:
   - 공개키: QR코드 + 복사 버튼
   - 잔액: `총 잔액` / `사용 가능` (KYC 미완료 시 안내)
   - 최근 트랜잭션: 최대 5개 (TXID, 금액, 날짜)
   - 기능 버튼들:
     - 송금받기(↓, 파란색)
     - 송금하기(↑, 빨간색) 
     - KYC 신청
     - OTP 설정
     - 시드문구 복구

#### 🔐 KYC/OTP 통합 시스템
1. **KYC 신청** (`/wallet/kyc`):
   - 모바일, 이메일, 소셜 ID 입력
   - 관리자 승인 대기

2. **구글 OTP** (`/wallet/otp`):
   - TOTP 비밀키 생성
   - QR코드 표시
   - 6자리 OTP 검증

3. **시드문구 복구** (`/wallet/recover`):
   - OTP 검증 필수
   - 암호화된 시드문구 복호화

#### 💰 보너스 보상 시스템
1. **출석 보너스**: 연속 출석일수별 가산 보너스
2. **추천 보너스**: 추천인 수별 지속 채굴 보너스  
3. **락업 보너스**: APY 기반 보상
4. **반감기**: 매년 점진적 감소
