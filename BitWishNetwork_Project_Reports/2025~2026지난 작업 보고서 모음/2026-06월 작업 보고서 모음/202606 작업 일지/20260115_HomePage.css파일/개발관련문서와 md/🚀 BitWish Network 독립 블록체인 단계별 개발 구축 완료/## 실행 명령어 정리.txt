## 실행 명령어 정리

### 백엔드 실행 명령어
```bash
# 백엔드 서버 시작 (포트 4001)
node simple-server.js

# 또는
npm run start

# 백엔드 개발 모드 (자동 재시작)
npm run server
```

### 프론트엔드 실행 명령어
```bash
# 프론트엔드 개발 서버 시작 (포트 4000)
npm run dev

# 프론트엔드 빌드
npm run build

# 프론트엔드 미리보기
npm run preview
```

### 통합 시스템 실행
```bash
# 통합 시스템 시작
npm run system
```

### 최종 포트 구성
```
BitWish Network 시스템
├── 🚀 백엔드 API 서버 (포트 4001)
│   ├── 지갑 API
│   ├── 블록체인 네트워크
│   ├── 블록체인 익스플로러
│   ├── P2P 네트워크
│   ├── 모니터링 시스템
│   └── 하이브리드 저장소
└── 🌐 프론트엔드 (포트 4000)
    ├── React + TypeScript
    ├── Vite 개발 서버
    └── 실시간 핫 리로드
```

### 개발 워크플로우
1. 터미널 1: `node simple-server.js` (백엔드)
2. 터미널 2: `npm run dev` (프론트엔드)

또는

1. 터미널 1: `npm run system` (통합 시스템)

포트는 4000(프론트엔드)과 4001(백엔드)만 사용합니다.
