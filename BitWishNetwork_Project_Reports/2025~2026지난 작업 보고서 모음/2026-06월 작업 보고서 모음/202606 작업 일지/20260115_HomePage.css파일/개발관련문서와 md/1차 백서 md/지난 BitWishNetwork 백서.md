## 🔒 **고급 락업 시스템 작동 방식**

### **🎯 락업 시스템 개요**
BitWishNetwork의 락업 시스템은 **기본락업**과 **추가락업**의 2단계 구조로 작동하며, 각각 **월간 이자**와 **실시간 마이닝 보상**으로 분리됩니다.

#### **1. 락업 시스템 구조**
- **기본락업**: 기본 채굴률의 일정 비율을 월간 이자로 보관
- **추가락업**: 남은 채굴률의 일정 비율을 월간 이자로 보관
- **실시간 마이닝**: 남은 채굴률만큼 실시간으로 누적

#### **2. 계산 공식**
```
기본락업보관함 = 기본채굴률 × 기본락업비율 × APY (월간 이자)
추가락업보관함 = 남은채굴률 × 추가락업비율 × APY (월간 이자)
실시간마이닝 = 기본채굴률 × 남은비율 (시간당 누적)
```

#### **3. 구체적 계산 예시**
- **기본 보상률**: 0.25 BW/시간
- **기본락업 20% + 추가락업 25%**:
  - 기본락업보관함: 0.25 × 20% × 2.7% = **0.00135 BW/월**
  - 추가락업보관함: 0.2 × 25% × 2.1% = **0.00105 BW/월**
  - 실시간마이닝: 0.25 × 60% = **0.15 BW/시간**

#### **4. 최종 보상 공식**
```
총 노드 보상 = 기본락업보관함(월간이자) + 추가락업보관함(월간이자) + 실시간마이닝보상(시간당누적)
```

**모든 보상은 투명하게 분리되어 계산됩니다.**

## 1. 개요

### 1.1. 비전과 목표

**BitWishNetwork**는 **완전한 독자 개발 블록체인**으로 구축된 **무로그인 시스템**이라는 획기적인 혁신을 통해 블록체인 진입장벽을 완전히 제거한 사용자 중심의 분산형 블록체인 플랫폼입니다. 

#### 🌟 **핵심 비전 선언**
우리는 **"누구나, 언제든지, 어디서든 블록체인에 참여할 수 있는 세상"**을 만들고자 합니다. 기존 블록체인 플랫폼의 복잡한 가입 절차, 개인정보 수집, 기술적 진입장벽을 모두 제거하여, **진정한 의미의 대중화된 블록체인 생태계**를 구축하는 것이 우리의 궁극적 목표입니다.

#### 🎯 **구체적 목표**
1. **즉시 참여 시스템**: 로그인 없이 3초 만에 블록체인 참여 가능
2. **완벽한 보안**: 24단어 시드문구로 업계 최고 수준의 보안 제공
3. **공정한 보상**: 출석, 추천, 반감기 보너스로 지속적 수익 창출
4. **글로벌 접근성**: 4개 언어 지원으로 전 세계 사용자 포용
5. **지속가능한 이코노미**: 21B 토큰으로 100년 이상 지속 가능한 생태계

#### 🚀 **혁신의 핵심 가치**
- **사용자 중심**: 기술이 사용자를 위해 존재하는 플랫폼
- **투명성**: 모든 블록체인 데이터를 실시간으로 공개
- **공정성**: AI나 특권층 없이 모든 사용자가 동등한 기회 보장
- **지속가능성**: 환경 친화적 PoW와 반감기 정책으로 장기적 가치 창출

BitWishNetwork는 사용자 중심의 분산형 블록체인 플랫폼으로,BitWishNetwork PoW 블록체인을 기반으로 누구나 쉽게 접근 가능한 비수탁 지갑, 투명한 보상 시스템, 활발한 커뮤니티를 제공합니다. 우리의 비전은 경제적 자유와 사용자 주도형 생태계를 통해 전 세계 사용자들이 디지털 자산을 안전하고 효율적으로 관리할 수 있는 환경을 구축하는 것입니다.

#### 🎯 **금융권 표준 초월 정밀 계산 시스템**
BitWishNetwork는 **Decimal.js 기반의 고급 정밀 계산 시스템**을 통해 금융권 표준을 초월하는 수학적 정확성을 보장합니다:

**🔬 정밀도 비교 (업계 최고 수준)**
- **Bitcoin**: 8자리 정밀도 (Satoshi 단위)
- **Ethereum**: 18자리 정밀도 (Wei 단위)  
- **Stellar**: 7자리 정밀도 (Stroops 단위)
- **BitWish**: **50자리 정밀도** (Decimal.js 기반) ⭐ **업계 최고가 아닐까?**

**💎 금융권 표준 완전 준수**
- **ISO 4217 국제 통화 표준** 준수
- **부동소수점 오차 완전 제거** (0.1 + 0.2 = 0.3 정확)
- **BigDecimal 기반 정밀 연산** (금융권 표준 방식)
- **실시간 정밀도 검증** 시스템 구축

**🚀 블록체인 시장 대비 우위**
- **정수 연산 한계 극복**: Bitcoin의 정수 연산 한계를 소수점 50자리 부동소수점 정밀 계산으로 해결
- **계산 정확성 보장**: 모든 보상 부동소수점 정밀 계산에서 수학적 완벽성 달성
- **사용자 신뢰성**: 정확한 수치로 투명하고 신뢰할 수 있는 보상 시스템
1.2. BitWishNetwork란?
BitWishNetwork는 PoW을 활용한 비수탁 블록체인 플랫폼으로, 무로그인 시스템, 즉시 지갑 생성, P2P 네트워크, 실시간 보상 시스템, 다국어 UI(한국어, 영어, 중국어, 일본어)를 제공합니다. 주요 구성 요소는 다음과 같습니다:

비수탁 지갑: 무로그인으로 즉시 BW + 40자리 16진수 42자 지갑주소, 공개키(BW로 시작)와 24단어 시드 문구(BIP39) 생성.

## 2. 기술 아키텍처

### 2.1. BitWish 독자 개발 블록체인

**BitWishNetwork**는 **완전한 독자 개발 블록체인**으로 구축되었으며, **고급 합의 프로토콜**과 **PoW(Proof of Work)**를 결합하여 높은 처리량과 낮은 수수료를 제공합니다.

#### 🎯 **고급 정밀 계산 아키텍처**

**BitWishNetwork의 핵심 기술적 우위는 금융권 표준을 초월하는 정밀 계산 시스템입니다:**

**🔬 Decimal.js 고급 설정 (업계 최고 수준)**
```typescript
Decimal.set({
  precision: 50,        // 최대 정밀도 50자리 (업계 최고)
  rounding: Decimal.ROUND_HALF_UP,  // 금융권 표준 반올림
  toExpNeg: -50,        // 음수 지수 범위
  toExpPos: 50,         // 양수 지수 범위
  maxE: 9e15,           // 최대 지수
  minE: -9e15,          // 최소 지수
  modulo: Decimal.ROUND_FLOOR,  // 나머지 연산 방식
  crypto: false         // 암호화 모드 비활성화
});
```

**💎 금융권 표준 완전 준수**
- **ISO 4217 국제 통화 표준** 준수
- **BigDecimal 기반 정밀 연산** (금융권 표준 방식)
- **부동소수점 오차 완전 제거** (0.1 + 0.2 = 0.3 정확)
- **실시간 정밀도 검증** 시스템 구축

**🚀 블록체인 시장 대비 기술적 우위**
- **Bitcoin**: 8자리 정밀도 (정수 연산 한계) → **BitWish**: 50자리 정밀도 (소수점 정밀 계산)
- **Ethereum**: 18자리 정밀도 → **BitWish**: 50자리 정밀도 (2.8배 우수)
- **Stellar**: 7자리 정밀도 → **BitWish**: 50자리 정밀도 (7.1배 우수)

#### 🔗 **BitWish 독자 개발 블록체인 아키텍처**

```
[사용자 브라우저] ←→ [React 프론트엔드:4000]
         ↓
[BitWish API] ←→ [BitWish 독자 블록체인]
         ↓
[Node.js 백엔드:4001] ←→ [MongoDB/Redis]
         ↓
[WebSocket] ←→ [실시간 데이터 동기화]
```

#### 📊 **BitWish API 엔드포인트 구조**
- **`/api/bitwish/blockchain/status`**: 실시간 블록체인 상태 조회
- **`/api/bitwish/blockchain/economy`**: 토큰 이코노미 정보
- **`/api/bitwish/wallet/create`**: 24단어 시드문구 기반 지갑 생성
- **`/api/bitwish/wallet/balance/:publicKey`**: 실시간 잔액 조회
- **`/api/bitwish/wallet/transaction`**: OTP 검증 후 트랜잭션 실행

#### 🎯 **BitWish 통합보상 시스템 API**
- **`/api/bitwish/attendance/check-in`**: 출석 체크인 및 보너스율 계산
- **`/api/bitwish/referral/generate`**: 추천인 코드 생성 (1회 발급 후 영구 고정)
- **`/api/bitwish/referral/use`**: 추천인 코드 사용 및 관계 설정
- **`/api/bitwish/rewards/rate/:walletAddress`**: 통합 보상률 계산 (출석+추천인+락업+반감기)

### 2.2. 비수탁 지갑 시스템

#### 🔐 **24단어 시드문구 보안**
- **BIP39 표준**: 업계 표준 24단어 시드문구 생성
- **클라이언트 측 생성**: 서버는 절대 비밀키를 저장하지 않음
- **AES-256 암호화**: 시드문구를 안전하게 로컬 저장
- **Google OTP**: 2단계 인증으로 추가 보안 강화
