### **2단계: 핵심 마이닝 시스템 구현** ⭐ **핵심 우선순위**

#### **2.1 정밀 계산 시스템 (50자리 부동소수점)**
```typescript
// src/utils/PrecisionCalculator/PrecisionCalculator.ts
/**
 * BitWishNetwork BW 포인트 채굴 시스템
 * 현재 토큰 이코노미는 완벽한 가상 이코노미입니다.
 * 추후 KYC 시스템 구현과 블록체인 연결 지갑까지 완성하면

 * 절대 준수사항:
 * - 전역 변수 사용 금지
 * - 공통 함수 사용 금지
 * - 공통 클래스 사용 금지
 * - 전역 모달 사용 금지
 * - 중복 코드 사용 금지
 * - 다른 컴포넌트와 상태 공유 금지
 * - 전역 상태 관리 라이브러리 사용 금지
 */
```

#### **2.2 기본 마이닝 보상률 시스템**
- 시간당: 0.25 BW (고정)
- 일일: 6.0 BW (고정)
- 월간: 180 BW (고정)
- 연간: 2,190 BW (고정)

#### **2.3 실시간 데이터 동기화**
- 30초마다 자동 새로고침
- 1분마다 전체 페이지 새로고침
- 실시간 BW 발행량 계산
- 실시간 BW잔여 발행량 계산

### **3단계: 보너스 시스템 구현** ⭐ **중요 우선순위**

#### **3.1 출석 보너스 시스템 (5%)**
- 출석 체크 달력 시스템
- 시간 제한: 오전 9시 ~ 다음날 오전 8시 59분 59초
- 달력 날짜 표시 시스템 (파란색/회색/빨간색)
- 5% 보너스 계산 및 적용

#### **3.2 추천 보너스 시스템 (2% + 1BW)**
- 추천인: 2% 영구 적용
- 가입자: 1회만 2% 적용
- 즉시 보너스: 각 1BW
- 추천 보너스 보관함 시스템
- 추천 보상 보관함 시스템

#### **3.3 가맹점 등록 보너스 시스템 (125%)**
- 사업자 등록증 업로드
- KYC 인증 시스템
- 가맹점 심사 시스템 (승인 날 때까지 대기)
- 125% 가산 보너스 적용
