### 1.1 추천 보너스 현재 상태

#### ✅ **구현 완료 항목**

**데이터베이스 스키마:**
- ✅ `BonusRecord` 모델에 추천 보너스 필드 구현
  - `referralBonusStorage`: 2% 보너스 누적 저장소
  - `referralRewardStorage`: 1BW 보상 저장소
  - `referralList`: 가입자 목록 (지갑주소, 가입일시, 누적보너스, KYC상태, 보상지급상태)
  
- ✅ `MiningState` 모델에 추천 상태 필드 구현
  - `referralCount`: 추천인 수
  - `referralBonusRate`: 추천 보너스율

- ✅ `User` 모델에 추천 코드 필드 구현
  - `myReferralCode`: 개인 추천 코드 (Unique)

**프론트엔드:**
- ✅ `ReferralModal` 컴포넌트 구현

#### 작업 1-1: MiningController 동기화 로직 수정

**파일:** `server/controllers/MiningController.ts`

**목표:** 30초 동기화 시 추천 보너스 2% 분리 계산

**구현 내용:**
```typescript
async syncMiningData(req: Request, res: Response) {
  // 1. 기존 동기화 로직
  const miningState = await MiningState.findOne({ walletAddress });
  
  // 2. 추천 보너스 2% 분리 계산
  if (miningState.referralCount > 0) {
    const baseRate = new Decimal(miningState.currentBaseRate);
    const referralRate = new Decimal(miningState.referralCount).mul(0.02);
    
    // 3. 추천 보너스 분리 저장
    const bonusRecord = await BonusRecord.findOne({ walletAddress });
    const elapsedHours = elapsedSeconds / 3600;
    const referralBonus = baseRate.mul(referralRate).mul(elapsedHours);
    
    // 4. referralBonusStorage 업데이트
    bonusRecord.referralBonusStorage = new Decimal(bonusRecord.referralBonusStorage)
      .plus(referralBonus)
      .toString();
    
    await bonusRecord.save();
  }
  
  // 5. 기존 누적 보상 계산 (2% 제외)
  // ...
}
```

#### 작업 1-2: 추천 코드 가입 시 2% 보너스율 적용

**파일:** `server/controllers/UserController.ts`

**목표:** 가입자 발생 시 추천자의 채굴률에 2% 추가

**구현 내용:**
```typescript
private async processReferral(referrerCode: string, newWalletAddress: string) {
  // 1. 기존 로직 (referralList 추가, referralCount 증가)
  
  // 2. 추천자의 MiningState 업데이트
  const miningState = await MiningState.findOne({ 
    walletAddress: referrer.walletAddress 
  });
  
  // 3. referralBonusRate 업데이트
  const newReferralRate = new Decimal(miningState.referralCount).mul(0.02);
  miningState.referralBonusRate = newReferralRate.toString();
  
  // 4. currentTotalRate 재계산
  const baseRate = new Decimal(miningState.currentBaseRate);
  const attendanceRate = miningState.isAttendanceActive ? new Decimal(0.05) : new Decimal(0);
  const partnerRate = miningState.partnerStatus === 'REGISTERED' ? new Decimal(1.25) : new Decimal(0);
  
  miningState.currentTotalRate = baseRate
    .mul(new Decimal(1).plus(attendanceRate).plus(newReferralRate).plus(partnerRate))
    .toString();
  
  await miningState.save();
  
  // 5. 가입자에게도 1BW 지급
  const newUserBonusRecord = await BonusRecord.findOne({ 
    walletAddress: newWalletAddress 
  });
  newUserBonusRecord.referralRewardStorage = new Decimal(newUserBonusRecord.referralRewardStorage)
    .plus(1)
    .toString();
  await newUserBonusRecord.save();
}
```

**예상 작업 시간:** 3시간

### 2.2 Phase 2: 가입자 목록 페이지 구현 (우선순위: 높음)

#### 작업 2-1: 가입자 목록 API 구현

**파일:** `server/routes/referral.ts` (신규)

**목표:** 가입자 목록 조회 API

**구현 내용:**
```typescript
import express from 'express';
import BonusRecord from '../models/BonusRecord';

const router = express.Router();

// GET /api/referral/list/:walletAddress
router.get('/list/:walletAddress', async (req, res) => {
  try {
    const { walletAddress } = req.params;
    
    const bonusRecord = await BonusRecord.findOne({ walletAddress });
    
    if (!bonusRecord) {
      return res.json({
        success: true,
        data: { referralList: [] }
      });
    }
    
    // 가입자 목록 포맷팅
    const formattedList = bonusRecord.referralList.map(item => ({
      walletAddress: item.childWalletAddress,
      joinedAt: item.joinedAt,
      accumulatedBonus: item.accumulatedBonus,
      isKycVerified: item.isKycVerified,
      rewardStatus: item.rewardStatus
    }));
    
    return res.json({
      success: true,
      data: {
        referralList: formattedList,
        totalBonus: bonusRecord.referralBonusStorage,
        totalReward: bonusRecord.referralRewardStorage
      }
    });
  } catch (error) {
    console.error('Referral list error:', error);
    return res.status(500).json({
      success: false,
      message: '서버 오류가 발생했습니다'
    });
  }
});

export default router;
```

**예상 작업 시간:** 3시간

```typescript
import mongoose, { Schema, Document } from 'mongoose';

export interface IPartnerRecord extends Document {
  walletAddress: string;        // 신청자 지갑 주소
  businessName: string;         // 사업자명
  businessLicense: string;      // 사업자 등록번호
  licenseDocument: string;      // 사업자 등록증 파일 경로
  contactEmail: string;         // 연락처 이메일
  contactPhone: string;         // 연락처 전화번호
  status: 'PENDING' | 'APPROVED' | 'REJECTED';
  submittedAt: Date;            // 신청 일시
  reviewedAt?: Date;            // 심사 일시
  approvedAt?: Date;            // 승인 일시
  rejectedAt?: Date;            // 거부 일시
  rejectionReason?: string;     // 거부 사유
}

const PartnerRecordSchema: Schema = new Schema({
  walletAddress: { type: String, required: true, unique: true },
  businessName: { type: String, required: true },
  businessLicense: { type: String, required: true },
  licenseDocument: { type: String, required: true },
  contactEmail: { type: String, required: true },
  contactPhone: { type: String, required: true },
  status: {
    type: String,
    enum: ['PENDING', 'APPROVED', 'REJECTED'],
    default: 'PENDING'
  },
  submittedAt: { type: Date, default: Date.now },
  reviewedAt: { type: Date },
  approvedAt: { type: Date },
  rejectedAt: { type: Date },
  rejectionReason: { type: String }
}, {
  timestamps: true
});

export default mongoose.model<IPartnerRecord>('PartnerRecord', PartnerRecordSchema);
```

```typescript
    const { walletAddress, businessName, businessLicense, contactEmail, contactPhone } = req.body;
    const licenseDocument = req.file?.path;
    
    // 중복 신청 체크
    const existing = await PartnerRecord.findOne({ walletAddress });
    if (existing) {
      return res.json({
        success: false,
        message: '이미 가맹점 신청이 존재합니다'
      });
    }
    
    // 신청 정보 저장
    const partnerRecord = new PartnerRecord({
      walletAddress,
      businessName,
      businessLicense,
      licenseDocument,
      contactEmail,
      contactPhone,
      status: 'PENDING'
    });
    
    await partnerRecord.save();
    
    // MiningState 업데이트
    const miningState = await MiningState.findOne({ walletAddress });
    if (miningState) {
      miningState.partnerStatus = 'PENDING';
      await miningState.save();
    }
    
    return res.json({
      success: true,
      message: '가맹점 신청이 완료되었습니다'
    });
  } catch (error) {
```

```typescript
// POST /api/admin/partner/approve
router.post('/partner/approve', async (req, res) => {
  try {
    const { walletAddress } = req.body;
    
    const partnerRecord = await PartnerRecord.findOne({ walletAddress });
    if (!partnerRecord) {
      return res.json({
        success: false,
        message: '가맹점 신청을 찾을 수 없습니다'
      });
    }
    
    // 승인 처리
    partnerRecord.status = 'APPROVED';
    partnerRecord.reviewedAt = new Date();
    partnerRecord.approvedAt = new Date();
    await partnerRecord.save();
    
    // MiningState 업데이트 (125% 보너스 적용)
    const miningState = await MiningState.findOne({ walletAddress });
    if (miningState) {
      miningState.partnerStatus = 'REGISTERED';
      
      // currentTotalRate 재계산
      const baseRate = new Decimal(miningState.currentBaseRate);
      const attendanceRate = miningState.isAttendanceActive ? new Decimal(0.05) : new Decimal(0);
      const referralRate = new Decimal(miningState.referralBonusRate);
      const partnerRate = new Decimal(1.25); // 125%
      
      miningState.currentTotalRate = baseRate
        .mul(new Decimal(1).plus(attendanceRate).plus(referralRate).plus(partnerRate))
        .toString();
      
      await miningState.save();
    }
    
    return res.json({
      success: true,
      message: '가맹점이 승인되었습니다'
    });
  } catch (error) {
    console.error('Partner approval error:', error);
    return res.status(500).json({
      success: false,
      message: '서버 오류가 발생했습니다'
    });
  }
});

// POST /api/admin/partner/reject
router.post('/partner/reject', async (req, res) => {
  try {
    const { walletAddress, rejectionReason } = req.body;
    
    const partnerRecord = await PartnerRecord.findOne({ walletAddress });
    if (!partnerRecord) {
      return res.json({
        success: false,
        message: '가맹점 신청을 찾을 수 없습니다'
      });
    }
    
    // 거부 처리
    partnerRecord.status = 'REJECTED';
    partnerRecord.reviewedAt = new Date();
    partnerRecord.rejectedAt = new Date();
    partnerRecord.rejectionReason = rejectionReason;
    await partnerRecord.save();
    
    // MiningState 업데이트
    const miningState = await MiningState.findOne({ walletAddress });
    if (miningState) {
      miningState.partnerStatus = 'NOT_REGISTERED';
      await miningState.save();
    }
    
    return res.json({
      success: true,
      message: '가맹점 신청이 거부되었습니다'
    });
  } catch (error) {
    console.error('Partner rejection error:', error);
    return res.status(500).json({
      success: false,
      message: '서버 오류가 발생했습니다'
    });
  }
});
```
