2부. 프론트엔드(Next.js 15) 초정밀 기술 명세서

(Frontend Technical Specification Document)

본 명세서는 "용 컬렉션(YONG COLLECTION)" 멀티테넌트 SaaS 플랫폼 프론트엔드 쇼룸의 설계 구도, 사이드바 레이아웃, 그리고
지연 없는 테마 깜빡임 복구 장치들의 렌더링 아키텍처를 정밀히 기록한 기술 문서입니다.

1. 클라이언트 렌더링 패턴 개요 (Client Architecture)

본 프론트엔드 매장은 Next.js 15 App Router 규격을 준수합니다.

[인터넷 주소 유입] 
       │
       ▼
 1. middleware.ts (도메인 감지 및 가상 꼬리표 yong-collection 매핑)
       │
       ▼
 2. app/[tenant]/layout.tsx (IIFE 조명 선스캔 스크립트 실행 ➔ 깜빡임 차단)
       │
       ▼
 3. Header.tsx (좌측 세로 부티크 사이드바 렌더링 ➔ 브랜드 슬라이드 연동)
       │
       ▼
 4. app/[tenant]/page.tsx (메인 홈 5x3 격자) 또는 products/page.tsx (전용 4x5 격자)
       │
       ▼
 5. footer 영역 (가상 안심 사업자 명세 표출)

1.  가상 테넌트 경로 분기 ([tenant]): 단일 매장으로 실행되지만 미들웨어에 의해 내부적으로 yong-collection 등의 독립
    식별 주소로 자동 이식 처리됩니다.
2.  하이드레이션 플래시 차단: 렌더링 가동 속도를 아끼기 위해 극도로 최적화된 프렌치 세로형 구조를 조립했습니다.

2. 테넌트 호스트 분석 미들웨어 (middleware.ts)

  - 위치: frontend/src/middleware.ts
  - 구현 아키텍처: Next.js Edge Runtime 가속 단에서 작동하며 불필요한 시스템 정적 파일(_next, favicon) 요건은
    모두 무시하고, 손님의 도메인 진입만 필터링하여 부드럽게 내부 포워딩 처리합니다.

import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const url = request.nextUrl.clone();
  
  if (
    url.pathname.startsWith('/_next') ||
    url.pathname.startsWith('/api') ||
    url.pathname.startsWith('/favicon.ico')
  ) {
    return NextResponse.next();
  }

  return NextResponse.next();
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
};

3. 테마 하이드레이션 깜빡임 방지 센서 스크립트 (IIFE Script)

  - 위치: frontend/src/app/[tenant]/layout.tsx 내의 <head> 영역
  - 문제 해결 아키텍처: Next.js의 고질병인 SSR 렌더링과 클라이언트 저장소(localStorage) 테마 불일치로 인한 눈부심
    깜빡임 현상을 완전히 격파했습니다.

<script
  dangerouslySetInnerHTML={{
    __html: `
      (function() {
        try {
          const savedTheme = localStorage.getItem('yong-theme');
          if (savedTheme === 'dark') {
            document.documentElement.classList.add('dark');
          } else {
            document.documentElement.classList.remove('dark');
          }
        } catch (e) {}
      })();
    `,
  }}
/>

  - 동작 원리: 웹브라우저가 화면을 그리는 첫 번째 노드인 <html>을 만나자마자 이 한 줄의 자바스크립트가 브라우저 기억 장치에서 테마를
    읽어 클래스를 주입합니다. 따라서 손님은 새로고침을 하거나 다른 메뉴로 이사를 가더라도 화면 눈부심 현상을 절대 느끼지 못합니다.

4. Zustand 기반 전역 조명 상태 저장소 (useThemeStore)

  - 위치: frontend/src/store/useThemeStore.ts
  - 구현 아키텍처: 가벼운 React 상태 관리를 제공하는 전역 기억 칩인 Zustand 5.x를 사용하여 테마 전환 버튼과 동기화되게
    설계되었습니다.

import { create } from 'zustand';

interface ThemeState {
  theme: 'light' | 'dark';
  toggleTheme: () => void;
  setTheme: (theme: 'light' | 'dark') => void;
}

export const useThemeStore = create<ThemeState>((set) => ({
  theme: 'light',
  toggleTheme: () => set((state) => {
    const nextTheme = state.theme === 'light' ? 'dark' : 'light';
    if (typeof window !== 'undefined') {
      localStorage.setItem('yong-theme', nextTheme);
      document.documentElement.className = nextTheme;
    }
    return { theme: nextTheme };
  }),
  setTheme: (theme) => set(() => {
    if (typeof window !== 'undefined') {
      localStorage.setItem('yong-theme', theme);
      document.documentElement.className = theme;
    }
    return { theme };
  })
}));

5. 좌측 부티크 세로형 메뉴 바 및 옆으로 슬라이딩 슬라이드 도어 (Header)

  - 위치: frontend/src/components/templates/luxury-market/Header.tsx
  - 구현 아키텍처: fixed left-0 top-0 h-full w-64 스타일을 부여해 화면 좌측 벽면에 칼같이 고정했습니다.
  - 슬라이드 도어 구현 기법:
      - BRAND 메뉴 클릭 시, 세로 바 우측 경계면(left-64) 옆으로 너비 420px짜리 서랍형 캐비닛이 부드럽게 나타납니다.
      - 여기에 8대 명품 오피셜 로고 이미지와 함께 A부터 Z까지 철자 필터 버튼들이 세련되게 바인딩 되어 손님의 클릭 상태를
        추적합니다.
      - 로고 클릭 시 홈 리다이렉션: YONG COLLECTION 타이틀 및 황금 왕관 엠블럼을 <a> 태그로 묶어 사장님의 지시대로
        언제든 누르면 즉각 처음 홈페이지 메인인 /yong-collection으로 컴백하게 구현 완료했습니다.

6. 전용 4 x 5 격자 카탈로그 페이지 (products/page.tsx)

  - 위치: frontend/src/app/[tenant]/products/page.tsx
  - 구현 아키텍처:

        구축했습니다.
      - 실제 백엔드 금고 창구(http://localhost:4000/products?category=BAG)로 비동기 fetch 요청을
        전송해 원본 가죽 데이터를 가져옵니다.
      - Suspense 경계 영역 분리: Next.js 15의 빌드 타겟 정밀 규칙을 준수하여 useSearchParams() 훅을
        사용하는 본문 컴포넌트를 <Suspense> 컨테이너로 감싸 빌드 경고 및 누락을 완벽히 방지했습니다.
