2. [신규 집중 분석] 요구 기능별 현재 상태 및 잔여 개발 명세

제시해주신 그랑파리 레퍼런스 화면 정보와 관리실 ERP 상품 등록 규칙을 정밀 대조하여, 차기 설계해야 할 상세 기술 규격을 명문화합니다.

2.1 회원가입 및 로그인 페이지 시스템 (가맹점 공통 규격)

  - 현재 상태: admin 폴더 내에 1차적인 다크 테마 로그인 창(admin/src/app/login/page.tsx)만 구현되어 있으며,
    고객들이 가입하고 로그인하는 프론트엔드 전용 회원체계(frontend/src/app/[tenant]/register, login)는 아직
    빈 파일(스켈레톤) 상태입니다.
  - 그랑파리 레퍼런스 적용 요구 분석:
    1.  SNS 간편 로그인 연동: 카카오, 네이버, 구글, 애플의 4대 간편 로그인 버튼 배치를 프론트엔드 UI에 완벽히 장착해야
        합니다.
    2.  정밀 가입 폼: 아이디(영문소문자/숫자 416자), 비밀번호(영문 대소문자/숫자/특수문자 중 2가지 조합 1016자), 비밀번호
        확인, 이름, 휴대전화 구분 입력창, 이메일을 수집해야 합니다.
    3.  약관 동의 모듈: [전체동의] 스위치와 필수 이용약관 동의, 선택 SMS 수신 동의, 선택 이메일 수신 동의 체크박스가 작동해야
        합니다.
  - 잔여 개발 항목:
      - frontend/src/app/[tenant]/register/page.tsx (가입 화면 구현)
      - frontend/src/app/[tenant]/login/page.tsx (로그인 및 SNS 버튼 구현)
      - backend/src/auth/ (비밀번호 단방향 암호화 보관 및 토큰 발행 백엔드 모듈 연동)

2.2 장바구니 페이지 시스템 (Zustand 메모리 보관함)

  - 현재 상태: 폴더 경로만 구성되어 있으며 소스코드는 빈 상태입니다.
  - 그랑파리 레퍼런스 적용 요구 분석:
    1.  혜택 안내 배너: 상단에 "로그인 후 더 많은 혜택을 받으세요" 라는 럭셔리 알림창을 매핑합니다.
    2.  텅 빈 장바구니 UI: 장바구니에 담긴 물건이 없을 시 "장바구니가 비어 있습니다." 라는 문구를 중앙에 우아하게 노출합니다.
    3.  정밀 이용안내 문구 보드: 하단에 장바구니 보관 기간, 마일리지 정책, 무이자 할부 이용안내 정보를 그랑파리 사양과 동일하게
        디자인하여 장착합니다.
  - 잔여 개발 항목:
      - frontend/src/app/[tenant]/order/cart/page.tsx (장바구니 화면 구현)
      - frontend/src/store/useCartStore.ts (Zustand 기반 실시간 담기/빼기 메모리 구현)

2.3 관리자 상품 등록 및 회계/세무 정산 연산 시스템 (ERP)

  - 현재 상태: 어드민 조종실 대시보드(admin/src/app/tenant/page.tsx) 화면만 구현되어 있고, 상품을 등록하며 세금을
    계산하는 실제 폼과 계산 엔진은 대기 중입니다.
  - 실제 명품 비즈니스 세무 연산 산식 명세 (핵심 로직):
    1.  매입 거래 실수익 산식:
          - 마진 부가세 = (실제 판매가 - 매입 원가) / 11
          - PG 수수료 = 실제 판매가 * 3.3% (가맹점 기본 수수료 적용)
          - 사장님 실수익 = 실제 판매가 - 매입 원가 - 마진 부가세 - PG 수수료
    2.  위탁 거래 실수익 산식:
          - 위탁 수수료 매출 = 실제 판매가 * 위탁 수수료율 (예: 10%)
          - PG 수수료 = 실제 판매가 * 3.3%
          - 고객 송금 정산금 = 실제 판매가 - 위탁 수수료 매출 - PG 수수료
  - 잔여 개발 항목:
      - admin/src/app/tenant/products/page.tsx (OCR 연동형 신상품 등록 폼 구현)
      - backend/src/settlements/ (위의 복잡한 마진 세무 쿼리를 매일 밤 정산 테이블에 자동 기입하는 백엔드 엔진
        개발)
