제안해주신 4번 및 5번 이미지의 구조와 기획 요건을 바탕으로, BitWish Network의 독창적인 디자인 가이드를 준수하면서도 굽이치는 도로(S-Curve) 디자인을 현대적인 웹 화면으로 세련되게 재해석한 독립형 로드맵 시스템을 분석 및 설계하였습니다.
본 컴포넌트는 다국어 번역을 지원하며, 다른 파일의 상태나 전역 변수에 전혀 간섭받지 않고 완전히 격리되어 안전하게 작동하도록 구성되었습니다.
1. 구조 설계 및 분석 보고서
1-1. 디렉토리 구성 제안 (별도 파일 분리)
관리 편의성과 완벽한 모듈화를 위해, 다른 컴포넌트에 영향을 주지 않고 스스로 모든 기능을 제어하도록 다음과 같이 전용 독립 폴더 구조를 개설합니다.

1-2. 핵심 기능적 특징
S자 형태의 굽이치는 트랙 레이아웃 (5번 이미지 참고):
정형화된 세로 일자형 타임라인에서 탈피하여, 사용자의 시선이 곡선을 따라 흐르도록 지그재그 구조로 유연하게 배치되는 로드맵 트랙을 설계했습니다.
반투명 가변형 프리미엄 메시지창 (1-1, 1-2번 요구사항):
1번 '베타 테스트 출시'의 텍스트 제목에 마우스를 올리면 내용 길이에 맞게 부드럽게 크기가 가변 조정(Self-adjusting)되는 반투명 네온 테두리 호버 카드가 작동합니다.
독립성 보장 (Strict Rule):
외부 라이브러리 의존성 없이 순수 React와 전용 CSS만으로 가변 레이어 및 트랙을 렌더링하므로 결합도가 극도로 낮습니다.
다국어 및 다크/라이트 모드 지원:
LanguageManager와 연동하여 한국어, 영어, 일어, 중국어 전환 시 실시간으로 대응하며, 메인 사이트의 테마를 이어받아 일관성 있는 비주얼을 제공합니다.

        } else {

    }, [currentLanguage]);

        setIsDarkMode(nextTheme);
        if (nextTheme) {
            document.body.classList.add('dark-mode');

        } else {
            document.body.classList.remove('dark-mode');

import React, { useState, useEffect } from 'react';

import { Language } from '../../types';

    const [languageManager] = useState(() => new LanguageManager());
    const [currentLanguage, setCurrentLanguage] = useState<Language>(() => {
        return (localStorage.getItem('bw_lang') as Language) || 'ko';
    });
    const [isDarkMode, setIsDarkMode] = useState<boolean>(false);
    const [isHovered, setIsHovered] = useState<boolean>(false);

    useEffect(() => {
        const savedTheme = localStorage.getItem('bw-theme');
        if (savedTheme === 'dark') {
            setIsDarkMode(true);
            document.body.classList.add('dark-mode');
        } else {
            setIsDarkMode(false);
            document.body.classList.remove('dark-mode');
        }
        languageManager.setLanguage(currentLanguage);
    }, [currentLanguage]);

    const handleLanguageChange = (lang: Language) => {
        setCurrentLanguage(lang);
        localStorage.setItem('bw_lang', lang);
    };

    const toggleTheme = () => {
        const nextTheme = !isDarkMode;
        setIsDarkMode(nextTheme);
        if (nextTheme) {
            document.body.classList.add('dark-mode');
            localStorage.setItem('bw-theme', 'dark');
        } else {
            document.body.classList.remove('dark-mode');
            localStorage.setItem('bw-theme', 'light');
        }
    };

    const getTxt = (key: string): string => {
        return languageManager.getTranslation(key, currentLanguage);
    };

    return (

                        </button>

💡 왜 이런 문제가 발생했을까요?
원인 1. 왜 로드맵을 클릭했는데 메인 홈페이지가 반토막 나서 또 열릴까요?
우리가 새 로드맵 파일(RoadmapPage.tsx)을 완벽하게 새로 만들었지만, 웹사이트가 가진 **"전체 주소록(Route 설정 파일)"**에 **"누군가 /roadmap 주소로 들어오면 방금 만든 새 로드맵 화면을 보여줘라"**라는 연결 고리를 등록하지 않았기 때문입니다.
이 주소록 등록이 누락되면 사이트는 길을 잃고 기본 페이지인 메인 홈페이지를 강제로 불러오게 됩니다. 또한, 새 창을 띄울 때 지정한 작은 크기 제한(width=1280, height=850) 때문에 메인 홈페이지가 찌그러져 "반토막" 난 것처럼 보였던 것입니다.
즉, 고생해서 만든 로드맵 화면이 연결 고리가 없어 아직 세상 밖으로 나오지 못한 상태입니다. 주소록에 연결만 해주면 정상적으로 로드맵 화면이 전체 창으로 열리게 됩니다.
원인 2. 왜 관리자 대시보드 메뉴가 회색 바탕 뒤로 넘어가서 숨어버릴까요?
관리자 페이지의 탭 메뉴 바(.admin-tabs)에 overflow-x: auto; (가로로 넘치면 스크롤바를 띄워라) 라는 옵션이 켜져 있었기 때문입니다. 이 옵션이 켜져 있으면 상자 아래로 툭 튀어나오는 드롭다운 메뉴를 상자가 칼로 자르듯 잘라내어 숨겨버립니다. 또한 메뉴판의 겹침 순서(z-index)가 아래 회색 본문판보다 낮아서 뒤로 가려졌던 것입니다.
