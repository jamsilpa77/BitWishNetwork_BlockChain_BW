## 🚀 3. Vultr 실서버 최종 실행 가이드 (3단계)

대표님의 Vultr 서버 터미널에서 다음 3단계 명령어를 실행하시면 DB 내 허수 초과 블록이 정밀 제거되고 1:1 완벽 정합이 완성됩니다:

```bash
# 1단계: 1·2·3공정 수복 코드 최신화 및 서버 빌드
git pull origin main && npm run build

# 2단계: 3공정 초과 블록 정밀 안전 소거 스크립트 실행
npx ts-node server/scripts/sync-blocks-1to1.ts

# 3단계: 백엔드 서비스 재가동 (버그 완전 차단 적용)
pm2 restart bitwish-backend
```
