## 🛠️ [1단계] 모달 외곽 레이아웃 규격 축소 & 배경 스크롤 잠금 엔진 설치

### 1-1. 배경 스크롤 잠금 (Body Scroll Lock) 회로 수술
- **작업 내용**:
  - `MyWalletModal.tsx` 및 `MiningStatusModal.tsx` 모달 컴포넌트의 `useEffect` 생명주기에 `document.body.style.overflow` 제어 로직을 주입.
  - `isOpen === true` 시 `document.body.style.overflow = 'hidden'`을 실행하여 뒤쪽 메인 홈페이지의 마우스 휠 스크롤을 100% 완전히 고정/잠금.
  - `isOpen === false` 또는 컴포넌트 언마운트 시 `document.body.style.overflow = 'unset'`으로 원복하여 휠 스크롤 간섭 버그 차단.

### 1-2. `MyWalletModal` 팝업 껍데기 규격 슬림화
- **작업 내용**:
  - `MyWalletModal.css` 내 데스크톱 기준 최대 폭을 기존 약 850px~900px에서 **680px ~ 720px 슬림 규격**으로 축소.
  - `max-height`를 `85vh`로 제한하고, 내부 패딩(`padding`)을 기존 24px/32px에서 **18px/20px**로 조여 한눈에 들어오는 가독성 확보.

### 1-3. `MiningStatusModal` 팝업 껍데기 규격 슬림화
- **작업 내용**:
  - `MiningStatusModal.css` 내 데스크톱 기준 최대 폭을 기존 600px~650px에서 **540px ~ 580px 컴팩트 규격**으로 축소.
  - 내부 패딩을 16px/20px로 정돈하여 마우스 드래그 이동 시 경쾌하고 매끄럽게 반응하도록 개선.

### 1-4. 오버레이 백드롭 블러(Backdrop Blur) 효과 고급화
- **작업 내용**:
  - 두 모달의 오버레이 배경색을 `rgba(15, 23, 42, 0.75)` (딥 슬레이트 다크)로 조정.
  - `backdrop-filter: blur(12px)` 및 `-webkit-backdrop-filter: blur(12px)`를 적용하여 메인 홈페이지와 모달 간의 명확한 공간 입체감 부여.

## 🛠️ [2단계] `MyWalletModal` 헤더 슬림화 및 지갑 주소 단권화 수복

### 2-1. 헤더 톤앤매너 재설계
- **작업 내용**:
  - `MyWalletModal.css` 내 `.wallet-header` 배경의 강렬한 보라색 글래디언트를 삭제하고, 절제되고 차분한 **딥 인디고 다크 톤(`background: #1E293B` / `#0F172A`)** 으로 교체.

### 2-2. 헤더 내부 7개 난잡한 요소의 2행 정돈 구조화
- **작업 내용**:
  - **1행 (상단)**: `나의 지갑` 타이틀 + `🟢 활성` 배지 + `새로고침(↻)` 버튼 + `로그아웃` 버튼을 우측 정렬로 깔끔히 수평 배치.
  - **2행 (하단)**: `축약 지갑 주소` + `📋 주소복사` 버튼 + `⛏ 마이닝 시작` 강조 버튼을 한 줄로 정렬하여 시선 이동 최소화.

### 2-3. 하단 중복 지갑 주소 박스 완전 제거
- **작업 내용**:
  - `MyWalletModal.tsx` 내 하단 영역에 위치하던 거대한 `address-footer-section` (중복 지갑 주소 박스) 태그를 **완전 삭제**.
  - 지갑 주소 관련 조작은 상단 헤더의 주소 복사 배지 1개로 단권화하여 모달 하단의 불필요한 높이 낭비 요인을 완전히 제거.

## 🛠️ [3단계] `MyWalletModal` 탭 메뉴 & 2대 데이터 카드 대개조

### 3-1. 6개 탭 메뉴 시각적 명확화
- **작업 내용**:
  - `MyWalletModal.css` 내 `.tab-item` 스타일에 활성화(`active`) 시 **네온 블루 하단 인디케이터 바(`border-bottom: 3px solid #3B82F6`)** 와 볼드 폰트를 적용.
  - 비활성 탭은 텍스트 색상을 `color: #64748B`로 톤다운하여 현재 위치한 탭이 1초 만에 직관적으로 부각되도록 수복.

### 3-2. `잔액 카드` 수치 타이포그래피 모노스페이스 수직 정렬
- **작업 내용**:
  - `실시간 누적 보상` 및 `사용 가능 금액` 수치 표시에 `font-family: 'Roboto Mono', 'Courier New', monospace` 적용.
  - 소수점 8자리 수치와 `BW` 단위를 분리 정렬하여 숫자가 뭉개지거나 겹쳐 보이는 현상 완전 해결.
  - 카드 내부의 면적을 가로막던 조잡한 분홍/하늘 안내 박스를 **12px 슬림 마이크로 가이드**로 전환하여 카드 내부 답답함 제거.

### 3-3. `추천 보너스 카드` 디자인 통합
- **작업 내용**:
  - 하늘색으로 혼자 이질적으로 떠 있던 `추천인 코드 박스`를 지갑 전체 톤앤매너와 어울리는 **은은한 인디고 틴트 박스(`background: #F0F9FF`, `border: 1px solid #BAE6FD`)** 로 교체.
  - 핀 메모 아이콘 텍스트 여백을 정돈하여 깔끔한 카드 비율 완성.

## 🛠️ [4단계] `MyWalletModal` 하단 2x2 기능 버튼군 시각적 가중치(Visual Hierarchy) 수복

### 4-1. 버튼 색상 무지개화 해소 및 체계화
- **작업 내용**:
  - 파랑/빨강/보라/주황으로 난잡하던 4개 버튼의 색상 체계를 1차(Primary) 및 2차(Secondary) 그룹으로 명확히 분류.

### 4-2. 1차 프라이머리 버튼 (핵심 금융 기능) 강조
- **작업 내용**:
  - **`[↓ 송금받기 ↓]` / `[↑ 송금하기 ↑]`**: 사용자가 가장 자주 쓰는 핵심 액션이므로 **시선 집중도가 높은 프라이머리 입체 블루/에메랄드 엠보싱 버튼**으로 시각적 가중치 최대 부여.

### 4-3. 2차 세컨더리 버튼 (보조 인증/설정 기능) 톤다운
- **작업 내용**:
  - **`[🔑 OTP 설정]` / `[🛡️ KYC 인증 신청]`**: 톤다운된 **세컨더리 엠보싱 메탈/슬레이트 버튼 스타일**로 변경하여, 1차 송금 버튼과의 시각적 충돌을 차단하고 4개 버튼이 우후죽순 튀는 현상 해결.

## 🛠️ [8단계] 검증 및 품질 테스트 (QA Protocol)

### 8-1. 데스크톱 & 모바일 뷰포트 레이아웃 정밀 검증
- **검증 항목**:
  - 데스크톱(1920x1080, 1440x900)에서 지갑 및 마이닝 모달이 꽉 차지 않고 슬림하게 정중앙에 뜨는지 확인.
  - 스마트폰 모바일 화면(370x886)에서 모달이 찌그러지거나 하단으로 밀리지 않고 100% 정중앙 반응형으로 작동하는지 확인.

### 8-2. 배경 스크롤 잠금 및 모달 간 전환 검증
- **검증 항목**:
  - 모달을 열었을 때 메인 홈페이지 배경 휠 스크롤이 100% 잠기는지 검증.
  - 마이닝 모달에서 `🔑 나의 지갑` 클릭 시 마이닝 모달이 닫히며 지갑 모달만 깔끔하게 전환되는지 겹침 현환 제로 검증.
